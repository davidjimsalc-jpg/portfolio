
[DomainPasswordSpray](https://github.com/dafthack/DomainPasswordSpray): muy util cuando tenemos un foothold en Windows

También podríamos utilizar Kerbrute como en la seccion anterior

Si estamos autenticados en el dominio, la herramienta generará automáticamente una lista de usuarios desde Active Directory, consultará la política de contraseñas del dominio y excluirá las cuentas de usuario que estén a un intento de ser bloqueadas

Al igual que cuando ejecutamos el ataque de pulverización de contraseñas (_password spraying_) desde nuestro host Linux, también podemos proporcionar una lista de usuarios a la herramienta

Opciones:

- -UserList: si lo ponemos es para especificar una Lista de usuarios, sino la crea el
- -Password: suministraremos la pass
- -OutFile: escribe la salida tambien en un archivo

```
Import-Module .\DomainPasswordSpray.ps1
Invoke-DomainPasswordSpray -Password Welcome1 -OutFile spray_success -ErrorAction SilentlyContinue
```

## Password Spraying externo

Algunos objetivos comunes incluyen:

- Microsoft 0365
- Outlook Web Exchange
- Exchange Web Access
- Skype for Business
- Lync Server
- Portales de Microsoft Remote Desktop Services (RDS)
- Portales de Citrix que utilizan autenticación de AD
- Implementaciones de VDI que utilizan autenticación de AD como VMware Horizon
- Portales de VPN (Citrix, SonicWall, OpenVPN, Fortinet, etc. que utilizan autenticación de AD)
- Aplicaciones web personalizadas que utilizan autenticación de AD
