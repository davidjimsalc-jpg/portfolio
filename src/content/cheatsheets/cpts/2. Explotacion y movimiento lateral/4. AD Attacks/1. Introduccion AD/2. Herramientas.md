
## Ubicacion

Como se dijo estaran ubicadas en:

- MS01: C:\Tools
- ATTACK: /opt


## Herramientas AD 

| Herramienta                                                                                                                                   | Descripcion                                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [PowerView](https://github.com/PowerShellMafia/PowerSploit/blob/master/Recon/PowerView.ps1)/[SharpView](https://github.com/dmchell/SharpView) | Enumeran y consultan información de **Active Directory** (usuarios, grupos, equipos, permisos, sesiones, etc.) para descubrir relaciones, accesos y posibles vías de ataque. PowerView usa PowerShell y SharpView es su port a .NET. |
| [BloodHound](https://github.com/BloodHoundAD/BloodHound)                                                                                      | Representa gráficamente las **relaciones y permisos de AD** para identificar posibles **rutas de ataque** hasta objetivos de interés.                                                                                                |
| [SharpHound](https://github.com/BloodHoundAD/BloodHound/tree/master/Collectors)                                                               | **Recolector de datos de BloodHound** escrito en C#. Extrae información de AD (usuarios, grupos, ACL, GPO, sesiones, equipos...) y genera archivos para importarlos en BloodHound.                                                   |
| [BloodHound.py](https://github.com/fox-it/BloodHound.py)                                                                                      | Ingestor/recolector de BloodHound escrito en **Python**, útil para recopilar información de AD desde una máquina atacante **no unida al dominio**.                                                                                   |
| [Kerbrute](https://github.com/ropnop/kerbrute)                                                                                                | Utiliza **Kerberos** para **enumerar usuarios**, realizar **password spraying** y probar credenciales mediante fuerza bruta.                                                                                                         |
| [Impacket toolkit](https://github.com/SecureAuthCorp/impacket)                                                                                | Colección de herramientas en **Python** para interactuar con protocolos de red y realizar **enumeración y ataques sobre Active Directory**                                                                                           |
| [Responder](https://github.com/lgandx/Responder)                                                                                              | Realiza **poisoning de LLMNR, NBT-NS y mDNS** para interceptar solicitudes de resolución de nombres y capturar credenciales/hashes                                                                                                   |
| [Inveigh.ps1](https://github.com/Kevin-Robertson/Inveigh/blob/master/Inveigh.ps1)                                                             | Alternativa a Responder escrita en **PowerShell**, orientada a realizar **spoofing y poisoning** en la red.                                                                                                                          |
| [C# Inveigh (InveighZero)](https://github.com/Kevin-Robertson/Inveigh/tree/master/Inveigh)                                                    | Versión en **C# de Inveigh**, con consola interactiva para realizar poisoning y gestionar los **usuarios/hashes capturados**.                                                                                                        |
| [rpcinfo](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/rpcinfo)                                           | Enumera los **servicios RPC disponibles** en un host remoto y muestra información sobre ellos.                                                                                                                                       |
| [rpcclient](https://www.samba.org/samba/docs/current/man-html/rpcclient.1.html)                                                               | Herramienta de Samba para interactuar con **RPC de Windows** y enumerar información de AD, como **usuarios, grupos, dominios y políticas**.                                                                                          |
| [CrackMapExec (CME)](https://github.com/byt3bl33d3r/CrackMapExec)                                                                             | Herramienta para **enumeración, validación de credenciales y post-explotación** en entornos AD mediante protocolos como SMB, WinRM, WMI y MSSQL.                                                                                     |
| [Rubeus](https://github.com/GhostPack/Rubeus)                                                                                                 | Herramienta en **C# especializada en Kerberos**, utilizada para enumerar y realizar distintas técnicas de abuso de Kerberos.                                                                                                         |
| [GetUserSPNs.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/GetUserSPNs.py)                                              | Módulo de Impacket que identifica cuentas con **SPN asociados**, útil para detectar usuarios susceptibles de **Kerberoasting**                                                                                                       |
| [Hashcat](https://hashcat.net/hashcat/)                                                                                                       | Herramienta para **crackear hashes** y recuperar contraseñas mediante distintos tipos de ataques.                                                                                                                                    |
| [enum4linux](https://github.com/CiscoCXSecurity/enum4linux)                                                                                   | Enumera información de sistemas **Windows/Samba**, como usuarios, grupos, recursos compartidos y políticas.                                                                                                                          |
| [enum4linux-ng](https://github.com/cddmp/enum4linux-ng)                                                                                       | Versión modernizada de enum4linux para realizar **enumeración de Windows/Samba** de forma más estructurada.                                                                                                                          |
| [ldapsearch](https://linux.die.net/man/1/ldapsearch)                                                                                          | Cliente de línea de comandos para realizar **consultas LDAP** y obtener información de Active Directory.                                                                                                                             |
| [windapsearch](https://github.com/ropnop/windapsearch)                                                                                        | Script en Python que automatiza la **enumeración de usuarios, grupos y equipos de AD mediante LDAP**.                                                                                                                                |
| [DomainPasswordSpray.ps1](https://github.com/dafthack/DomainPasswordSpray)                                                                    | Script PowerShell para realizar **password spraying** contra usuarios de un dominio.                                                                                                                                                 |
| [LAPSToolkit](https://github.com/leoloobeek/LAPSToolkit)                                                                                      | Herramientas PowerShell para **enumerar y auditar LAPS**, identificando equipos y permisos relacionados con contraseñas de administradores locales.                                                                                  |
| [smbmap](https://github.com/ShawnDEvans/smbmap)                                                                                               | Enumera **recursos compartidos SMB y sus permisos** para identificar a qué recursos puede acceder un usuario.                                                                                                                        |
| [psexec.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/psexec.py)                                                        | Herramienta de Impacket para obtener **ejecución remota de comandos** en Windows mediante SMB, proporcionando una shell semiinteractiva                                                                                              |
| [wmiexec.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/wmiexec.py)                                                      | Herramienta de Impacket para ejecutar **comandos remotamente mediante WMI**                                                                                                                                                          |
| [Snaffler](https://github.com/SnaffCon/Snaffler)                                                                                              | Busca automáticamente **información sensible y credenciales** en recursos compartidos de archivos accesibles dentro de un entorno AD.                                                                                                |
| [smbserver.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/smbserver.py)                                                  | Levanta rápidamente un **servidor SMB**, principalmente útil para **transferir archivos** entre el atacante y equipos Windows.                                                                                                       |
| [setspn.exe](https://docs.microsoft.com/en-us/previous-versions/windows/it-pro/windows-server-2012-r2-and-2012/cc731241\(v=ws.11\))           | Herramienta de Windows para **consultar, añadir, modificar o eliminar SPN** asociados a cuentas de Active Directory.                                                                                                                 |
| [Mimikatz](https://github.com/ParrotSec/mimikatz)                                                                                             | Herramienta para **extraer y utilizar credenciales de Windows**, incluyendo contraseñas, hashes NTLM y tickets Kerberos; permite técnicas como **Pass-the-Hash**.                                                                    |
| [secretsdump.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/secretsdump.py)                                              | Herramienta de Impacket para **extraer hashes y secretos de SAM/LSA/NTDS**, tanto local como remotamente.                                                                                                                            |

| [noPac.py](https://github.com/Ridter/noPac)                                                                                                   | Explota **CVE-2021-42278 + CVE-2021-42287** para escalar desde un usuario de dominio hasta **Domain Admin** en sistemas vulnerables.                                                                                                 |
| [rpcdump.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/rpcdump.py)                                                      | Herramienta de Impacket para **enumerar endpoints RPC** disponibles en un sistema remoto.                                                                                                                                            |

| [PetitPotam.py](https://github.com/topotam/PetitPotam)                                                                                        | Explota **CVE-2021-36942** para forzar a un equipo Windows a **autenticarse contra otro sistema**, pudiendo combinarse con ataques de relay.                                                                                         |
