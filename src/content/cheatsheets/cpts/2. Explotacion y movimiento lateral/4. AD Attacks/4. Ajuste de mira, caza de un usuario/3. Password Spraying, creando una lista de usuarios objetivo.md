
## Enumeracion detallada de usuarios

Varias formas de conseguir una lista de usuarios validos:

- Aprovechando las SMB NULL Sessions para recuperar la lista completa desde el DC
- Usando vinculacion anonima LDAP para consultar LDAP
- Usando Kerbrute para validar una lista de alguna fuente externa como RRSS (listas de usuarios: [statistically-likely-usernames](https://github.com/insidetrust/statistically-likely-usernames), LinkedIn: [linkedin2username](https://github.com/initstring/linkedin2username)) con estas herramientas podemos crear listas de usernames de esas fuentes
- Usando credenciales de un sistema de ataque Linux o Windows ya sea proporcionado por cliente u obtenido por medios como LLMNR/NTB-NS Poisoning usando Responder o password spraying exitoso


## Obteniendo lista de usuarios con diferentes metodos

#### SMB Null Session para obtener lista

Si estamos dentro de una maquina interna pero sin credenciales validas podemos usar SMN NULL Sessions 

	Si tenemos SYSTEM en un host Windows podemos consultar facilmente el AD para obtener info suplantando la cuenta maquina


[enum4linux](https://github.com/portcullislabs/enum4linux), [rpcclient](https://www.samba.org/samba/docs/current/man-html/rpcclient.1.html) y [CrackMapExec](https://github.com/byt3bl33d3r/CrackMapExec): herramientas para Null Sessions y vinculaciones anonimas LDAP

1. Con enum4linux

```
enum4linux -U 172.16.5.5 | grep "user:" | cut -f2 -d"[" | cut -f1 -d"]"
```
![[Pasted image 20260925192732.png]]


2. Con rpcclient > enumdomusers

```
rpcclient -U "" -N IP_DC
```
![[Pasted image 20260925192813.png]]

3. Con crackmapexec --users (`badpwdcount`: mostrara el numero de intentos fallidos para que podamos eliminar de la lista cuentas que esten cerca del umbral, `badpwdtime`: fecha y hora del ultimo intento)

```
crackmapexec smb IP_DC --users
```
![[Pasted image 20260925193008.png]]


#### Vinculacion anonima LDAP para obtener lista

[windapsearch](https://github.com/ropnop/windapsearch) y [ldapsearch](https://linux.die.net/man/1/ldapsearch): herramientas que podemos usar

1. Con ldapsearch:

```
ldapsearch -h IP_DC -x -b "DC=INLANEFREIGHT,DC=LOCAL" -s sub "(&(objectclass=user))" | grep sAMAccountName: | cut -f2 -d" "
```
![[Pasted image 20260925193105.png]]

2. Con windapsearch:

```
./windapsearch.py --dc-ip 172.16.5.5 -u "" -U
```
![[Pasted image 20260925193142.png]]


#### Kerbrute para obtener lista de usuarios

Si no tenemos ningun acceso desde nuestra posicion en la red interna podemos usar Kerbrute para enumerar el AD

Es mas rapida y potencialmente sigilosa

La herramienta envía solicitudes de TGT al controlador de dominio sin preautenticación de Kerberos para realizar la enumeración de nombres de usuario. Si el KDC responde con el error `PRINCIPAL UNKNOWN`, el nombre de usuario no es válido. Cada vez que el KDC solicita la preautenticación de Kerberos, esto indica que el nombre de usuario existe, y la herramienta lo marcará como válido

No causa fallos de inicio de sesión y no bloqueará cuentas

###### Wordlist de usuarios: [jsmith.txt](https://github.com/insidetrust/statistically-likely-usernames/blob/master/jsmith.txt) o [statistically-likely-usernames](https://github.com/insidetrust/statistically-likely-usernames) 

```
kerbrute userenum -d inlanefreight.local --dc 172.16.5.5 /opt/jsmith.txt
```

## Enumeracion con credenciales para construir lista de usuarios

Con crackmapexec --users (`badpwdcount`: mostrara el numero de intentos fallidos para que podamos eliminar de la lista cuentas que esten cerca del umbral, `badpwdtime`: fecha y hora del ultimo intento)

```
sudo crackmapexec smb 172.16.5.5 -u htb-student -p Academy_student_AD! --users
```
