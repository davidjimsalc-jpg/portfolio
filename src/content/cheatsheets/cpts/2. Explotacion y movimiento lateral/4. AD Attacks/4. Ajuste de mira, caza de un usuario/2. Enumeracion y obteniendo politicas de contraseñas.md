
Hay dos formas, con **SMB** o con **LDAP**

## SMB

#### Enumerando la politica de contraseñas desde Linux CON CREDENCIALES

Con credenciales de dominio validas podemos usar [CrackMapExec](https://github.com/byt3bl33d3r/CrackMapExec) o `rpcclient` para obtener la politica de contraseñas

```
crackmapexec smb 172.16.5.5 -u avazquez -p Password123 --pass-pol
```
![[Pasted image 20260925184019.png]]

#### Enumerando la politica de contraseñas desde Linux con Sesiones Nulas de SMB

Sin credenciales podemos obtenerlo a traves de SMB NULL sessions o una vinculacion anonima de LDAP

Las SMB NULL Sessions permiten a un atacante no autenticado obtener informacion del dominio como listas de usuarios, grupos, equipos... (las malas confs de SMB suelen ser de configuraciones in situ de los DCs antiguos)

Podriamos usar `enum4linux`, `CrackMapExec`, `rpcclient`

[rpcclient](https://www.samba.org/samba/docs/current/man-html/rpcclient.1.html): para comprobar si un DC permite acceso por SMB NULL Session

```
rpcclient -U "" -N 172.16.5.5
> querydominfo
```

#### Enumerando la Null Session desde Windows

Establecer sesion nula desde Windows y confirmar que podemos realizar mas ataques de este tipo:

```
net use \\DC01\ipc$ "" /u:""
```
![[Pasted image 20260925185255.png]]

	Tambien podemos usar NOMBRE/PASS para conectarnos

Errores comunes al intentar autenticarnos:

1. Error: la cuenta esta deshabilitada
```
net use \\DC01\ipc$ "" /u:guest
```
![[Pasted image 20260925185400.png]]

2. Error: la contraseña es incorrecta
```
net use \\DC01\ipc$ "password" /u:guest
```
![[Pasted image 20260925185447.png]]

3. Error: la cuenta esta bloqueada
```
net use \\DC01\ipc$ "password" /u:guest
```

## LDAP y otros

#### Enumerando la politica de contraseñas desde Linux - Vinculacion anonima de LDAP

La vinculacion anonima de LDAP permite a los atacantes obtener informacion del dominio como una lista de usuarios, grupos, equipos...

Podemos usar herramientas como `windapsearch.py`, `ldapsearch`, `ad-ldapdomaindump.py`...


[ldapsearch](https://linux.die.net/man/1/ldapsearch)

Ejemplo para obtener politica de contraseñas:

```
ldapsearch -h 172.16.5.5 -x -b "DC=INLANEFREIGHT,DC=LOCAL" -s sub "*" | grep -m 1 -B 10 pwdHistoryLength
```
![[Pasted image 20260925190256.png]]

	En versiones recientes se usa -H en vez de -h


#### Enumerando politicas de contraseñas desde Windows

Si podemos autenticarnos en el dominio desde un host de Windows, podemos usar binarios integrados de Windows como `net.exe`

También podemos usar varias herramientas como PowerView, CrackMapExec portado a Windows, SharpMapExec, SharpView

1. net.exe para politica de contraseñas:

```
net accounts
```
![[Pasted image 20260925190502.png]]

Esta política de contraseñas es excelente para un ataque de `password spraying`. El mínimo de ocho caracteres significa que podemos probar contraseñas débiles comunes como `Welcome1`. El umbral de bloqueo de 5 significa que podemos intentar 2-3 (para estar seguros) ataques de `password spraying` cada 31 minutos sin el riesgo de bloquear ninguna cuenta


2. Usando PowerView para politica de contraseñas:

```
import-module .\PowerView.ps1
Get-DomainPolicy
```
