Podemos usar la siguiente consulta Cypher para buscar usuarios con este tipo de acceso pegandola en Raw Query:

MATCH p1=shortestPath((u1:User)-[r1:MemberOf*1..]->(g1:Group)) MATCH p2=(u1)-[:CanPSRemote*1..]->(c:Computer) RETURN p2

## Adminsitrador de SQL Server

Podemos obtener credenciales para una cuenta con este acceso a través de Kerberoasting (común) u otros como la Falsificación de Respuesta LLMNR/NBT-NS o la pulverización de contraseñas

Otra forma en que puedes encontrar credenciales de servidor SQL es usando la herramienta [Snaffler](https://github.com/SnaffCon/Snaffler) para encontrar archivos web.config u otros

#### Comprobacion BloodHound

Podemos usar la siguiente query para encontrar acceso SQLAdmin buscando los `SQL Admin Rights en la pestaña Node Info` o con la siguiente consulta Cypher:

```
MATCH p1=shortestPath((u1:User)-[r1:MemberOf*1..]->(g1:Group)) MATCH p2=(u1)-[:SQLAdmin*1..]->(c:Computer) RETURN p2
```
