```

```
![[Pasted image 20260926231203.png]]

#### Enumeracion rpcclient

Cuandon miramos usuarios en rpcclient veremos un campo llamado `rid:` al lado de cada usuario que es un identificador unico para cada objeto puesto por Windows:

- SID o identificador de seguridad para el dominio: S-1-5-21-3842939050-3880317879-2865463114
- Cuando se crea un objeto de dominio, el SID se combina con un RID para crear un valor unico que representa al objeto
- El usuario `htb-student` con RID:0x457 que en decimal seria 1111 tendra un SID: S-1-5-21-3842939050-3880317879-2865463114-1111
- Unico para el objeto dentro del dominio

Habra cuentas que tengan el mismo RID aunque esten en distinto equipo como: Administrator de un dominio que es RID: 0x1f4 y en decimal 500

1. Enumeramos usuarios y vemos su RID


## Impacket Toolkit

Proporciona muchas formas diferentes de enumerar, interactuar y explotar protocolos de Windows y encontrar la información que necesitamos usando Python

[wmiexec.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/wmiexec.py) y [psexec.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/psexec.py)

#### Psexec.py

Crea un servicio remoto subiendo un ejecutable con nombre aleatorio al recurso compartido ADMIN$, registra el servicio usando RPC y el administrador de control de servicios de windows. Despues proporciona una shell como SYSTEM

```
psexec.py DOMAIN/USER:'PASS'@IP
```
![[Pasted image 20260926232100.png]]

#### Wmicexec.py

Usa una shell semiinteractiva donde los comandos se ejecutan a traves del WMI, no deja archivos ni ejecutables en el host y genera menos registros. Despues de conectarse ejecuta como usuario de administracion local con que nos conectamos (es un enfoque mas sigiloso)

```
wmiexec.py DOMAIN/USER:'PASS'@IP
```
![[Pasted image 20260926232349.png]]
