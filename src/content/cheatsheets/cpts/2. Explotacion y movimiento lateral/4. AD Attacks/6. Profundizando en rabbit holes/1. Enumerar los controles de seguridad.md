
Tras obtener un foothold podriamos enumerar el estado defensivo de los hosts, enumerar el dominio a fondo...

Estos productos de seguridad pueden afectar a las herramientas que usamos


## Windows Defender

Por defecto bloqueara herramientas como PowerView

[Get-MpComputerStatus](https://docs.microsoft.com/en-us/powershell/module/defender/get-mpcomputerstatus?view=win10-ps): para obtener el estado actual de Defender en el parametro `RealTimeProtectionEnabled` está establecido en `True`

```
Get-MpComputerStatus
```

## AppLocker

Lista blanca de aplicaciones: lista de sw o ejecutables que pueden estar presentes y ejecutarse en el sistema. El resto seran bloqueados

[AppLocker](https://docs.microsoft.com/en-us/windows/security/threat-protection/windows-defender-application-control/applocker/what-is-applocker): es la solución de listas blancas de aplicaciones

Es habitual que las organizaciones bloqueen cmd.exe y PowerShell.exe y el acceso de escritura a ciertos directorios, pero todo esto se puede eludir

Pueden bloquear el ejecutable PowerShell.exe pero se pueden olvidar de otros directorios por lo que podemos simplemente llamarlo desde otras ubicaciones:

- `%SystemRoot%\SysWOW64\WindowsPowerShell\v1.0\powershell.exe` 
- `PowerShell_ISE.exe`

1. Miramos si esta activado AppLocker:

```
Get-AppLockerPolicy -Effective | select -ExpandProperty RuleCollections
```

## Modo de lenguaje restringido de PS

Bloquea muchas de las caracteristicas necesarias para usar PS de forma eficaz como el bloqueo de objetos COM

1. Enumerar si estamos en este modo de lenguaje

```
$ExecutionContext.SessionState.LanguageMode
```

## LAPS

Se usa para aleatorizar las contraseñas de administradores locales en los hosts de Windows y evitar movimiento lateral

[LAPSToolkit](https://github.com/leoloobeek/LAPSToolkit) facilita enormemente esto con varias funciones

Podemos usarla para analizar si esta activado para todos los ordenadores

1. Identificar los grupos de Active Directory que tienen permisos delegados para leer las contraseñas de administradores locales gestionadas mediante LAPS

```
Find-LAPSDelegatedGroups
```
![[Pasted image 20260926200604.png]]


2. Comprobar los derechos de cada ordenador con LAPS habilitado para cualquier grupo con acceso de lectura y usuarios. Estos pueden leer contraseñas de LAPS y pueden estar menos protegidos que los usuarios de grupos delegados

```
Find-AdmPwdExtendedRights
```
![[Pasted image 20260926200824.png]]

3. Buscar ordenadores con LAPS habilitado, cuando expiran las contraseñas e incluso las contraseñas aleatorias en texto plano

```
Get-LAPSComputers
```
