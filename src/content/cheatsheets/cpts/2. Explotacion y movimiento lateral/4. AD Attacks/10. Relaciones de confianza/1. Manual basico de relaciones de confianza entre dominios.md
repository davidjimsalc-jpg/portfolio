
## Descripcion general de las relaciones de confianza de dominio

Una relacion de confianza se usa para establecer autenticacion entre bosques o arboles de dominio

![[Pasted image 20261005152618.png]]

Esto permite acceder a recursos de otro dominio fuera del principal donde reside la cuenta

La confianza crea un vinculo entre los sistemas de autenticacion de dominios y permite comunicacion bidireccional o unidireccional. Tipos:

- Padre-hijo: relacion entre dominios del mismo arbol siendo transitica bidireccional (se pueden autenticar en el padre y en el hijo)
- Vinculo cruzado: entre dominios hijos de diferentes arboles para acelerar la autenticacion
- Externa: confianza no transitiva entre dominios de de diferentes bosques usando los SID como filtrado para la autenticacion
- Raiz de arbol: confianza transitiva bidireccional creada entre el dominio raíz de un nuevo árbol y el dominio raíz del bosque
- De bosque: confianza transitiva entre dos dominios raiz de bosques distintos

	Dominio raiz de bosque es el primer dominio que se crea en todo el bosque. Dominio raiz de arbol es el primer dominio de cada arbol


Tipos de confianzas:

- Transitivas: la confianza se extiende en los que confia el hijo. Si A (padre) confia en B(hijo) y este en C(otro), A confiara en C
- No transitiva: solo confia en el propio dominio hijo

![[Pasted image 20261005154049.png]]


Direcciones de confianza:

- Unidireccional: el dominio puede acceder a los recursos de quien confia pero no viceversa
- Bidireccional: ambos dominios confian entre ellos

Una intrusion en un dominio hijo o en un dominio secundario de otro bosque o arbol que tenga confianza con el principal podria permitirnos acceso al principal. Si obtuviesemos control de un usuario que es admin en el dominio principal, podriamos obtener control de todo el dominio


## Enumeracion de las relaciones de confianza

#### Usando Get-ADTrust

[Get-ADTrust](https://docs.microsoft.com/en-us/powershell/module/activedirectory/get-adtrust?view=windowsserver2022-ps): para enumerar relaciones de confianza

```
Import-Module activedirectory
Get-ADTrust -Filter *
```
![[Pasted image 20261005154509.png]]

En esta salida se muestra que el dominio actual INLANEFREIGHT.LOCAL tiene 2 relaciones de confianza:

- LOGISTICS.INLANEFREIGHT.LOCA: donde en el atributo `IntraForest`  muestra que es uno de sus hijo y actualmente estamos en la raiz del arbol
- FREIGHTLOGISTICS.LOCAL: el atributo `ForestTransitive` en True significa que se trata de una confianza de bosque o externa entre dominios raices


#### Usando PowerView

```
Get-DomainTrust
```
![[Pasted image 20261005160537.png]]

Aqui podemos ver informacion del tipo de confianza

Podemos hacer tambien un mapeo de confianzas del dominio

```
Get-DomainTrustMapping
```
![[Pasted image 20261005160640.png]]

Desde aqui podriamos hacer una enumeracion de usuarios de los subdominios o dominios que tenga confianza:

```
Get-DomainUser -Domain LOGISTICS.INLANEFREIGHT.LOCAL | select SamAccountName
```
![[Pasted image 20261005160736.png]]


#### Usando netdom

Recupera informacion sobre el dominio incluyendo las workstations, servidores y confianzas

```
netdom query /domain:inlanefreight.local trust
```
![[Pasted image 20261005160834.png]]

Consultar controladores de dominio:

```
netdom query /domain:inlanefreight.local dc
```
![[Pasted image 20261005160904.png]]

Consultar workstations y servidores:

```
netdom query /domain:inlanefreight.local workstation
```
![[Pasted image 20261005160926.png]]
