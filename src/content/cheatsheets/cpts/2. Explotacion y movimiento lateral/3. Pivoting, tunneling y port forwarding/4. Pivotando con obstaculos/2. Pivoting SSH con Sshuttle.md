
[Sshuttle](https://github.com/sshuttle/sshuttle): herramienta de Python que elimina la necesidad de configurar proxychains pero solo funciona sobre SSH

1. Instalamos la herramienta

```
sudo apt install sshuttle
```
![[Pasted image 20260704134300.png]]

2. Ejecutamos sshuttle: -r nos permite conectarnos a la maquina remota (host pivote). Necesitamos incluir la red o IP que queremos enrutar a traves del host pivote

Esto crea una entrada en iptables que redirige todo el trafico hacia la red interna a traves del host pivote

```
sudo sshuttle -r USER@IP_HOST_PIVOTE_PUBLICA IP_RED/mascara 
```
![[Pasted image 20260704134438.png]]

3. Ejecutamos comandos dentro de la red interna

```
sudo nmap -Pn -sT -p3389 IP_HOST_OBJETIVOD
```
