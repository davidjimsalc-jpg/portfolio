
En los casos en los que tengamos acceso a una maquina Linux y solo Windows

 [SocksOverRDP](https://github.com/nccgroup/SocksOverRDP): herramienta que usa los Canales Virtuales Dinamicos DVC responsables de tunelizar paquetes a traves de RDP

![[Pasted image 20260705135953.png]]

1. Binarios necesarios:

Podemos buscar ProxifierPE.zip
- [Binarios x64 de SocksOverRDP](https://github.com/nccgroup/SocksOverRDP/releases)
- [Binario portable de Proxifier](https://www.proxifier.com/download/#win-tab)

2. Nos conectamos via RDP con xfreerdp al host Windows inicial y copiamos el archivo SocksOverRDPx64.zip  

- Necesitamos cargar  en el host pivote la DLL SocksOverRDP.dll

```
C:\..\SocksOverRDP-x64> regsvr32.exe SocksOverRDP-Plugin.dll
```
![[Pasted image 20260705125223.png]]

3. Nos conectamos via RDP al host pivote usando mstsc.exe

![[Pasted image 20260705125304.png]]


4. Pasamos el archivo SocksOverRDP-Server.exe al host objetivo y lo ejecutamos como administrador

![[Pasted image 20260705125349.png]]


5. Comprobamos en el host pivote que hay un SOCKS5 iniciado
![[Pasted image 20260705125427.png]]


6. Transferimos Proxifier al pivote y lo configuramos

![[Pasted image 20260705125530.png]]![[Pasted image 20260705125541.png]]

7. Una vez configurado nos podemos iniciar mstsc.exe para pivotar todo el trafico a traves de 127.0.0.1:1080 que lo tunelizara por RDP a el host objetivo que a su vez lo enrutara a el host pivote 

![[Pasted image 20260705130120.png]]


## Rendimiento
