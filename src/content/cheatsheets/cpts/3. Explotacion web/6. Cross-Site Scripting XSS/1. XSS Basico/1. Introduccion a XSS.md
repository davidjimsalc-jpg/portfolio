
Aprovechan la falla en la sanetizacion de la entrada para escribir codigo en JS en la pagina y ejecutarlo desde el lado del cliente

## Que es XSS

Las aplicaciones web funcionan recibiendo el codigo HTML del servidor backend y renderizandolo en el lado del cliente. Cuando una aplicacion web no sanetiza adecuadamente la entrada del usuario, este puede escribir codigo JS en el campo de entrada de modo que cuando alguien visite la pagina se ejecute este codigo

Solo afectan al lado del cliente, osea que solo afecta al usuario que ejecuta la vulnerabilidad

Puntuacion normal --> Bajo impacto + alta probabilidad = riesgo medio

## Ataques XSS

Pueden dar lugar a cualquier cosa que se pueda ejecutar con JS a traves del navegador

Ejemplo: el usuario que visite la pagina con XSS incrustrado envie las cookies de sesion a un servidor del atacante

Como esta limitado al JS dentro del navegador no se puede ejecutar JS en todo el sistema. En los navegadores modernos estan limitados al mismo dominio del sitio web
