
Es otro tipo de XSS no persistente basado en DOM

En el reflejado los datos se envian al backend a traves de solicitudes HTTP, pero en este se procesa completamente desde el lado del cliente a traves de JS

Ocurre cuando se usa JS para cambiar el codigo fuente de la pagina web a traves de DOM

## Fuente y sumidero

- Fuente: objeto JS que toma la entrada del usuario y puede ser cualquier parametro de entrada como un parametro URL o campo de entrada
- Sumidero: funcion que se escribe en la entrada de usuario en un objeto DOM. Si la funcion sumidero no se sanetiza adecuadamente, la entrada de usuario seria vulnerable a ataques XSS DOM

Funciones que se usan en XSS DOM:

- document.write()
- DOM.innerHTML
- DOM.outerHTML

Funciones jQuery que escriben en objetos DOM:

- add()
- after()
- append()

## Ataques DOM

Si metemos \<script>alert(window.origin)\</script> no funcionara ya que innerHTML no permite etiquetas \<script> dentro

Pero podemos usar:

```
<img src="" onerror=alert(window.origin)>
```

![[Pasted image 20260716113058.png]]


Para dirigirlo hacia otro usuario podemos mirar si es HTTP GET y enviar de nuevo la URL para que cuando la visiten se ejecute
