
Casi todos los escaneres de vulns como [Nessus](https://www.tenable.com/products/nessus), [Burp Pro](https://portswigger.net/burp/pro), o [ZAP](https://www.zaproxy.org/) tienen capacidades de deteccion de los 3 tipos de XSS. Estos suelen usar escaneres pasivos que revisan el codigo del lado del cliente en busca de vulns DOM y analisis activo que envia tipos de payloads para intentar desencadenar un XSS

En este caso usaremos XSS Strike:

```
git clone https://github.com/s0md3v/XSStrike.git
cd XSStrike
pip install -r requirements.txt
python xsstrike.py
```

Despues lo ejecutamos proporcionando la URL. En este caso vamos a probarlo con el Reflected XSS anterior que pasaba los parametros al backend a traves de una solicitud GET con los parametros en la URL

```
python xsstrike.py -u "URL"
```

Como vemos la herramienta identifico el parametro como vulnerable a XSS desde el primer payload. Debemos probar el payload manualmente para ver si funciona realmente


## Descubrimiento manual

Para encontrar XSS basicas sirven con un par de payloads, pero para XSS avanzadas se requiere de una gran habilidad de revision de codigo

#### Payloads XSS

El metodo mas basico es probar payloads XSS

Lista de payloads --> [PayloadAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings/blob/master/XSS%20Injection/README.md) o [Payload-Box](https://github.com/payload-box/xss-payload-list) 

Podemos ir probando uno por uno a ver si sale el cuadro de alerta aunque no es muy eficiente porque la mayoria no funcionan en nuestros casos ya que muchos estan hechos para saltarse medidas de seguridad, sanetizaciones, usar diferentes tipos de etiquetas... y nosotros estamos viendo lo mas basico


*DESTACAR QUE EL XSS PUEDE SER VULNERABLE EN CUALQUIER ENTRADA DE LA PAGINA YA SEAN ENTRADAS DEL HTML O CABECERAS HTTP COMO USERAGENT, COOKIE...*


Podriamos escribir nuestro propio script de python para automatizar el envio de payloads


#### Revision de codigo

Metodo mas fiable que debe cubrir tanto el front como el back

Es probable que los desarrolladores lancen escaneos de vulns a sus aplicaciones antes de su lanzamiento para parchear lo que se detecte pero una revision manual puede revelar vulnerabilidades
