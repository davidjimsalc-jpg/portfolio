## Tipo MIME

Estandar de internet que determina el tipo de archivo que es a traves de su formato y estructura de bytes

Se suele inspeccioanr los primeros bytes que contienen la [firma de archivo (_file signature_)](https://en.wikipedia.org/wiki/List_of_file_signatures) o los [bytes mágicos (_magic bytes_)](https://web.archive.org/web/20240522030920/https://opensource.apple.com/source/file/file-23/file/magic/magic.mime)

Ejemplo: aunque pongamos la extension .jpg sigue siendo un ASCII text

![[Pasted image 20260721193503.png]]

Pero si le ponemos primero la GIF8 se convierte en un GIF image data:

![[Pasted image 20260721193551.png]]


Esto se hace porque hay servidores que usan el estandar MIME para determinar los tipos de archivo lo que suele ser mas preciso que las extensiones:

![[Pasted image 20260721193633.png]]

Si tratamos de repetir el ataque de antes no dara ressultado porque interpretara que es un PHP:

![[Pasted image 20260721193721.png]]

Pero si le ponemos los bytes magicos de GIF8 si funcionara:

![[Pasted image 20260721193755.png]]![[Pasted image 20260721193801.png]]![[Pasted image 20260721193806.png]]


## Lista de bytes magicos

JPEG y JPG : FF D8 FF
PNG  : 89 50 4E 47 0D 0A 1A 0A
GIF  : 47 49 46 38 37 61
GIF  : 47 49 46 38 39 61
BMP  : 42 4D
WEBP : RIFF....WEBP
ICO  : 00 00 01 00
TIFF : 49 49 2A 00
TIFF : 4D 4D 00 2A

Si no funcionan podemos usar su version legible para humanos

JPEG y JPG : \xFF\xD8\xFF
PNG   : \x89PNG\r\n\x1A\n
GIF87 : GIF87a
GIF89 : GIF89a
BMP   : BM
WEBP  : RIFF....WEBP
ICO   : \x00\x00\x01\x00
CUR   : \x00\x00\x02\x00
TIFF  : II*\x00
TIFF  : MM\x00*
JP2   : \x00\x00\x00\x0CjP\x20\x20
HEIC  : ....ftypheic
AVIF  : ....ftypavif
SVG   : \<?xml ... <svg ...   (no tiene bytes mágicos fijos)
