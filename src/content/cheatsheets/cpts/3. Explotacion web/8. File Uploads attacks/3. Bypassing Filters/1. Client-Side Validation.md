Como es desde el lado del cliente podemos eludirla facilmente o modificar el codigo fuente

## Deshabilitar la validacion del frontend

Otro metodo es deshabilitar la validacion del frontend

1. Inspeccionar > Elements y vamos a la parte donde se encuentra el input de la imagen

![[Pasted image 20260721151509.png]]![[Pasted image 20260721151521.png]]

Pero esta parte es facilmente saltable al poder seleccionar All Files

2. Lo que nos interesa es el `checkFile(this)`. Console > escribimos checkFile y vemos la funcion. Esta revisa la extension de lo que se sube y si no es permitido salta un mensaje de que no esta permitido

![[Pasted image 20260721151748.png]]

3. Simplemente eliminamos la funcion volviendo al Inspect > Elements y dejamos el `onchange=""`

![[Pasted image 20260721151905.png]]

Tambien podriamos hacer lo mismo con el accept

	Estas modificaciones son temporales


4. Subimos el archivo. Vamos de nuevo al inspector o al codigo fuente y vemos el src de la img

![[Pasted image 20260721152020.png]]

5. Por ultimo visitamos el sitio web y usamos la webshell

![[Pasted image 20260721152115.png]]
