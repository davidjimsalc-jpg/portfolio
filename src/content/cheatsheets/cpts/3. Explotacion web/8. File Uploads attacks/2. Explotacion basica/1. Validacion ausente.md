## Identificacion del Framework Web

Para obtener una webshell o una reverse shell, estas deben estar escritas en el mismo lenguaje de programacion que ejecuta el servidor web

A veces suele ser relativamente facil ya que las mismas extensiones de las paginas web /index.php nos dicen que lenguaje permite

Hay frameworks y lenguajes que usan RUTA WEB para no mostrar la extension 


1. Metodo para identificar la extension: probar con /index.`extension:`

```
/index.extension
```

php, asp, aspx....


2. Usando [Wappalyzer](https://www.wappalyzer.com/)

![[Pasted image 20260721093218.png]]

Identifico el lenguaje, el servidor y su version, sistema operativo...


## Identificacion de la vulnerabilidad

Ahora que hemos identificado el lenguaje podemos probar la vulnerabilidad con un simple archivo en .php con el framework:

1. Creamos el archivo:

```
echo '<?php echo "Hello World!"; ?>' > test.php
```

![[Pasted image 20260721093454.png]]


2. Lo subimos correctamente por lo que la aplicacion no tiene validacion. Visitamos el directorio de /uploads/ y escribimos al ruta del archivo

```
http://IP:PORT/uploads/test.php
```

![[Pasted image 20260721093615.png]]
