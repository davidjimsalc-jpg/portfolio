
La mayoria de aplicaciones permiten funcionalidades de subida de archivos 

La razon mas comun detras de las vulns de subida de archivos es una validacion y verificacion de archivos debil que puede no estar bien asegurada

El peor tipo es la subida arbitraria de archivos sin autenticación: permite a una aplicacion web subir cualquier tipo de archivo 

Se suelen usar muchos filtros para validar la extension o el contenido de los archivos subidos

El ataque mas comun y critico es la obtencion de ejecucion remota de comandos del servidor backend mediante la subida de una reverse shell o webshell

Hay veces en las que solo podremos subir un tipo de archivos, aun asi hay ataques especificos para ello
