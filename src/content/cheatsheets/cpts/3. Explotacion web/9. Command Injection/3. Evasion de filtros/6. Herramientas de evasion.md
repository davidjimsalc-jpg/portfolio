
Es posible que nos encontremos con herramientas de seguridad muy avanzadas por lo que podemos usar herramientas automatizadas que nos ayuden

## Linux --> Bashfuscator

1. Instalacion

```
git clone https://github.com/Bashfuscator/Bashfuscator
cd Bashfuscator
pip3 install setuptools==65
python3 setup.py install --user
```

2. Uso

```
cd ~/HTB_Academy/Tools/Bashfuscator
source .venv/bin/activate

bashfuscator --help
deactivate
```
![[Pasted image 20260723154838.png]]

3. Pasamos el comando a ofuscar

```
./bashfuscator -c 'COMANDO'
```
![[Pasted image 20260723154911.png]]

El problema esta en que si la usamos asi, la herramienta elige la tecnica de ofuscacion lo que puede dar lugar a unos cientos de caracteres o mas de un millon

4. Usamos flags para que produzca un comando mas corto y simple

```
./bashfuscator -c 'cat /etc/passwd' -s 1 -t 1 --no-mangling --layers 1
```
![[Pasted image 20260723155056.png]]

5. Lo probamos en nuestra bash

```
bash -c 'COMANDO_OFUSCADO'
```
![[Pasted image 20260723155126.png]]


## Windows (DOSfuscation)

[DOSfuscation](https://github.com/danielbohannon/Invoke-DOSfuscation): esta es una herramienta interactiva

1. Instalacion:

```
git clone https://github.com/danielbohannon/Invoke-DOSfuscation.git
cd Invoke-DOSfuscation
```

2. Uso

```
Import-Module .\Invoke-DOSfuscation.psd1
Invoke-DOSfuscation
Invoke-DOSfuscation> help
```
![[Pasted image 20260723155411.png]]

3. Creacion de comandos ofuscados

```
SET COMMAND COMANDO
encoding
1
```
