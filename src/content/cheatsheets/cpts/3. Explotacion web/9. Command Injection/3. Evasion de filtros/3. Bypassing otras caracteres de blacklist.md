
Otros caracteres que suelen estar incluidos en listas negras son `/ o \` ya que son necesarios para especificar rutas


## Linux

Podemos usar variables del entorno y acortar su contenido para que muestren el caracter que queremos:


![[Pasted image 20260723143241.png]]

Si le ponemos una longitud del 0-1

```
echo ${PATH:0:1}
```
![[Pasted image 20260723143259.png]]

	En el payload no añadiremos echo

Se puede hacer lo mismo con otras variables como $HOME o $PWD

![[Pasted image 20260723143403.png]]


Vamos a usar el siguiente payload:

```
127.0.0.1${LS_COLORS:10:1}${IFS}
```

Que en realidad se veria:

```
127.0.0.1;ESPACIO
```

![[Pasted image 20260723143507.png]]

## Desplazamiento de caracteres

Linux:
1. Miramos la tabla ascii

```
man ascii
```

2. Si queremos \ esta en la posicion 92 despues de \[

```
echo $(tr '!-}' '"-~'<<<[)
```
![[Pasted image 20260723144033.png]]


Windows PS:

```
[char](([int][char]'[') + 1)
```
