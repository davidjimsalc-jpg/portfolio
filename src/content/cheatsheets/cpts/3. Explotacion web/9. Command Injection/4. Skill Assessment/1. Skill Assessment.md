
Nos encontramos con una aplicacion de gestion de archivos. Estos suelen ejecutar comandos en el host

Usa diversas tecnicas para detectar la vulnerabilidad de inyeccion de comandos y luego explotarla

Cual es el contenido de /flag.txt
