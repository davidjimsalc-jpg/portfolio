
## Instalacion

[Repositorio de GitHub](https://github.com/ffuf/ffuf.git)

o 

```
apt install fuff -y
```
## Directorios

1. Tenemos un sitio web como objetivo, no tiene enlaces ni da informacion de mas paginas

![[Pasted image 20260707131907.png]]

2. Hacemos fuzzing para encontrar directorios que nos devuelvan un 200 OK usando wordlists de [SecLists](https://github.com/danielmiessler/SecLists) 

```
/use/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt
```

-ic: en fuff quita las lineas de comentarios que vienen con las wordlists
-t N: numero de threads (si es muy alto puede generar DoS)


```
ffuf -w /RUTA/WORDLIST:FUZZ -u http:IP:PORT/FUZZ -ic -t 200
```
