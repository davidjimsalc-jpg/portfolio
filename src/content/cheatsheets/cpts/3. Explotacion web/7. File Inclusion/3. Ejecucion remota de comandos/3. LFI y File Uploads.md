
La mayoria de aplicaciones permiten la subida de archivos para multitud de cosas

En este ataque simplemente necesitamos que nos deje subir archivos que la funcion `Execute` este habilitada para ejecutar codigo independientemente del tipo de extension

Ejemplo: subir un image.jpg con un webshell en PHP dentro y si lo incluimos a traves de un LFI, el codigo PHP lo ejecutara

Las siguientes funciones son las que permiten ejecutar codigo con la LFI:

![[Pasted image 20260719195444.png]]


## Carga de imagenes

Usaremos la extension de imagen permitida por la pagina web y bytes magicos al principio del contenido del archivo

![[Pasted image 20260719195722.png]]


Subimos el archivo añadiendolo a Profile Settings como foto de perfil:

![[Pasted image 20260719195838.png]]

Si miramos el codigo fuente podemos ver la ruta donde se ha almacenado:

![[Pasted image 20260719195909.png]]

Ahora la visitamos y ejecutamos comandos:

```
http://IP:PORT/index.php?language=./profile_images/shell.gif&cmd=id
```
![[Pasted image 20260719195937.png]]


## Carga de un ZIP

![[Pasted image 20260719200009.png]]

```
http://IP:PORT/index.php?language=zip://./profile_images/shell.jpg%23shell.php&cmd=id
```

![[Pasted image 20260719200110.png]]


## PHP Wrapper Phar

Pdemos lograr algo parecido usando `phar://`. Escribimos el siguiente script PHP en un archivo shell.php:

![[Pasted image 20260719200312.png]]

Compilamos el archivo en un phar que al ser llamado escribira el webshell en un subarchivo llamado shell.txt. El archivo phar lo renombramos como jpg:

![[Pasted image 20260719200413.png]]

```
http://IP:PORT/index.php?language=phar://./profile_images/shell.jpg%2Fshell.txt&cmd=id
```
![[Pasted image 20260719200500.png]]



Tanto ZIP como PHAR deben ser metodos alternativos si el primero no funciona
