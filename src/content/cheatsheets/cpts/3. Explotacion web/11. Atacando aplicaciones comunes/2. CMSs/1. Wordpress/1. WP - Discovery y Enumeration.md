
[WordPress](https://wordpress.org/) es un CMS de codigo abierto que se usa para multiples propositos (alojar blogs, foros...)

Suele ser vulnreable a traves de temas y plugins. Suele estar escrito en PHP y usar Apache + MySQL


## Descubrimiento y Footprinting


1. Una forma rapida suele ser mirar /robots.txt donde habra rutas de wp:

![[Pasted image 20260726154429.png]]

La presencia de /wp-admin y /wp-content es una señal inequivoca de WP


2. Podemos navegar a /wp-admin a ver si existe. Este nos redigira a wp-login.php que es el portal de inicio de sesion de WP:

![[Pasted image 20260726154520.png]]


3. WP almacena los plugins en /wp-content/plugins y los temas en /wp-content/themes. Estos pueden ser vulnerables y llevar a RCE


#### Tipos de usuarios en WP

Hay 5 tipos:

- Administrator: tiene acceso a funciones adminsitrativas dentro del sitio web. Añadir y eliminar usuarios y publicaciones, editar codigo fuente...
- Editor: puede publicar y gestionar publicaciones incluidas la de otros usuarios
- Autor: puede publicar y gestionar sus propias publicaciones
- Colaborador: el usuario puede escribir y gestionar sus publicaciones pero no puede publicarlas
- Suscriptor: usuario estandar que puede navegar por las publicaciones y editar sus perfiles

## WPScan

[WPScan](https://github.com/wpscanteam/wpscan) es un escaner y herramienta de enumeracion automatizada de WP

Nos mostrara los diversos temas y plugins desactualizados o son vulnerables instalados en el CMS

```
sudo gem install wpscan
```

```
wpscan -h
```
![[Pasted image 20260726160418.png]]

```
sudo wpscan --url URL --enumerate -t N
```
![[Pasted image 20260726160452.png]]


Mostro varios hallazgos como: 

- Versión 5.8 del núcleo de WordPress y listado de directorios habilitado
- Transport Gravity, que es un tema hijo de Business Gravity
- Descubrió otro nombre de usuario (john)

Pero:

- Pasó por alto los plugins wpDiscuz y Contact Form 7


## Datos recopilados que deberiamos apuntar

- El sitio está ejecutando la versión 5.8 del núcleo de WordPress, que sufre de algunas vulnerabilidades que no parecen interesantes en este momento.
- El tema instalado es Transport Gravity.
- Se utilizan los siguientes plugins: Contact Form 7, mail-masta, wpDiscuz.
- La versión de wpDiscuz es 7.0.4, que sufre de una vulnerabilidad de ejecución remota de código no autenticada.
- La versión de mail-masta es 1.0.0, que sufre de una vulnerabilidad de Inclusión de Archivos Locales, así como de inyección SQL (SQL injection).
- El sitio de WordPress es vulnerable a la enumeración de usuarios, y se confirma que los usuarios `admin` y `john` son usuarios válidos.
- El listado de directorios está habilitado en todo el sitio, lo que puede llevar a una exposición de datos sensibles.
- XML-RPC está habilitado, lo que puede ser aprovechado para realizar un ataque de fuerza bruta de contraseñas contra la página de inicio de sesión utilizando WPScan, [Metasploit](https://www.rapid7.com/db/modules/auxiliary/scanner/http/wordpress_xmlrpc_login), etc.
