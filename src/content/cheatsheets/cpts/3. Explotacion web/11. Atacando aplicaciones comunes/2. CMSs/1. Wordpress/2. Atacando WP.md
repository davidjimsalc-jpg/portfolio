## Fuerza bruta de inicio de sesion

Con WPScan vimos que `XML-RPC  estaba activado` lo que nos permite hacer fuerza bruta. Ademas encontramos a los usuario `admin y doug`

WPScan tiene varios metodos de fuerza bruta:

- wp-login: intenta forzar el inicio de sesion estandar de WP
- xmlrpc: usa una API de WP para realizar intentos de inicio de sesion atraves de /xmlrpc.php (es mas rapido)

```
sudo wpscan --password-attack xmlrpc -t 20 -U USER -P /usr/share/wordlists/rockyou.txt --url http://blog.inlanefreight.local
```
