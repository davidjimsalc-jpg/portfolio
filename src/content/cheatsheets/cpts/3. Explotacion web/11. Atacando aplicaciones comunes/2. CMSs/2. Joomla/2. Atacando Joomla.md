## Aprovechando vulns conocidas

La version de Joomla 3.9.4 esta desactualizada. Buscando un poco encontramos [CVE-2019-10945](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2019-10945), que es una vulnerabilidad de directory traversal y  eliminación de archivos autenticada


Usaremos este [script](https://www.exploit-db.com/exploits/46710) para explotarlo y listar el conetenido de webroot y otros directorios

La version Python3 del script --> [aquí](https://github.com/dpgg101/CVE-2019-10945)


- Version Python2.7:

```
python2.7 joomla_dir_trav.py --url "http://dev.inlanefreight.local/administrator/" --username admin --password admin --dir /
```
