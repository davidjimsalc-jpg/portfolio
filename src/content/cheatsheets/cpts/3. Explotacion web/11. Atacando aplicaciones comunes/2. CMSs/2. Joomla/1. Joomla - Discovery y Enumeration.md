
[Joomla](https://www.joomla.org/) es un CMS que se suele usar para foros de discusion, galerias de fotos e e-Commerce


## Descubrimiento y Footprinting

Imaginemos que estamos frente a un e-Commerce no del todo personalizado y no sabemos exactamente que tecnologia usa

Asumimos que es Joomla pero lo debemos confirmar:

1. Miramos en el codigo fuente:

```
curl -s http://dev.inlanefreight.local/ | grep Joomla
```
![[Pasted image 20260726175602.png]]

2. Tambien podemos mirar en /robots.txt

![[Pasted image 20260726175630.png]]


3. Nos podemos fijar en el favicon de Joomla
4. Podemos leer el readme.txt

```
curl -s http://dev.inlanefreight.local/README.txt | head -n 5
```
![[Pasted image 20260726175723.png]]

5. Tambien podemos mirar archvios del directorio de JS `/media/system/js/` o en `/administrator/manifests/files/joomla.xml`

```
curl -s http://dev.inlanefreight.local/administrator/manifests/files/joomla.xml | xmllint --format -
```
![[Pasted image 20260726175903.png]]

6. Por ultimo podemos ver `plugins/system/cache/cache.xml` que nos puede dar una version aproximada

```
curl -s http://dev.inlanefreight.local/plugins/system/cache/cache.xml | xmllint --format -
```
![[Pasted image 20260726181749.png]]

## Fuerza bruta

La cuenta de admin default es `admin` y la contraseña se cambia a la hora de la instalacion, por lo que nuestra oportunidad esta en que la credencial sea debil

Podemos usar este [script](https://github.com/ajnik/joomla-bruteforce) para la fuerza bruta:

```
sudo python3 joomla-brute.py -u http://dev.inlanefreight.local -w /usr/share/metasploit-framework/data/wordlists/http_default_pass.txt -usr admin
```
