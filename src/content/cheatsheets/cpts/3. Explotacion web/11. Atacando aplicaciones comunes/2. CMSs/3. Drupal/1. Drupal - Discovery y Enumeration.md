
[Drupal](https://www.drupal.org/) CMS popular entre empresas y desarrolladores escrito en PHP y compatible con MySQL o PostgreSQL

Usa temas y modulos


## Descubrimiento y Footprinting

Revisando el sitio web sabemos que el CMS no es ni WP ni Joomla

1. Podemos leer el encabezado

```
curl -s http://drupal.inlanefreight.local | grep Drupal
```
![[Pasted image 20260726192357.png]]

2. Mirar el favicon
3. Buscar CHANGELOG.txt o README.txt

4. A traves de [nodos](https://www.drupal.org/docs/8/core/modules/node/about-nodes). Drupal indexa su contenido usando nodos que puede contener cualquier cosa como una entrada de blog, una encuesta, un articulo... `URL/node/ID`

![[Pasted image 20260726192530.png]]

![[Pasted image 20260726192559.png]]


#### Tipos de usuario

- Administrator: tiene control total sobre la web Drupal
- Authenticated User: pueden iniciar sesion en el sitio web y realizar operaciones como añadir y editar articulos en funcion de sus permisos
- Anonymous: los visitantes del sitio web. Solo le permite leer publicaciones
