2. Metemos en /etc/hosts las apliaciones

```
IP=IP_host
print "%s\t%s\n\n" "$IP" "sub1.domain.local sub2.domain.local sub3.domain.local" | sudo tee -a /etc/hosts
cat /etc/hosts
```

![[Pasted image 20260726134848.png]]

3. Miramos a ver si ha funcionado el /etc/hosts

![[Pasted image 20260726134917.png]]

4. Creamos una lista para pasarsela a nmap

```
cd nmap/
nano list.txt
```
![[Pasted image 20260726135121.png]]

5. Creamos un directorio para los archivos nmap y hacemos un escaneo de puertos abiertos y de versiones que guardaremos en todos los formatos. Nos interesa el XML

```
sudo nmap -Pn -sS -sV --open -oA webnamp -iL list.txt
```
![[Pasted image 20260726135258.png]]

6. Usamos EyeWitness para que saque capturas, informacion, nos los clasifique y nos diga posibles credenciales default

```
eyewitness --web -x web_discovery.xml -d inlanefreight_eyewitness
```
![[Pasted image 20260726135539.png]]![[Pasted image 20260726135555.png]]

8. Tendremos creadas en Obsidian las siguientes carpetas:

- `Alcance` (incluyendo direcciones/rangos IP dentro del alcance, URLs, cualquier host frágil, plazos de prueba y cualquier limitación u otra información relativa que necesitemos tener a mano)
- `Puntos de Contacto del Cliente`
- `Credenciales`
- `Descubrimiento/Enumeración`
    - `Escaneos`
    - `Hosts activos`
- `Descubrimiento de Aplicaciones`
    - `Escaneos`
    - `Hosts Interesantes/Notables`
- `Explotación`
    - `<Nombre de host o IP>`
    - `<Nombre de host o IP>`
- `Postexplotación`
    - `<Nombre de host o IP>`
    - `<Nombre de host o IP`
