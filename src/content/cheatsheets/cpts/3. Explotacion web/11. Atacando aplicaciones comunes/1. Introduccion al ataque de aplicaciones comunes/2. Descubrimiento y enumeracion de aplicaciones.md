
Ciertas aplicaciones tienen portales administrativos que pueden restringirse para que solo sean accesibles desde direcciones IP específicas o desde el propio host (localhost)

La realidad es que muchas organizaciones no conocen todo lo que hay en su red, y algunas organizaciones tienen muy poca visibilidad


#### Nmap - Descubrimiento web

```
sudo nmap -Pn -sS --open -p 80,443,8000,8080,8180,8888,10000 -oA web_directory -iL ip_list
```
![[Pasted image 20260726125034.png]]

Revisar los datos de la enumeracion manualmente llevaria mucho tiempo

Usaremos herramientas para ayudarnos a revisar esta enumeracion:

- [EyeWitness](https://github.com/FortyNorthSecurity/EyeWitness) 
- [Aquatone](https://github.com/michenriksen/aquatone)

Ambas se alimentan con la salida XML del nmap. Estas aplicaciones revisaran las paginas y haran capturas de pantalla que meteran en un informe para ayudarnos a saber cuales estan activas y demas

Con esto podemos construir una lista mas especifica de que aplicaciones dedicar mas tiempo y enumerar para atacar


## Organizarse

Primero dividimos un Obsidian en las siguientes carpetas:

- `Alcance` (incluyendo direcciones/rangos IP dentro del alcance, URLs, cualquier host frágil, plazos de prueba y cualquier limitación u otra información relativa que necesitemos tener a mano)
- `Puntos de Contacto del Cliente`
- `Credenciales`
- `Descubrimiento/Enumeración`
    - `Escaneos`
    - `Hosts activos`
- `Descubrimiento de Aplicaciones`
    - `Escaneos`
    - `Hosts Interesantes/Notables`
- `Explotación`
    - `<Nombre de host o IP>`
    - `<Nombre de host o IP>`
- `Postexplotación`
    - `<Nombre de host o IP>`
    - `<Nombre de host o IP`

	- Enumeracion

#### EyeWitness

Puede tomar la salida XML tanto de Nmap como de Nessus para crear un informe de capturas de pantalla de cada aplicacion web presente

Tambien categorizara las aplicaciones cuando sea posible, hara footprinting y sugerira credenciales default


```
sudo apt install eyewitness
```

![[Pasted image 20260726131854.png]]![[Pasted image 20260726131909.png]]


```
eyewitness --web -x web_discovery.xml -d inlanefreight_eyewitness
```
![[Pasted image 20260726132002.png]]


#### Aquatone

[Aquatone](https://github.com/michenriksen/aquatone) es similar a Eyewitness y puede tomar capturas de pantalla cuando se le proporciona un .txt de hosts o un .xml de Nmap 

```
wget https://github.com/michenriksen/aquatone/releases/download/v1.7.0/aquatone_linux_amd64_1.7.0.zip
```

```
unzip aquatone_linux_amd64_1.7.0.zip
```

Lo movemos a uno de los directorios de `$PATH` para que se pueda ejecutar desde cualquier directorio

![[Pasted image 20260726132251.png]]
```
mv aquatone /usr/local/bin
```


```
cat web_discovery.xml | ./aquatone -nmap
```
