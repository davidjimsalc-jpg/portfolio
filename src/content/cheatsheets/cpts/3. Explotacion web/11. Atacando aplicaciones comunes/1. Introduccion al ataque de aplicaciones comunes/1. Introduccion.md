## Objetivo del modulo

Usaremos Vhosts para simular un entorno grande y realista con multiples servidores web

Dado que los vhosts se mapean en un directorio diferente en el mismo host tendremos que ir añadiendo entradas a `/etc/hosts`

1. Añadir entradas rapidamente a /etc/hosts

```
IP=IP_host
print "%s\t%s\n\n" "$IP" "sub1.domain.local sub2.domain.local sub3.domain.local" | sudo tee -a /etc/hosts
cat /etc/hosts
```
