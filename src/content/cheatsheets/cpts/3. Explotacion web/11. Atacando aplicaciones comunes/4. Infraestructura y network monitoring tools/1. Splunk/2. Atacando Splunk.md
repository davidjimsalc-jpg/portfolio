
Podemos obtener ejecución remota de código (RCE) en Splunk creando una aplicación personalizada para ejecutar scripts de Python, Batch, Bash o PowerShell

La maquina vimos que es un Windows tras el escaneo de nmap


## Abusando de la funcionalidad incorporada

[Paquete Splunk](https://github.com/0xjpuff/reverse_shell_splunk): dentro de /bin hay un repositorio que tiene ejemplos de Python y Powershell para ayudarnos


Primero tenemos que crear una aplicacion personalizada de Splunk usando su estructura de directorios:

![[Pasted image 20260727141738.png]]

- /bin: contiene un .ps1, .py y .bat

En el directorio `/bin` pondremos el script que queremos ejecutar (en este caso un .ps1 con una shell inversa de PowerShell) 

	Usaremos un reverse shell de Powershell de una linea basico que podemos montar con msfvenom o buscar en PayloadAllTheThings
	
![[Pasted image 20260727141850.png]]


**SI FUERA UN LINUX PONDRIAMOS LO SIGUIENTE EN EL ARCHIVO .PY**

![[Pasted image 20260727142720.png]]


En el .bat pondremos que se ejecutara cuando la aplicacion se despliegue y ejecutara el PS1

![[Pasted image 20260727142222.png]]


- /deafult: 

El archivo `inputs.conf` le dice a Splunk que ejecutar:

```
[script://./bin/rev.py] 
disabled = 0 
interval = 10 
sourcetype = shell 
[script://.\bin\run.bat] 
disabled = 0 
sourcetype = shell 
interval = 10
```

Lo comprimimos:

```
tar -cvzf updater.tar.gz splunk_shell/
```

## Pivotar con Splunk

Splunk puede estar desplegado en varios hosts que tengan instalados `Universal Forwarders`. Para enviar una reverse shell a todos estos debemos colocar la aplicacion creada en el directorio:

- `$SPLUNK_HOME/etc/deployment-apps`

En un entorno donde la mayoria sean Windows, debemos usar PS1 porque `Universal Forwarders` no se instala con Python
