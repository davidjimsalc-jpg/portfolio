
Splunk es una herramienta de análisis de logs que se utiliza para recopilar, analizar y visualizar datos

Los despliegues de Splunk se usan con frecuencia para albergar datos sensibles y podrían proporcionar una gran cantidad de información a un atacante si se vieran comprometidos

## Descubrimiento y Footprinting

A menudo se ejecuta como root en sistemas Linux o como SYSTEM en sistemas Windows

Aunque poco comun, a veces podemos encontrarnos un Splunk expuesto externamente con una instancia olvidada

## Enumeracion

La version de prueba de Splunk Enterprise se convierte en una version gratuita la pasar 60 dias que no requiere autenticacion

Los desarrolladores pueden coger una de prueba y luego coger una enterprise y olvidarse de ella y hay organizaciones que optan por las versiones gratuitas

![[Pasted image 20260727140215.png]]

Una vez iniciado sesion en Splunk o accedido a una instancia gratuita podemos explorar los datos, ejecutar informes, crear dashboards...

![[Pasted image 20260727140303.png]]

Splunk tiene múltiples formas de ejecutar código, como aplicaciones Django del lado del servidor, endpoints REST, entradas programadas (scripted inputs) y scripts de alerta. Un método común para obtener ejecución remota de código en un servidor Splunk es mediante el uso de una entrada programada. Estas están diseñadas para ayudar a integrar Splunk con fuentes de datos como APIs o servidores de archivos

 Las entradas programadas están pensadas para ejecutar estos scripts, proporcionando la salida estándar (STDOUT) como entrada para Splunk.
 
Como Splunk se puede instalar en hosts Windows o Linux, se pueden crear entradas programadas para ejecutar scripts de Bash, PowerShell o Batch

 Además, cada instalación de Splunk viene con Python instalado, por lo que los scripts de Python pueden ejecutarse en cualquier sistema Splunk. Una forma rápida de obtener RCE es creando una entrada programada que le indique a Splunk que ejecute un script de Python para una shell inversa
