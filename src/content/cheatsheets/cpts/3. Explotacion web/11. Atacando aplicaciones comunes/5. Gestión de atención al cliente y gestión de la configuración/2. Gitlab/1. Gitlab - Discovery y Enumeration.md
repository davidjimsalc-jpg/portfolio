
[GitLab](https://about.gitlab.com/) es una herramienta de alojamiento de repositorios Git basada en la web que proporciona capacidades de wiki, seguimiento de incidencias y funcionalidad de pipeline de integración y despliegue continuo

GitLab es similar a GitHub y BitBucket

Estos repositorios son simplemente codigo disponible publicamente como scripts para interactuar con APIs
Podemos tambien encontrar scripts o archivos de configuracion, claves privadas SSH, usuarios, credenciales

Gitlab permite:
- Repositorios publicos que no requieren de autenticacion
- Repositorios internos disponibles para usuarios autenticados
- Repositorios privados restringidos a usuarios especificos

Normalmente solo se permite que un usuario con direccion de correo electronico publica se registre y requerira la autorizacion de un admin (aunque hay veces que no)

## Footprinting y Descubrimiento

Navegando a la URL de Gitlab seremos directamente redirigidos a su inicio de sesion que muestra el logo de Gitlab:

![[Pasted image 20260727201530.png]]

Para identificar la version tenemos que iniciar sesion e ir a `/help`

1. Podemos tratar de registrar una cuenta nueva
2. Sino podriamos lanzar un script de bajo riesgo como el siguiente: [script](https://www.exploit-db.com/exploits/49821)

1. Una vez iniciado sesion podemos ir a `/explore` y ver si hay proyectos publicos. Encontramos `Inlanefreight dev`
