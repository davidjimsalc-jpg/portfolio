
Las aplicaciones que se conectan a servicios suelen tener codigo de conexion que pueden filtrarse si no estan protegidas y pueden contener credenciales para permitirnos movernos lateralmente


## Evaluacion de un ejecutable ELF

El binarion elf `octopus_checker` se encuentra en una maquina remota durante la prueba. Al ejecutarlo localmente revela que se conecta a instancias de BBDD para verificar que esten disponibles

![[Pasted image 20260730124201.png]]

Probablemente se conecta usando una cadena de conexion SQL que contiene credenciales

Usando herramientas como [PEDA](https://github.com/longld/peda) (gbd) podemos examinar el archivo mas a fondo (sirve para programas en C y C++)

Permite recorrer el codigo paso a paso, establecer puntos de interrupcion (breakpoints) y cambiar variables en ese punto

![[Pasted image 20260730124417.png]]

Una vez que esta cargado, establecemos el `disassemby-flavor` (define el estilo de la visualizacion del codigo). Despues desamblamos la funcion principal main:

```
set disassembly-flavor intel
disas main
```
![[Pasted image 20260730124628.png]]

Vemos cadenas call que apuntan a registros que contienen cadenas de texto. Estas no estan en orden y el endianness (define el orden en el que se leen los bytes dependiendo de la arquitectura) implica que la cadena de texto esta invertida

Vemos una cadena de `SQLDriverConnect`:

![[Pasted image 20260730124911.png]]


Añadimos un breakpoint en esa direccion y volvemos a ejecutar el programa, revelando una conexion de SQL en la direccion del RDX que contiene las credenciales de la BBDD local:

```
b *main+N  (N=433 en este caso)
run
```

![[Pasted image 20260730125043.png]]


## Evaluacion de un archivo DLL

Un archivo DLL es una biblioteca de enlace dinamico y contiene codigo que es llamado desde otros programas

Tenemos el binario MultimasterAPI.dll que se encuentra en la maquina remota para su evaluacion

Al ejecutarlo revela que se trata de un ensamblado .NET:

![[Pasted image 20260730125430.png]]

Usando [dnSpy](https://github.com/0xd4d/dnSpy) podemos ver el codigo fuente directamente

	MultimasterAPI.Controllers -> ColleagueController

Revela una cadena de conexion a la BBDD que contiene la contraseña:

![[Pasted image 20260730125558.png]]
