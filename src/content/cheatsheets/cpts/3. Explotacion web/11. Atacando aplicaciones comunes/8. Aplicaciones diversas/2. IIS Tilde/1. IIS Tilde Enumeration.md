
Es una tecnica usada para descubrir archivos, directorios y nombres de archivos ocultos conocidos como formato 8.3 aprovechando una vulnerabilidad de IIS

Cuando se crea un archivo o carpeta en IIS se genera un nombre archivo en formato 8.3 o corto que consta de 8 caracteres que dan acceso a sus archivos o carpetas originales correspondientes

	~NUMEROS_8CARACTERES = FORMATO 8.3


#### Explicacion enumeracion

La enumeracion se basa en el envio de solicitudes HTTP con distintas combinaciones de caracteres para identificar nombres cortos validos para poder acceder a los recursos

## Enumeracion

1. Identificamos los puertos y servicios abiertos:

![[Pasted image 20260730110513.png]]

IIS 7.5 se está ejecutando en el puerto 80


2. Enumeracion de tilde con IIS ShortName Scanner

[IIS-ShortName-Scanner](https://github.com/irsdl/IIS-ShortName-Scanner): herramienta para enviar solicitudes HTTP para cada letra esperando un 200OK

```
java -jar iis_shortname_scanner.jar 0 5 http://10.129.204.231/
```
![[Pasted image 20260730110648.png]]

Se descubren 2 directorios y 3 archivos


El problema esta en que no nos permite acceder mediante GET a `http://10.129.204.231/TRANSF~1.ASP` por lo que tendremos que hacer fuerza bruta para el resto del archivo


3. Generamos una wordlist de palabras que empiecen por transf

```
egrep -r ^transf /usr/share/wordlists/* | sed 's/^[^:]*://' > /tmp/list.txt
```

- egrep -r \^transf: egrep busca linea que contengan el patron que comience por trans. -r hace una busqueda recursiva
- sed 's/\^\[^:]\*://': busca cualquier sentencia de caracteres al principio de la linea hasta que haya : y los reemplace por nada haciendo que sean lineas que empiecen por trans


4. Enumeramos con gobuster

```
gobuster dir -u http://10.129.204.231/ -w /tmp/list.txt -x .aspx,.asp
```
