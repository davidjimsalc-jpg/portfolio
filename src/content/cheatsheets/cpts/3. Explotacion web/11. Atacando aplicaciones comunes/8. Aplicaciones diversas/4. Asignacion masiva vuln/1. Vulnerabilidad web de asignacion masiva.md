
Las funciones de asignacion masiva sirven para disminuir la carga de trabajo de los desarrolladores. Debido a esto los programadores pueden insertar directamente un conjunto completo de datos introducidos por el usuario desde un formulario en un objeto o base de datos

Se suele usar sin una whitelist para proteger los campos de entrada del usuario permitiendo aprovecharlo para robar informacion sensible o destruir datos

Se modifican los atributos del modelo de una aplicacion a traves de los parametros enviados al servidor
Mediante ingenieria inversa del codigo, se pueden ver estos parametros y asignar valores a parametros ciriticos no protegidos durante la solcitud HTTP
