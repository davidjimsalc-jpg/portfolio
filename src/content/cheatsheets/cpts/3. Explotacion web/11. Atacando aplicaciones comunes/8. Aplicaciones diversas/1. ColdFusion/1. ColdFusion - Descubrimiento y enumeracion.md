
ColdFusion es un lenguaje de programación y una plataforma de desarrollo de aplicaciones web basada en Java

Se utiliza para construir aplicaciones web dinámicas e interactivas que pueden conectarse a diversas API y bases de datos como MySQL, Oracle y Microsoft SQL Server

Tiene una sintaxis similar a HTML. Incluye etiquetas y funciones para la integración de bases de datos, servicios web, gestión de correo electrónico y otras tareas

## Enumeracion

- Por enumeracion de puertos
- Por extension de archivos .cfm o .cfc
- Por cabeceras de solicitudes HTTP en `Server: ColdFusion` o `X-Powered-By: Coldfusion`
- Mensajes de error que pueden tener referencias a coldfusion
- Archivos por defecto como `admin.cfm` o `CFIDE/administrator/index.cfm`
