## Salto de directorio/ Path traversal

Nos permite acceder a archivos y y salir fuera del directorio previsto por la aplicacion explotando la falta de validacion de entradas en una aplicacion web y puede ejecutarse a traves de varios campos de entrada de usuario (parametros GET, campos de form, cookies...)

Al manipularlos podemos recorrer la estructura de directorios y acceder a archivos sensibles

Este ataque manipula los parametros de entrada de las etiquetas CFFile y CFDIRECTORY que se usan para operaciones de archivos y directorios

![[Pasted image 20260729152300.png]]

Vemos que en este fragmento la etiqueta cfdirectory lista el contenido del directorio uploads 
La etiqueta cfloop se usa para iterar los resultados de la consulta y motstrar los nombres de archivos en los enlaces clicables

El problema esta en que el parametro directory en cfdirectory que se encaga de listar los contenido del `uploads/` no valida ni sanetiza su entrada por lo que podriamos ponerL

`?directory=../../../etc&file=passwd`

Quedando --> `/uploads/../../../etc/passwd`

La vuln CVE-2010-2861 encontrada en searchsploit se puede explotar sobre los siguientes directorios vulnerables de la version 9.0.1 a versiones anteriores:

- `CFIDE/administrator/settings/mappings.cfm`
- `logging/settings.cfm`
- `datasources/index.cfm`
- `j2eepackaging/editarchive.cfm`
- `CFIDE/administrator/enter.cfm`

La vulnerabilidad explota el paremtro GET `locale`:

![[Pasted image 20260729152919.png]]

Es probable que el paremetro locale=en hace que se muestre el archivo en ingles de mappins.cfm localizado en alguna parte del webroot. Si ponemos ../ podemos explotarlo:

![[Pasted image 20260729153043.png]]


Vamos a usar el exploit de MSF:

```
searchsploit -p 14641
```
![[Pasted image 20260729153120.png]]

```
cp /usr/share/exploitdb/exploits/multiple/remote/14641.py .
python2 14641.py
```
![[Pasted image 20260729153145.png]]

	password.properties es un archivo de ColdFusion que alamcena credenciales cifradas de varios servicios usados por ColdFusion en una lista k:v
	Se usan para conexiones a BBDD, servidores de correo, servidores LDAP...
	Suele estar en /lib/

python2 14641.py IP PUERTO "../../../../../../../../ColdFusion8/lib/password.properties"

## RCE no autenticado

Nos permite ejecutar codigo arbitrario en un sistema vulnerable sin necesidad de autenticacion

En el contexto de ColdFusion este ataque puede ocurrir cuando una aplicacion web permite la ejecucion de codigo a traves de una caracteristica o funcion que no requiere autenticacion (ejemplos, consola de depuracion, funcionalidad de carga de archivos...):

![[Pasted image 20260729153727.png]]

Como vemos en el codigo cmd sera la concatenacion de:

```
/c + comando(en parametro cgi.query_string)
```

Este comando sera ejecutado por cfexecute usando una cmd y no se valida bien la entrada de cmd antes de ejecutarse

Ejemplo:

![[Pasted image 20260729154011.png]]

Como vemos usa `;` al principio de la consulta para ejecutar multiples comandos


La vuln encontrada en searchsploit CVE-2009-2265 afecto a la version 8.0.1 y anteriores permitiendo de forma no autenticada cargar archivos y obtener ejecucion remota de comandos:

![[Pasted image 20260729154228.png]]


Lo copiamos en el directorio de trabajo:

```
searchsploit -p 50057
```
![[Pasted image 20260729154306.png]]

```
cp /usr/share/exploitdb/exploits/cfm/webapps/50057.py .
```
![[Pasted image 20260729154321.png]]

Corregimos el contenido del exploit con nuestros datos:

![[Pasted image 20260729154350.png]]

Lo explotamos:

python3 50057.py
