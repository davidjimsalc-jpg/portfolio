
LDAP es un protocolo usado para acceder y gestionar informacion de directorios que contienen informacion de recursos de red como usuarios, grupos, ordenadores, impresoras...

Se usa comunmente para proporcionar una ubicacion central para acceder y gestionar servicios de directorio permitiendo almacenar, gestionar y proteger esta informacion de forma estandarizada

2 implementaciones de LDAP:

- OpenLDAP: open source 
- Microsoft AD: implementacion basada en Windows

Aunque LDAP y AD estan relacionados sirven para cosas diferentes:

- LDAP: protocolo que especifica el metodo para acceder y modificar servicios de directorio
- AD: servicio de directorio que almacena y gestiona datos de usuarios y ordenadores que ofrece ademas funcionalidades de politicas, inicios de sesion e integracion con diversos productos de Microsoft


Funcionamiento LDAP cliente-servidor:

- Un cliente envia una solicitud LDAP a un servidor
- Este busca en el AD y devuelve una respuesta al cliente

Componentes de una solicitud:

- Conexion de sesion: puertos 389 o 636
- Tipo de solicitud: operacion del cliente
- Parametros de la solicitud: informacion para la solicitud como nombre distinguido
- ID de la solicitud

Componentes respuesta:

- Tipo de respuesta: indica la operacion que se realizo
- Codigo de resultado: si tuvo exito o no
- DN coincidiente: devuelve el DN de la entrada
- Referencia: una URL de otro servidor que puede tener mas info sobre la solicitud
- Datos de la respuesta


## Ldapsearch

Utilidad que se usa para buscar informacion almacenada en un directorio mediante el protocolo LDAP:

```
ldapsearch -H ldap://ldap.example.com:389 -D "cn=admin,dc=example,dc=com" -w secret123 -b "ou=people,dc=example,dc=com" "(mail=john.doe@example.com)"
```

- Se conecta a ldap.example.com por el puerto 389
- Se autentica como (cn=admin, en el dominio dc=exameple dc=com) con la contraseña secret123
- Busca bajo el DN ou=people en el dominio dc=example dc=com
- Usa el filtro `mail=john.dow@example.com` para encontrar la entrada con esa direccion

## Enumeracion

Con nmap:

![[Pasted image 20260730114640.png]]

nmap detecta un servidor `http` ejecutándose en el puerto `80` y un servidor `ldap` ejecutándose en el puerto `389`

Como `OpenLDAP` se ejecuta en el servidor, es seguro asumir que la aplicación web que se ejecuta en el puerto `80` utiliza LDAP para la autenticación

Intentar iniciar sesión utilizando un carácter comodín (`*`) en los campos de nombre de usuario y contraseña concede acceso al sistema
