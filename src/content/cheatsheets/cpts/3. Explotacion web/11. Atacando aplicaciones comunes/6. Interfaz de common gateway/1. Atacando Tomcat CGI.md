
scritps CGI: scripts de la web que ejecutan comandos en el webserver

El Servlet CGI es un componente vital de Apache Tomcat que permite a los servidores web comunicarse con aplicaciones externas más allá de la JVM de Tomcat. Estas aplicaciones externas suelen ser scripts CGI escritos en lenguajes como Perl, Python o Bash

El Servlet CGI recibe solicitudes de los navegadores web y las reenvía a los scripts CGI para su procesamiento

Los scripts CGI se utilizan en los sitios web por varias razones:

![[Pasted image 20260728115144.png]]

La configuración `enableCmdLineArguments` para el Servlet CGI de Apache Tomcat controla si se crean argumentos de línea de comandos a partir de la cadena de consulta (query string). Si se establece en «true», el Servlet CGI analiza la cadena de consulta y la pasa al script CGI como argumentos


##### Ejemplo basico

Un script CGI que permite buscar libros por titulo y por autor

Esta habilitado `enableCmdLineArguments` por lo que se le puede pasar los argumentos por parametros

![[Pasted image 20260728115408.png]]

Como vemos en el action se establece el titulo y query la consulta del titulo

![[Pasted image 20260728115441.png]]

En este ptrp caso se hace con el autor

El problema esta que `enableCmdLineArguments` esta habilitado en un Windows, este no valida bien la entrada antes de pasarla al CGI, lo que puede llevar a una inyeccion de comandos

Un ejemplo seria: `http://example.com/cgi-bin/hello.bat?&dir`. dir se pasa como argumento de hello.bat y ejecuta dir en el servidor
