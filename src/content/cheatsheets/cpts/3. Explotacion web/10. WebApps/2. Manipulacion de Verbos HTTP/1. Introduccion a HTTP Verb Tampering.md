
El protocolo HTTP acepta en las solicitudes varios tipos de metodos HTTP como verbos al principio de las solicitudes

Dependiendo de la configuracion de la aplicacion web, esta puede aceptar ciertos metodos para diversas funcionalidades

Los programadores suelen considerar sobre todo GET y POST. Podemos enviar cualquier otro metodo y ver como reacciona


Ejemplo:

- Imaginemos que el backend esta configurado para aceptar GET y POST, y nosotros mandamos otro metodo, nos saldra una pagina de error

- Pero si el backend no esta bien configurado para solo aceptar GET y POST, y no se desarrolla para manejar otros metodos como HEAD, PUT..., entonces podemos explotar esta configuracion insegura para obtener acceso a funcionalidades que no teniamos acceso u omitir ciertos controles
