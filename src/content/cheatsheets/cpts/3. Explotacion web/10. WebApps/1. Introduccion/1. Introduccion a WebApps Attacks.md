
Es posible que las empresas usen aplicaciones web externas, internas o usen APIs externas que son vulnerables

Se cubriran otros 3 tipos de ataque web de los ya enseñados


## Manipulacion de Verbos HTTP o HTTP Verb Tampering

Explota webservers que aceptan muchos verbos y metodos HTTP

Se pueden enviar muchas solicitudes maliciosas con metodos HTTP inesperados lo que puede llevar a eludir el mecanismo de autorizacion de la aplicacion o sus controles de seguridad


## Referencias inseguras a objetos directoros o Insecure Direct Object References (IDOR)

Puede llevar a acceder a datos que no deberian ser accesibles para los atacantes. Se debe a la baja solidez de mecanismos de control de acceso al backend 

A medida que la aplicacion web almacena archivos e informacion de los usuarios, estos pueden usar numeros de indetificacion (ID) para identificar cada elemento

Si la aplicacion carece de un mecanismo de control robusto podemos acceder a archvios y recursos de otros usuarios adivinando o calculando estos IDs


## Inyeccion de Entidades Externas XML o XML External Entity Inyection (XXE)

Muchas aplicaciones web procesan datos en XML como parte de su funcionalidad. Si la aplicacion web usa librerias XML desactualizadas para analizar y procesar los datos de entrada XML del usuario en el frontend, podriamos enviar datos XML maliciosos para divulgar archivos locales almacenados en el servidor backend

Pueden ser archvios de configuracion con contenido sensible o incluso codigo fuente

Se pueden usar para robar credenciales del servidor de alojamiento
