
Hasta ahora hemos usado IDOR para acceder a archivos y recursos fuera del acceso de nuestro usuario

Tambien se pueden hacer en llamadas a funciones API y nos permitiran realizar diversas acciones

- Vulnerabilidades de Divulgación de Información por IDOR --> nos permiten leer varios tipos de recursos
- Llamadas a Funciones Inseguras por IDOR --> nos permiten llamar a APIs o ejecutar funciones como otro usuario

Estas funciones o APIs se pueden usar para cambiar informacion de usuario, restablecer credenciales o comprar articulos usando la informacion de pago de otro usuario

## Explotando APIs inseguras

Full name, email y about son parametros que podemos cambiar ya que estan bajo nuestro control en el HTML de la pagina web

Cosas que podriamos intentar:

1. Cmabiar el uid para encontrar mas cuentas
2. Cambiar detalles de otro usuario
3. Crear nuevos usuarios con detalles arbitrarios o eliminar existentes
4. Cambiar nuestro rol a admin para poder realizar mas acciones

- Vamos a cambiar nuestro uid primero, pero nos pone mismatch:

![[Pasted image 20260724181411.png]]

Parece que la aplicacion comapra el uid con el numero de la llamada a API (/1) por lo que tendremos que cambiar ambos:

![[Pasted image 20260724181506.png]]

Ahora pone uuid mismatch. Parece que la aplicacion compara el uuid que enviamos con el del usuario

- Como no sabemos como se compone realmente el uuid vamos a tratar de crear un nuevo usuario, usando POST y con un nuevo uid 50, vemos que dice que es una accion solo para admins:

![[Pasted image 20260724181655.png]]

DELETE tampoco funciona

- La aplicacion seguramente este  verificando el role. Vamos a cambiarlo por admin o administrator para nuestro uid 1 pero vemos que pone role invalido:

![[Pasted image 20260724181934.png]]


¿Es segura?
Hasta ahora no ha funcionado nada pero no significa que sea segura.

Solo hemos probado Llamadas a Funciones Inseguras por IDOR pero no hemos probado la peticion GET de la API en busca de Divulgación de Información por IDOR

Si el control de acceso no es robusto podriamos leer informacion de otros usuario usando Divulgación de Información por IDOR en el GET

Intenta probar la API en busca de vulnerabilidades de divulgación de información por IDOR intentando obtener los detalles de otros usuarios con peticiones GET
