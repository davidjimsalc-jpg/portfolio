
Una vez que identifiquemos un IDOR potencial podemos empezar a probarlo con tecnicas basicas

Para ataques avanzados necesitaremos entender mejor como funciona la aplicacion web, como calcula las referencias y como funciona su sistema de control de acceso


## Parametros inseguros

Tenemos una aplicacion de Adminsitracion de Empleados que aloja los registros de los empleados:

![[Pasted image 20260724164229.png]]

La aplicacion asume que hemos iniciado sesion como usuario1 con `uid=1`. Una vez hacemos click en `Documents` nos redigira a `/documents.php`

![[Pasted image 20260724164337.png]]

Aqui veremos varios doucmentos de nuestro usuario que pueden ser subidos por nuestro usuario o por el departamento de RRHH. Al revisar los enlaces vemos los siguientes nombres:

![[Pasted image 20260724164445.png]]

Se puede apreciar una nomenglatura predecible ya que los archivos parecen estar usando el Invoice/Report +`uid` del usuario + mes_año


Podemos ver que la pagina esta estrableciendo nuestro uid con un parametro GET en la URL `documents.php?uid=1`. Si la pagina web usa el uid como referencia de objetos, podriamos ver recursos de otros usuarios cambiando este uid

## Ejemplo practico

Repite lo que has aprendido para tener una lista de documentos de los 20 primeros users en /documents.php. Uno debe tener la flag.txt

1. Visitamos la pagina web y capturamos el POST al visitar /documents.php que contiene un parametro uid en su data. Lo mandamos al Intruder

![[Pasted image 20260724165553.png]]![[Pasted image 20260724170941.png]]

2. Cremos una wordlist de 20 numeros para cambiar en el uid. Ademas ponemos que una grep match a las respuestas que contengan flag o HTB

![[Pasted image 20260724170121.png]]![[Pasted image 20260724171006.png]]
![[Pasted image 20260724171312.png]]

3. Al iniciar el ataque vemos que el uid 15tiene en su respuesta la palabra flag

![[Pasted image 20260724171343.png]]

4. Para leerlo, volvemos a capturar el POST y ponemos 15 en el uid. Tras esto le damos a Forward

![[Pasted image 20260724171845.png]]![[Pasted image 20260724171855.png]]

5. Ahora estaremos viendo los documentos del usuario uid 15. Leemos la flag
