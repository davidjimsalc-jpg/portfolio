## XML

Lenguaje de marcado comun similar al HTML diseñado para la transferencia y almacenamiento flexible de datos y documentos en varios tipos de aplicaciones

Se centra en el almacenamiento y representacion de estructura de datos

Los documentos XML estan formados por arboles de elementos donde cada elemento se denota por un tag y el primer elemento se llama elemento raiz que contendra elementos hijos

## XML DTD

Permite la validacion de un documento XML contra una estructura de documento predefinida

Esta estructura puede definirse en el mismo documento o en uno externo

![[Pasted image 20260724232032.png]]

Ejemplo: declara el elemento email y denota sus hijos y tras esto se declaran cada uno de sus hijos

## Entidad XML

Podemos definir entidades personalizadas (son las variables de XML) en los DTD usando ENTITY:

![[Pasted image 20260724232331.png]]

Se puede hacer referencia a la entidad usando `&ENTIDAD;` y cada vez que hagamos referencia a esta, lo sustituira por su valor

Lo mas interesante es que podemos hacer referencia a ENTITIES externas con la palabra `SYSTEM o PUBLIC` + ruta entidad
