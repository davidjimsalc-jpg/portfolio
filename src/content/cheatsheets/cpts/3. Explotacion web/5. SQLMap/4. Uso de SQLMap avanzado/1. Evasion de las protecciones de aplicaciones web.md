
## Evasion de Tokens Anti-CSRF

Tokens anti falsificacion de peticiones en sitios cruzados o Cross-Site Request Forgery

Esto lo que hace es que cada peticion HTTP obtiene un token que se da solo si el usuario realmente visito y uso la pagina

--csrf-token: SQLMap intentara automaticamente analizar el contenido de la respuesta del objetivo y buscar valores de token nuevos para poder usarlos en la siguiente peticion. El token se proporciona en la peticion HTTP

Como esta presente en la solicitud HTTP, si SQLMap detecta un campo llamado (csfr, xsfr, token...) nos preguntara en linea de comandos si queremos actualizar el token para futuras peticiones

```
sqlmap -u URL --data="PARAMETRO=VALOR&TOKEN=VALOR" --csrf-token="csrf-token"
```

## Evasion por valor unico

Hay veces que la pagina web pide que la peticion tenga un valor unico. Es parecido a anti-csfr excepto que no es necesario analizar el contenido de la pagina web, solo asegurar que cada peticion tenga un valor unico para el parametro definido

--randomize

```
sqlmap -u URL --randomize=PARAMETRO --batch 
```
![[Pasted image 20260714145403.png]]


## Evasion por parametro calculado

La pagina web espera un valor para un parametro que se calcula basandose en otros valores. Lo mas frecuente es que tenga que contener el message digest --> h=MD5(PARAMETROX)

--eval

```
sqlmap -u "URL?PARAMETRO1=VALOR&PARAMETRO2=HASH" --eval="import hashlib; h=hashlib.md5(id).hexdigest()" --batch
```

## Ocultacion de la direccion IP

2 opciones:

- Añadir un proxy o varios

--proxy="socks4://IP:PUERTO"
--proxy-file=/RUTA

- Añadir un TOR
--tor=URL
--check-tor: para comprobar de que se esta ejecutando correctamente


## Evasion WAF

Cuando se ejecuta SQLMap primero envia un payload malicioso con un parametro inexistente para determinar la existencia de WAF (ej. ?pfov=...)

Si hay proteccion la respuesta sera diferente como que devuelva 406-Not Acceptable

Usara la biblioteca [identYwaf](https://github.com/stamparm/identYwaf) para ejecutar 80 soluciones WAF diferentes

Para omitir esto --> --skip-waf


## Evasion de listas negras de User-Agent

Cuando usamos SQLMap el UserAgent es (User-agent: sqlmap/1.4.9 (http://sqlmap.org))

--random-agent: cambia el useragent a un valor al azar de los navegadores registrados una BBDD de SQLMap


## Scripts de manipulacion

Para evadir soluciones WAF/IPS. Estos estan escritos en Python para modificar peticiones justo antes de que sean enviadas al objetivo

Ejemplo: script que cambia > por NOT BETWEEN 0 AND X o = por BETWEEN X AND X

Estos se pueden encadenar uno tras otro en el flag `--tamper`. Lista completa `--list-tampers`

```
sqlmap -u URL --tamper=script1,script2...
```

## Evasiones varias

1. Codificacion de transferencia fragmentada (Chunked transfer encoding): `--chunked`:

Divide el cuerpo de la peticion POST en los llamados "chunks". Las palabras SQL de lista negras se dividen en chunks para que pasen desapercibidas


2. Contaminacion de parametros HTTP (HTTP Parameter Pollution o HPP): el payload se divide de forma similar que en chuncked pero entre diferentes valores de la URL
