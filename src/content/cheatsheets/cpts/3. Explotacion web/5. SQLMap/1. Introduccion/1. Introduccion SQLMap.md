
[SQLMap](https://github.com/sqlmapproject/sqlmap): herramienta de python que automatiza el proceso de deteccion y explotacion de fallas de inyeccion SQLi

```
python sqlmap.py -u 'http://IP:PORT/DIRECTORIO?PARAMETRO=VALOR'
```
![[Pasted image 20260713204345.png]]


## Instalacion

```
sudo apt install sqlmap -y
sqlmap -h
```

o

```
git clone --depth 1 https://github.com/sqlmapproject/sqlmap.git sqlmap-dev
python sqlmap.py -h
```

## Tipos de inyeccion SQL 

Para ver todos los tipos de SQLi que soporta usamos:

```
sqlmap -hh
```
![[Pasted image 20260713204617.png]]

- BEUSTQ se refiere a:
	- B: basada en consultas a ciegas basadas booleanos
	- E: basada en errores
	- U: basada en consultas UNION
	- S: basada en consultas apiladas
	- T: basada en consultas a ciegas basadas en tiempo
	- Q: basada en consultas en linea


## Explicacion de cada tipo de inyeccion

#### Consultas a ciegas con Booleanos

Ejemplo:

![[Pasted image 20260713204924.png]]

SQLMap diferencia entre dos resultados `VERDADERS` = 1 y `FALSOS` = 0. Los datos reales los extrae debido a que un caracter = 1byte lo que da lugar a 7-8 peticiones por caracter. Compara las respuestas del servidor para determinar si la consulta devuelve `TRUE` o `FALSE`:

 - VERDADEROS: generalmente no tienen o casi ninguna diferencia con la respuesta normal
 - FALSE: tienen diferencias sustanciales con la respuesta del servidor

![[Pasted image 20260713210735.png]]

#### Consultas Apiladas

Ejemplo:

![[Pasted image 20260713210931.png]]

Apilar consultas SQL despues de la orginal. En caso de que se quieran usar sentencias como INSERT, UPDATE o DELETE, estas deben ser soportadas por el DBMS

SQLMap puede usar estas consultas para ejecutar sentencias que no son de consultas como ejecucion de comandos SO y para la recuperacion de datos de manera similar a SQLi basada a ciegas en tiempo


#### Inyeccion SQL ciega basada en tiempo

Ejemplo:

![[Pasted image 20260713211431.png]]

Es parecido a Inyección SQL Ciega Basada en Tiempo pero en este caso se usa el tiempo de respuesta para diferenciar entre `TRUE` y `FALSE`

- TRUE: diferencia notable en el tiempo de respuesta en comparacion con la respuesta normal
- FALSE: similar al tiempo de respuesta de la respuesta normal

Es mas lenta que Inyección SQL Ciega Basada en Tiempo y estos se usan cuando Inyección SQL Ciega Basada en Tiempo no es aplicable (ej. la sentencia SQL vulnerable no es una consulta sino un INSERT, UPDATE o DELETE ejecutada como parte de una funcionalidad que no da efecto sobre el renderizado de la pagina)

#### Inyeccion SQL fuera de banda

Ejemplo:

![[Pasted image 20260713212036.png]]

Mas avanzado y se usa cuando los otros fallan o son muy lentos. Es atraves de exfiltracion por DNS donde las consultas solicitadas se recuperan a traves de trafico DNS

SQLMap puede hacer que el servidor solicite subdominios inexistentes como (foo.example.com) donde foo seria la respuesta SQL que queremos recibir. SQLMap recoge estas peticiones y recoge la parte de foo de las peticiones para formar la respuesta correcta
