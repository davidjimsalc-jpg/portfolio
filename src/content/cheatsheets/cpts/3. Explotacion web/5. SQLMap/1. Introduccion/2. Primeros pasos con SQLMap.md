## Escenario basico

Una pagina web en la que hay una entrada de usuario que recoge esta entrada bajo un parametro GET

Ejemplo PHP backend:

![[Pasted image 20260713214937.png]]

En esta los errores SQL se devuelven como parte de la respuesta del web lo que facilita la SQLi

![[Pasted image 20260713215106.png]]

- Ejecutamos SQLMap contra el sitio web pasando la URL con el parametro HTTP GET:

```
sqlmap -u "http://SITIOWEB/PAGINA?PARAMETRO=VALOR" --batch
```

-u URL: proporcionar la URL
--batch: omitir cualquier entrada requerida por usuario eligiendo siempre la opcion por defecto
