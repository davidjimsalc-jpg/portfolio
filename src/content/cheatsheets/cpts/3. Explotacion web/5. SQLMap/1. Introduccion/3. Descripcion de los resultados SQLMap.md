## Descripcion de los mensajes de log

#### El contenido de la URL es estable

```
target URL content is stable
```

Significa que no hay cambios importantes entre respuestas en caso de solicitudes identicas. Las respuestas estables facilitan detectar diferencias causadas por los intentos de SQLi


#### El parametro parece dinamico

```
GET parameter 'id' appears to be dynamic
```

Es deseable que sea dinamico ya que es señal de que cualquier cambio en su valor resultara en un cambio de respuesta y puede indicar que esta vinculado a una BBDD
Si es estatico podria ser que el valor del parametro no es procesado en el objetivo

#### El parametro podria ser inyectable

```
heuristic (basic) test shows that GET parameter 'id' might be injectable (possible DBMS: 'MySQL')
```

En este caso MySQL genero un error que fue visible en la salida de la pagina web al usar `?id=1",)..).))'` lo que puede indicar que el parametro probado puede ser vulnerable a una inyeccion SQLi y que el objetivo podria ser MySQL

#### El parametro podria ser vulnerable a ataques XSS

```
heuristic (XSS) test shows that GET parameter 'id' might be vulnerable to cross-site scripting (XSS) attacks
```

Aunque no es el objetivo de SQLMap tambien hace una prueba rapida de XSS

#### El DBMS de backend es ...

```
it looks like the back-end DBMS is 'MySQL'. Do you want to skip test payloads specific for other DBMSes? Y/n
```

SQLMap prueba todos los DMBS compatibles y en caso de coincidencia podemos limitar los payloads solo al DBMS especifico

#### Valores de nivel/riesgo

```
for the remaining tests, do you want to include all tests for 'MySQL' extending provided level (1) and risk (1) values? Y/n
```

Si se detecta un DBMS se pueden especificar el uso de todos payloads para ese objetivo incluyendo mas avanzados. Si no se detecta solo se usan los principales


#### Se encontraron valores reflectantes

```
reflective value(s) found and filtering out
```

Es una advertencia que indica que parte de los payloads usados se muestran como respuesta lo que puede suponer problemas ya que representa basura, aunque SQLMap tiene mecanismos de limpieza de esa basura antes de comparar el contenido


#### El parametro parece ser inyectable

```
GET parameter 'id' appears to be 'AND boolean-based blind - WHERE or HAVING clause' injectable (with --string="luther")
```

Esto indica que el parametro puede ser vulnerable a SQLi aunque aun puede ser un FP.

- En SQL a ciegas basados en booleanos y tipos similares como basados en tiempo suele a ver muchos FP

SQLMap muestra (with --string="luther") lo que indica que uso la cadena de texto luther en la respuesta para distinguir entre `TRUE` o `FALSE`


#### Modelo estadistico de comparacion basada en tiempo

```
time-based comparison requires a larger statistical model, please wait........... (done)
```

SQLMap usa un modelo estadistico para el reconocimiento de respuestas regulares y retrasadas en el equipo. Para que funcione hay que recopilar un numero duficiente de tiempos de respuesta irregulares para distinguir estadisticamente el retraso


#### Ampliando las pruebas de la tecnica de inyeccion de consultas UNION

```
automatically extending ranges for UNION query injection technique tests as there is at least one other (potential) technique found
```

Las consultas UNION requieren de mas solicitudes para el reconocimiento exitoso de un payload utilizable para SQLi

Para reducir este tiempo se limita el numero de consultas a 10 para este tipo de comprobacion aunque si parece ser vulnerable (ej. se encuentra otra vuln SQLi de otro tipo) SQLMap amplia el numero predeterminado de solicitudes


#### La tecnica parece ser utilizable

```
ORDER BY' technique appears to be usable. This should reduce the time needed to find the right number of query columns. Automatically extending the range for current UNION query injection technique test
```

Antes de lanzar las consultas UNION realiza consultas ORDER BY para conocer las columnas de la tabla requerido para las consultas UNION


#### El parametro es vulnerable

```
GET parameter 'id' is vulnerable. Do you want to keep testing the others (if any)? y/N
```

Significa que ha encontrado que el parametro es vulnerable a SQLi. Aun asi podriamos continuar buscando si es vulnerable a mas tipos


#### SQLMap identifico los puntos de inyeccion

```
sqlmap identified the following injection point(s) with a total of 46 HTTP(s) requests:
```

Se muestra una lista de los puntos de inyeccion con su tipo, titulo y payloads lo que demuestra la prueba final de la deteccion y explotacion de SQLi

Solo se muestra los que son demostrablemente explotables


#### Datos de registrados en archivos de texto

fetched data logged to text files under '/home/user/.sqlmap/output/[www.example.com](http://www.example.com/)

Unicacion en el sistema de archivos local donde se almacenan los logs, sesiones y datos de salida del objetivo y se guardan para futuras operaciones sobre este
