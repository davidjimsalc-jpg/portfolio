2. Pegamos en portapapeles y cambiamos curl > sqlmap

Debe haber un valor de parametro que pueda ser evaluado o usar las flags para busqueda automatica de parametros como:

- \--crawl, --forms o -g



## Peticiones GET/POST

- GET

Se realiza el escaneo en ambos parametros:

```
sqlmap -u URL/PAGINA?PARAMETRO1=VALOR&PARAMETRO2=VALOR
```
![[Pasted image 20260713223948.png]]

En caso de que queramos solo hacer el escaneo a uno de ellos ponemos `*` o con -p:

```
sqlmap -u URL/PAGINA?PARAMETRO1=VALOR*&PARAMETRO2=VALOR
```

```
sqlmap -u URL/PAGINA?PARAMETRO1=VALOR&PARAMETRO2=VALOR -p PARAMETRO1
```


- POST

Se realiza el escaneo en ambos parametros:

```
sqlmap URL --data 'PARAMETRO1=VALOR&PARAMETRO2=VALOR'
```

En caso de que queramos solo hacer el escaneo a uno de ellos ponemos `*` o con -p:

```
sqlmap URL --data 'PARAMETRO1=VALO*R&PARAMETRO2=VALOR'
```

```
sqlmap URL --data 'PARAMETRO1=VALOR&PARAMETRO2=VALOR' -p PARAMETRO1
```
![[Pasted image 20260713224507.png]]


## Peticiones HTTP completas

En caso de tener solicitudes HTTP complejas como:

- Muchos parametros GET
- Un cuerpo POST grande

Podemos usar `-r ARCHIVO` para pasarle un archivo con la peticion HTTP

	Si hay varios parametros y queremos probar solo los que decidamos, usamos * --> (PARAMETRO=*)

1. Capturamos la peticion en Burp Suite

![[Pasted image 20260713224724.png]]

2. Varias formas:

- Pegamos toda la peticion que hemos captura de burp en un archivo 
- En burp le damos click derecho > Copy to File
- En la pagina web > Inspeccionar > Network > Click derecho sobre la peticion > Copy > Copy Request Headers > pegamos en un archivo

![[Pasted image 20260713224741.png]]

3. Ejecutamos sqlmap

```
sqlmap -r ARCHIVO.txt
```

## Peticiones SQLMap personalizadas

Si quisieramos crearlas manualmente podemos usar diferentes flags:

- Ejemplo especificando el valor de una cookie de sesion:

```
sqlmap ... --cookie='COOKIE=cookie'
```

o 

```
sqlmap ... -H='COOKIE=cookie'
```

--host
--referer
-A o --user-agent
--random-agent: selecciona un UserAgent aleatorio para evitar que salga sqlmap y salga GoogleChrome por ejemplo
--mobile: imitar un telefono


#### Se pueden apuntar a cabeceras de HTTP 

Esto no es normal pero se puede hacer con `*` :

```
sqlmap -u URL --data='PARAMETRO=VALOR' --cookie="PARAMETRO=VALOR*"
```

#### Especificar otro metodo alternativo

```
sqlmap -u URL --data='PARAMETRO=VALOR' --method (PUT,DELETE,UPDATE...)
```


## Peticiones HTTP Personalizadas

Aparte de con datos POST en formato `form-data` (id=1) tambien acepta en formatos `JSON` ({"id":1}) o `XML` (\<element>\<id>1\</id>\</element>)

Esto se pondra en el --data del comando:

- Form-data

```
sqlmap -u URL --data='PARAMETRO=VALOR' 
```

- JSON

```
sqlmap -u URL --data='{"PARAMETRO":VALOR}' 
```

- XML

```
sqlmap -u URL --data='\<element>\<PARAMETRO>VALOR\</id>\</element>' 
```
