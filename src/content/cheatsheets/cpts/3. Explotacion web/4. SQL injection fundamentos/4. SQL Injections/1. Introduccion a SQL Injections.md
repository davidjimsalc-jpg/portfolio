## Tipos de inyeccion

![[Pasted image 20260712131158.png]]

- Inband: la salida se puede leer en el front end 
	- Union based: es posible que tengamos que especificar la ubicacion exacta (columna para que pueda imprimirse)
	- Error based: se usa cuando podemos obtener errores PHP o SQL en el frontend 

- Blind: no se tiene salida por lo que es posible que tengamos que recuperar la salida caracter por caracter
	- Boolean based: sentencias condicionales SQL para controlar si la pagina devuelve alguna salida (ejemplo: la salida original si el condicional es true)
	- Time based: sentencias condicionales que retrasan la respuesta de la pagina si la sentencia condicional devuelve true (usando sleep())

- Out of band: no tenemos acceso directo a la salida en absoluto por lo que podriamos tener que dirigir la salida a una ubicacion remota (ejemplo: a un registro DNS y recuperarla desde alli)
