## Numero de columnas

#### Numero igual

Si hacemos una consulta UNION entre dos tablas con distinto numero de columnas dara error

![[Pasted image 20260713111454.png]]

Para remediarlo hay 2 opciones:

1. A la tabla que tiene mas columnas, debemos especificar que se muestren el numero de columnas que queremos. Ejemplo si queremos mostrar dos columnas que queramos:

```
SELECT * FROM tabla_pequeña WHERE columna='ALGO%' UNION SELECT columna1, columna2 FROM tabla_grande WHERE columna1='ALGO%';
```


2. Rellenar la tabla con menos columnas con columnas con datos junk 

```
SELECT columna1, 2, 3, 4 FROM tabla_pequeña WHERE columna='ALGO%' UNION SELECT * FROM tabla_grande WHERE columna1='ALGO%';
```
