## Detectar numero de columnas

Primero necesitamos saber el numero de columnas. 2 Metodos

1. ORDER BY N: esta sentencia ordena por el numero de la columna que le pasamos (ORDER BY 1 ordenara por la columna1, ORDER BY 2 ordenara por la columna2...) asi hasta llegar a un numero que obtengamos un error

![[Pasted image 20260713113822.png]]![[Pasted image 20260713113912.png]]![[Pasted image 20260713113919.png]]


2. UNION: usaremos UNION para que nos muestre el numero de columnas que especifiquemos hasta que deje de salir un error (' UNION SELECT 1 muestra un columna, 'UNION SELECT 1,2 muestra 2 columnas...) como UNION solo funciona cuando ambas consultas tengan el mismo numero de columnas, no se mostrara hasta que no llegue al numero igual

![[Pasted image 20260713114149.png]]![[Pasted image 20260713114155.png]]


## Ubicacion de la inyeccion

Como vemos al ser 4 columnas y tener 3 de salida por pantalla solo vemos las columnas 2,3,4 y no la 1

![[Pasted image 20260713114237.png]]

Podemos colocar el payload de explotacion para conseguir informacion en una de las columnas que salgan impresas:

```
UNION SELECT 1,@@version,3,4
```
