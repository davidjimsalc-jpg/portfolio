
La mayoria de aplicaciones usan una BBDD en el backend para almacenar y recuperar datos relacionados con la aplicacion web

Para que la pagina web sea dinamica esta tiene que interactuar con la BBDD en tiempo real

![[Pasted image 20260711175038.png]]

Cuando un usuario intenta pasar una entrada que modifica la consulta SQL final enviada por la aplicacion web permitiendo realizar otras consultas SQL no deseadas --> SQL Injection o NoSQL Injection


Para lograrlo hay que inyectar codigo fuera de los limites esperados de la entrada de usuario para que no se ejecute como una simple entrada
