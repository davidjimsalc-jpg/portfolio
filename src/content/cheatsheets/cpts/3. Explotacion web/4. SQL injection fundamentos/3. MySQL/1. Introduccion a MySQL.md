- Sin contraseña en la linea de comandos

```
mysql -u USER -p --ssl=0
```

- Con contraseña en linea de comandos

```

```
![[Pasted image 20260711181447.png]]

- Inicio de sesion remoto


#### Tablas

Las tablas estan formadas por filas horizontales y columnas verticales. La interseccion entre una fila y una columna es una celda

1. Creacion de una tabla "logins" que almacena datos de usuarios usando CREATE TABLE:

```
CREATE TABLE logins (id INT, username VARCHAR(100), password VARCHAR(100), data_of_joining DATETIME)
```
![[Pasted image 20260711182222.png]]


2. Ver tablas

```
SHOW TABLES;
```
![[Pasted image 20260711182319.png]]

3. Ver estructura de la tabla

```
DESCRIBE nombre;
```
![[Pasted image 20260711182345.png]]

#### Propiedades de las tablas

1. Establecer una columna que se autoincremente

```
columna INT NOT NULL AUTO_INCREMENT,
```

2. Hacer que una columna no deje celdas vacias

```
columna VARCHAR(100) UNIQUE NOT NULL,
```

3. Especificar un valor por defecto

```
columna DATETIME DEFAULT NOW(),
```

4. Establecer una columna como clave primaria para identificar de forma unica una tabla y poder relacionarla con otras tablas

```
PRIMARY KEY (columna)
```
