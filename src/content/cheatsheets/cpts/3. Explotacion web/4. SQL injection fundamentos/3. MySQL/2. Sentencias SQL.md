
## INSERT

Añadir nuevos registros a una tabla determinada

```
INSERT INTO tabla VALUES (columan1_VALOR, columna2_VALOR...);
```
![[Pasted image 20260711183342.png]]

Podemos añadir valores a columnas especificasÑ

```
INSERT INTO tabla(columna1, columna4..) VALUES(columna1_VALOR, colunma4_VALOR...)
```
![[Pasted image 20260711184022.png]]

Podemos añadir varias filas con valores:

```
INSERT INTO tabla(columna1, columna4...) VALUES (columna1_VALOR, columna4_VALOR), (columna1_VALOR, columna4_VALOR)
```
![[Pasted image 20260711184216.png]]


## SELECT

Ver contenido de las tablas

1. Ver todo

```
SELECT * FROM tabla;
```

2. Ver columnas determinadas de tablas

```
SELECT columna1, columna2 FROM tabla;
```

## ALTER

Cambiar nombres de tablas o de campos, eliminar o añadir columnas a una tabla existente

1. Añadir columna

```
ALTER TABLE tabla ADD nuevaColumna INT;
```
![[Pasted image 20260711212432.png]]

2. Renombrar columna
```
ALTER TABLE tabla RENAME COLUMN columna TO nuevaColumna;
```
![[Pasted image 20260711212514.png]]

3. Cambiar el tipo de dato de una columna
```
ATER TABLE tabla MODIFY nuevaColumna DATE;
```
![[Pasted image 20260711212554.png]]

4. Eliminar columna
```
ALTER TABLE tabla DROP nuevaColumna;
```
![[Pasted image 20260711212619.png]]


## Update

Actualizar registros especificos dentro de una tabla

```
UPDATE tabla SET columna1=nuevoValor, columna2=nuevoValor WHERE <condicion>;
```
