
## ORDER BY

Ordenar resultados especificando la columna

```
SELECT * FROM tabla ORDER BY columna;
```
![[Pasted image 20260711213722.png]]

Se puede hacer tambien de forma descendente:

```
SELECT * FROM tabla ORDER BY columna DESC;
```
![[Pasted image 20260711213800.png]]

Se pueden ordenar teniendo en cuenta dos columnas por si hay registros repetitivos en la primera

```
SELECT * FROM tabla ORDER BY columna1 DESC, columna2 ASC;
```
![[Pasted image 20260711213857.png]]


## LIMIT

Limitar el numero de resultados de salida

```
SELECT * FROM tabla LIMIT N;
```
![[Pasted image 20260711213953.png]]

Si quisieramos LIMITAR el numero de resultados de la salida pero ademas que se mostraran desde X fila, podemos especificar el numero de desplazamientos. En el siguiente ejemplo se desplaza 1 la salida por lo que salen los resultados 2 y 3 en vez de 1 y 2

```
SELECT * FROM tabla LIMIT N_desplazamiento, N_salidas;
```
![[Pasted image 20260711214117.png]]

## LIKE

Seleccionar registros haciendo coincidir un patron determinado

```
SELECT * FROM tabla WHERE columna LIKE 'patron';
```
![[Pasted image 20260711214414.png]]
![[Pasted image 20260711214546.png]]

% actua como comodin y coincide con todos los caracteres despues del patron admin 
_ se usa para que coincida con un caracter. En el ejemplo como se ponen 3 _ la salida muestra usernames con 3 caracteres
