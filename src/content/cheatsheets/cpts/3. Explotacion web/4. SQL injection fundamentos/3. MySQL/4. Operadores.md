
## AND o &&

Toma dos condicionaes y devuelve true o false

	condicion1 AND condicion2

```
SELECT 1=1 AND 'test' = 'test';
```

## OR o ||

Toma dos expresiones y devuelve true cuando al menos una se cumple

	condicion1 OR condicion2

```
SELECT 1=1 OR 'test' = 'abc'
```
![[Pasted image 20260711220409.png]]

```

```

## Precedencia de multiples operadores

SQL soporta varias operaciones como suma, division... Lista de precedencia:

- División (`/`), Multiplicación (`*`) y Módulo (`%`)
- Suma (`+`) y resta (`-`)
- Comparación (`=`, `>`, `<`, `<=`, `>=`, `!=`, `LIKE`)
- NOT (`!`)
- AND (`&&`)
- OR (`||`)

Las operaciones de la parte superior de la lista se realizan antes que las de abajo

```
SELECT * FROM logins WHERE username != 'tom' AND id > 3 - 2;
```

Primero la resta luego la comparacion del ud, luego el not y por ultimo el AND
