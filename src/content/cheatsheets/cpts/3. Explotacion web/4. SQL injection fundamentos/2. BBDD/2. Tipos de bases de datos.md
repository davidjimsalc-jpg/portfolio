
## Bases de datos relacionales

Usa esquemas, que son plantillas para dictar la estructura de la base de datos almacenada

Las tablas (entidades) de una BBDD relacional se asocian entre ellas con claves (keys) que proporcionan un resumen rapido de la base de datos o acceso a la fila/columna. Todas las tablas estan relacionadas entre si usando keys

Ejemplo: tabla/entidad users que tiene columnas (id. username, firstname), id puede actuar como key y usarse en otras tablas para relacionarlas con la tabla users

## Bases de datos No relacionales

No usa tablas, filas y columnas ni kjeys primearias, relaciones o esquemas. Almacena los datos usando varios metodos dependiendo de los datos almacenados:

- Clave-Valor
- Basado en documentos
- De columna ancha 
- De grafos
