
## Sistemas de Gestion de BBDD

Ayuda a crear, definir, alojar y gestionar bases de datos

#### Arquitectura de 2 niveles

![[Pasted image 20260711180036.png]]

NIVEL 1 Frontend: aplicaciones del lado del cliente como sitios web o programas GUI que consisten en interacciones de alto nivel (como inicios de sesion de usuario)
NIVEL 2 Backend: los datos de estas interacciones pasan al nivel 2 a traves de llamadas APIs u otras solicitudes. Este es un middleware que intercepta los eventos y los convierte a la forma requerida para la DBMS
DBMS: recoge las consultas del NIVEL2 y realiza las operaciones solicitadas (inserccion, recuperacion, eliminacion o actualizacion)

Es posible tener el backend y el DBMS en el mismo host
