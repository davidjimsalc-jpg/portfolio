
## Caso de estidop de Windows 7

Podemos volver a usar:

- [Sherlock](https://github.com/rasta-mouse/Sherlock): script que busca parches faltantes
- [Windows-Exploit-Suggester](https://github.com/AonCyberLabs/Windows-Exploit-Suggester): toma los resultados del comando `sysinfo` y compara el nivel de parches del host s con los de la base de datos de vulns de Microsoft

1. Recopilando la salida de systeminfo:

```
systeminfo
```
![[Pasted image 20260914170342.png]]

2. Lo guardamos en un archivo de texto en nuestra maquina atacante

3. Actualizamos la base de datos de Microsoft:

```
sudo python2 windows-exploit-suggester.py --update
```

4. Ejecutamos Windows Exploit Suggester:

```
python2 windows-exploit-suggester.py --database 2021-05-13-mssb.xls --systeminfo win7lpe-systeminfo.txt
```
![[Pasted image 20260914170457.png]]![[Pasted image 20260914170506.png]]

Si hubieramos obtenido un shell Meterpreter podriamos haber usado el [módulo _local exploit suggester_](https://www.rapid7.com/blog/post/2015/08/11/metasploit-local-exploit-suggester-do-less-get-more/) en esa sesion para ayudarnos

	En la lista podemos ver una lista extensa de modulos MSF y PoCs. Para eliminar el ruido podemos elimianr cualquiera que sea de DoS y los que no tengan sentido para nuestro SO

Destaca la vuln MS16-032
