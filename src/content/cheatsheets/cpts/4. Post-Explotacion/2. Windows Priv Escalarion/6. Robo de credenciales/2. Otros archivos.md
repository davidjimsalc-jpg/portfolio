## Busqueda manual de credenciales en el sistema de archivos

[esta hoja de referencia](https://swisskyrepo.github.io/InternalAllTheThings/redteam/escalation/windows-privilege-escalation/) con comandos para busqueda manual en sistema de archivos o en unidades compartidas

1. Ejemplo 1

```
cd c:\Users\htb-student\Documents & findstr /SI /M "password" *.xml *.ini *.txt
```
![[Pasted image 20260912162100.png]]

2. Ejemplo 2

```
findstr /si password *.xml *.ini *.txt *.config
```
![[Pasted image 20260912162118.png]]

3. Ejemplo 3

```
findstr /spin "password" *.*
```
![[Pasted image 20260912162124.png]]

4. Buscar contenido de archivo con PS

```
select-string -Path C:\Users\htb-student\Documents\*.txt -Pattern password
```
![[Pasted image 20260912162155.png]]

5. Buscar por extensiones de archivos

```
dir /S /B *pass*.txt == *pass*.xml == *pass*.ini == *cred* == *vnc* == *.config*
```
![[Pasted image 20260912162224.png]]

6. Buscar por extensiones de archivo

```
where /R C:\ *.config
```
![[Pasted image 20260912162251.png]]

7. Buscar por extensiones de archivo

```
where /R C:\ *.config
```
![[Pasted image 20260912162326.png]]

8. Buscar por extensiones de archivos usando PS

```
Get-ChildItem C:\ -Recurse -Include *.rdp, *.config, *.vnc, *.cred -ErrorAction Ignore
```
![[Pasted image 20260912162403.png]]

## Contraseña en Sticky Notes

A veces lo usan para guardar credenciales pero este es un BBDD que se encuentra en: 

```
C:\Users\<user>\AppData\Local\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState\plum.sqlite
```
![[Pasted image 20260912162658.png]]


Podemos copiar los tres archivos `plum.sqlite*` a nuestro sistema y abrirlos con una herramienta como [DB Browser for SQLite](https://sqlitebrowser.org/dl/) y ver la columna `Text` en la tabla `Note` con la consulta `select Text from Note;`

![[Pasted image 20260912163035.png]]


O podemos visualizarlos usando PS con el [módulo PSSQLite](https://github.com/RamblingCookieMonster/PSSQLite)

```
Set-ExecutionPolicy Bypass -Scope Process
cd .\PSSQLite\
Import-Module .\PSSQLite.psd1
$db = 'C:\Users\htb-student\AppData\Local\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState\plum.sqlite'
C:\htb> Invoke-SqliteQuery -Database $db -Query "SELECT Text FROM Note" | ft -wrap
```
![[Pasted image 20260912163140.png]]


O usar Strings para ver el contenido del archivo BD

```
strings plum.sqlite-wal
```
![[Pasted image 20260912163216.png]]
