
## Credenciales guardadas con CmdKey

[cmdkey](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/cmdkey) se puede usar para crear, listar y eliminar nombres de usuario y contraseñas almacenados. Los usuarios pueden querer almacenar credenciales para un host especifico o para conexiones de servicios de terminal y poder conectarse via RDP sin introducir la contraseña

```
cmdkey /list
```

## Almacenamiento de creds en texto claro en el registro

#### Autologon Windows

El [Autologon](https://learn.microsoft.com/en-us/troubleshoot/windows-server/user-profiles-and-logon/turn-on-automatic-logon) de Windows es una característica que permite a un usuario configurar su sistema operativo Windows para iniciar sesión automáticamente en una cuenta de usuario específica, sin requerir la entrada manual del nombre de usuario y la contraseña

El nombre de usuario y la contraseña se almacenan en el registro, en texto claro

Las claves del registro asociadas con Autologon se pueden encontrar en `HKEY_LOCAL_MACHINE`

```
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon
```

La configuración típica de una cuenta de Autologon implica el establecimiento manual de las siguientes claves del registro:

- `AutoAdminLogon` - Determina si Autologon está habilitado o deshabilitado. Un valor de "1" significa que está habilitado.
- `DefaultUserName` - Contiene el valor del nombre de usuario de la cuenta que iniciará sesión automáticamente.
- `DefaultPassword` - Contiene el valor de la contraseña para la cuenta de usuario especificada anteriormente.

1. Enumerar autologon

```
query "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
```
![[Pasted image 20260912170330.png]]


#### PuTTY

Para las sesiones de Putty que utilizan una conexión proxy, cuando se guarda la sesión, las credenciales se almacenan en el registro en texto claro.

```
Computer\HKEY_CURRENT_USER\SOFTWARE\SimonTatham\PuTTY\Sessions\<SESSION NAME>
```

Ten en cuenta que los controles de acceso para esta clave de registro específica están vinculados a la cuenta de usuario que configuró y guardó la sesión. Por lo tanto, para verla, necesitaríamos iniciar sesión como ese usuario y buscar en el hive `HKEY_CURRENT_USER`. Posteriormente, si tuviéramos privilegios de administrador, podríamos encontrarla bajo el hive del usuario correspondiente en `HKEY_USERS`

1. Enumerar sesiones y encontrar credenciales

```
reg query HKEY_CURRENT_USER\SOFTWARE\SimonTatham\PuTTY\Sessions
```
![[Pasted image 20260912170501.png]]

```
reg query HKEY_CURRENT_USER\SOFTWARE\SimonTatham\PuTTY\Sessions\kali%20ssh
```
![[Pasted image 20260912170519.png]]
