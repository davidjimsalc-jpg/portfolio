
## Tipos de cuenta

| Tipo                                                       | Explicacion                                                                                                                              |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| NT AUTHORITY\SYSTEM o LocalSystem                          | Cuenta con mayores privilegios de forma local por encima de Administrador Local y se usa para ejecutar la mayoria de procesos en Windows |
| Administrator local                                        | Algunas empresas lo deshabilitan y se suele reutilizar en multiples sistemas                                                             |
| Miembros de Administrators                                 | Cualquier cuenta en este grupo tiene los mismos privs que Administrator Local                                                            |
| Usario estandar del dominio que pertenece a Adminsitrators |                                                                                                                                          |
| Domain Admin que forma parte de Administrators             |                                                                                                                                          |


## Puntos clave de la enumeracion

- Nombre del SO: tipo de SO y version (nos dara una idea de la version de ejecutables como PS)
- Version: para saber que exploits publicos puede ser vulns
- Servicios en ejecucion: especialmente los que ejecute NT Authority\System o una cuenta con nivel Administrator. Un servicio mal conf que sea ejecutado por una cuenta privilegiada puede ser una escalada facil

## Informacion del sistema

`tasklist`: ver los procesos que se estan ejecutando

```
tasklist /svc
```
![[Pasted image 20260806183646.png]]


Conocer servicios estandar como `smss.exe, winlogon.exe, lsass o svchost.exe` nos ayudara a centrarnos solo en los que no son estandar

En este ejemplo podriamos estar interesados en FileZilla (FTP) e intentariamos enumerar la version para buscar vulns publicas o configuraciones incorrectas

Otro proceso seria MsMpEng.exe (es el Windows Defender) nos ayudaran a mapear las protecciones que estan implementadas


#### Mostrar las variables del sistema

```
set
```
![[Pasted image 20260806184715.png]]

Una variable que debemos mirar es `PATH`. Es posible que haya sido modificada y contenga rutas hacia Python u otros. Si la carpeta a la que colocada es escribible por nosostros, podriamos realizar inyecciones DLL contra otras aplicaciones

	Esto pasa porque si ejecutamos algo, Windows primero busca en el directorio actual y luego en el PATH de derecha a izquierda (cuanto mas a la izquierda esta nuestra ruta personalizada, mas peligroso es)

Otra variable es `HOME DRIVE` que suele ser un recurso compartido. Estos recursos pueden servir para dos cosas:

- Un recurso compartido con gente externa como un departamento IT
- Colocar los directorios personales para que cuando el usuario se conecte a otra maquina tenga los mimos archivos. Si pasa esto y colocamos un archivo malicioso en la ruta `USERPROFILE\AppData\Microsoft\Windows\Start Menu\Programs\Startup` cuando inicie sesion en una maquina diferente se ejecutara el payload


#### Informacion de configuracion detallada

```
sysinfo
```
![[Pasted image 20260806185156.png]]

Muestra si la maquina ha sido parcheada recientemente y si es una VM. Si no ha sido parcheada la escalada puede ser simplemente ejecutar un exploit

Para saber si ha sido parcheada debemos buscar los KBs en [HotFixes](https://www.catalog.update.microsoft.com/Search.aspx?q=hotfix) o si la maquina no se ha reiniciado en meses es probable que tampoco este reiniciada

#### Parches y actualizaciones

Si `sysinfo` no muestra los hotfixed:

```
wmic qfe
```
![[Pasted image 20260806185244.png]]

O desde PS:

```
Get-HotFix | ft -AutoSize
```
![[Pasted image 20260806185315.png]]


#### Programas instalados

WMI tambien puede mostrar los programas instalados y buscar exploits a estas versiones

```
wmic product get name
```
![[Pasted image 20260806185537.png]]


O desde PS:

```
Get-WmiObject -Class Win32_Product | select Name,Version
```
![[Pasted image 20260806185630.png]]

#### Mostrar procesos en ejecucion

`netstat` mostrara las conexiones TCP/UDP activas lo que nos dara una mejor idea de que servicios estan escuchando y en que puertos. Podemos encontrar servicios vulns solo accesibles desde localhost

```
netstat -ano
Get-Process -Id PID
```

## Informacion de usuarios y grupos

#### Usuarios con sesion iniciada

```
query user
```
![[Pasted image 20260806190346.png]]

En una operativa EVASIVA deberiamos tener cuidado para que no nos detecten si hay otros usuarios trabajando


#### Usuario actual

Primero hay que ver en que contexto de usuario estamos

```
echo %USERANME%
```
![[Pasted image 20260806190544.png]]

#### Privilegios de usuario actual

Debemos conocer nuestros privilegios ya que estos nos pueden ayudar en la escalada

```
whoami /priv
```
![[Pasted image 20260806190641.png]]


#### Informacion de grupos del usuario actual

```
whoami /groups
```
![[Pasted image 20260806190729.png]]


#### Obtener todos los usuarios 

```
net user
```
![[Pasted image 20260806190800.png]]

Conocer que otros usuarios estan en el sistema


#### Obtener todos los grupos

```
net localgroup
```
![[Pasted image 20260806190849.png]]

Saber que grupos no estandar estan presentes para determinar para que se usa el host


#### Detalles sobre un grupo

Vale la pena revisar los detalles de un grupo no estandar para ver alguna informacion interesante

```

```
![[Pasted image 20260806191304.png]]
