## Enrutamiento protecciones

Es probable que haya sistemas EDR conectados monitorizando la actividad y que si usamos alguna herramienta publica o exploit nos bloquee. Algunos bloquean hasta net.exe o tasklist

Muchas organizaciones tienen una lista blanca de aplicaciones para controlar los tipos de aplicaciones que se usan y bloquear el `cmd` o `powershell` entre otros.

Microsoft ofrece: [AppLocker](https://docs.microsoft.com/en-us/windows/security/threat-protection/windows-defender-application-control/applocker/applocker-overview)

Podemos usar en el cmdlet: [GetAppLockerPolicy](https://docs.microsoft.com/en-us/powershell/module/applocker/get-applockerpolicy?view=windowsserver2019-ps) para enumerar las politicas del AppLocker


#### Comprobar el estado del Microsoft Defender

```
Get-MpComputerStatus
```
![[Pasted image 20260806180818.png]]

#### Listar reglas del AppLocker

```
Get-AppLockerPolicy -Effective | select -ExpandProperty RuleCollections
```
![[Pasted image 20260806180923.png]]


#### Probar la politica de AppLocker

```
Get-AppLockerPolicy -Local | Teqst-AppLockerPolicy -path C:\Windows\System32\cmd.exe -User Everyone
```
![[Pasted image 20260806181033.png]]
