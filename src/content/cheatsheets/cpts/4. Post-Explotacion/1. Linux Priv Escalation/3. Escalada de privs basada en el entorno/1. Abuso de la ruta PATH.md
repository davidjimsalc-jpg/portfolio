
PATH es una variable de entorno que especifica el conjunto de directorios en el que se va a localizar un ejecutable

Ejemplo:

```
cat --> /bin/cat --? $PATH=...:/bin:...
```

![[Pasted image 20260917144338.png]]

Si creamos un script o alojamos un ejecutable en alguna de esas rutas, lo hara ejectable desde cualquier parte del entorno

```
pwd && COMANDO
```
![[Pasted image 20260917144424.png]]

![[Pasted image 20260917144456.png]]

	Vemos que conncheck que se aloja en /usrlocal/sbin puede ser ejecutado desde /tmp o cualquier otra ruta


Si agregamos `.` a la variable PATH, se agregara la ruta actual a la lista PATH

	Imagina que creas un binario malicioso llamado `ls`, tras esto añades `.` a la lista PATH y haces export PATH. Podremos ejecutar `ls` y se llamara al binario malicioso de nuestra ruta actual

```
PATH=.:${PATH}
export PATH
echo $PATH
```
![[Pasted image 20260917144829.png]]

Ejemplo con el comando ls para ejecute un echo simple (primero tendremos que incorporar `.` al PATH):

```
touch ls
echo 'echo "PATH ABUSE!!"' > ls
chmod +x ls
ls
```
