
[LinPEAS](https://github.com/carlospolop/PEASS-ng/tree/master/linPEAS) y [LinEnum](https://github.com/rebootuser/LinEnum): son scritps que ayudan a la enumeracion

Cuando entramos en un sistema por primera vex debemos verificar varias cosas:

1. Que SO se esta ejecutando:

```
cat /etc/os-release
```
![[Pasted image 20260916155312.png]]

	Deberiamos mirar si Ubuntu 20.04.4 LTS es algo desactualizado o desatendido

2. Miramos la variable PATH que es donde el sistema busca cada vez que ejecutamos un comando. Si esta esta mal configurada pordriamos elevar nuestros privs

```
echo $PATH
```
![[Pasted image 20260916155507.png]]

3. Podemos mirar todas las variables del entorno para ver si hay algo sensible aqui:

```
env
```
![[Pasted image 20260916155542.png]]

4. Revisar la version del kernel para ver si es vulnerable:

```
cat /proc/version
uanme -a
```
![[Pasted image 20260916155639.png]]

5. Recopilar informacion sobre el propio host:

```
lscpu
```
![[Pasted image 20260916155718.png]]

6. Que shells de inicio de sesion existen en el sistema:

```
cat /etc/shells
```
![[Pasted image 20260916155754.png]]

7. Verificar si hay medidas de defensa implementadas. Algunas cosas que mirar son:

	- [Exec Shield](https://en.wikipedia.org/wiki/Exec_Shield)
	- [iptables](https://linux.die.net/man/8/iptables)
	- [AppArmor](https://apparmor.net/)
	- [SELinux](https://www.redhat.com/en/topics/linux/what-is-selinux)
	- [Fail2ban](https://github.com/fail2ban/fail2ban)
	- [Snort](https://www.snort.org/faq/what-is-snort)
	- [Uncomplicated Firewall (ufw)](https://wiki.ubuntu.com/UncomplicatedFirewall)

	Lo normal es que no tengamos privs para enumerarlos

8. Mirar las unidades y recursos compartidos en el sistema:

```
lsblk
```
![[Pasted image 20260916155934.png]]

9. Encontrar info sobre impresoras conectadas al sistema: `lpstat`
10. Unidades montadas y no montadas:

```
cat /etc/fstab
```
![[Pasted image 20260916160058.png]]

11. Revisar la tabla de enrutamiento para ver que otras redes estan disponibles:

```
route
netstat -rn
```
![[Pasted image 20260916160137.png]]

12. Revisar `/etc/resolv.conf` si estamos en un entorno de dominio para ver si esta configurado para usar el DNS interno y consultar asi el AD
13. Revisar la table ARP:

```
arp -a
```
![[Pasted image 20260916160250.png]]

## Conocimiento sobre los usuarios

1. Usuarios existentes:

```
cat /etc/passwd
```
![[Pasted image 20260916160336.png]]

	Puede que alguna vez veamos los hashes aqui aunque suelen estar en /etc/shadow

Para ver los usuarios que existen:

```
cat /etc/passwd | cut -f1 -d:
```
![[Pasted image 20260916160439.png]]


2. Identificar el algoritmo de los hashes almacenados:

![[Pasted image 20260916160514.png]]

3. Verificar los usuarios con shells de inicio de sesion:

```
grep "sh$" /etc/passwd
```
![[Pasted image 20260916160549.png]]

	Las versiones bash anteriores a 4.1 son vulns a Shellshock

4. Revisar los grupos de los usuarios

```
cat /etc/group
```
![[Pasted image 20260916160907.png]]

O revisar los miembros de un grupo especifico:

```
getent group sudo
```
![[Pasted image 20260916160944.png]]

5. Como digimos antes, revisar los que tengan carpeta /home para ver si tienen .bash_history o .ssh dentro

```
ls /home
```
![[Pasted image 20260916161035.png]]

6. Podemos buscar cualquier archivo de configuracion y otros con contenido sensible
7. Revisar archivos montados (hay varios tipos: ext4, NTFS, FAT32):

```
df -h
```
![[Pasted image 20260916161226.png]]

	Habra veces que no podremos ver los sistemas de archivos porque estan capados solo para root

8. Sistemas de archivos no montados:

```
cat /etc/fstab | grep -v "#" | column -t
```
![[Pasted image 20260916161401.png]]

	Habra veces que no podremos montar los sistemas de archivos porque estan capados solo para root

9. Busqueda de archivos ocultos:

```
find / -type f -name ".*" -exec ls -l {} \; 2>/dev/null | grep htb-student
```
![[Pasted image 20260916161445.png]]

10. Busqueda de directorios ocultos:

```
find / -type d -name ".*" -ls 2>/dev/null
```
![[Pasted image 20260916161509.png]]

11. Carpetas destinadas a archivos temporales: /tmp, /var/tmp

- /tmp: se almacenan durante un tiempo mas corto (se eliminan tras reinicio)
- /var/tmp: se almacenan durante un tiempo mas largo (no se eliminan tras reinicio)

```
ls -l /tmp /var/tmp /dev/shm
```
![[Pasted image 20260916161713.png]]
