
Podemos encontrar credenciales en archivos de configuracion (`.conf, .config, .xml, .php...`), scripts de shell, archivos de historial, de respaldo `.bak` o en archivos de texto

/var: suele contener el webroot de los servidores web el cual puede contener credenciales para conectarse a BBDD i otros tipos de credenciales. Ejemplo:

```
grep 'DB_USER\|DB_PASSWORD' wp-config.php
```
![[Pasted image 20260916214343.png]]

Los directorios spool o de correo, si son accesibles, tambien pueden contener informacion valiosa o credenciales:

```
find / ! -path "*/proc/*" -iname "*config*" -type f 2>/dev/null
```

## SSH Keys

Buscar el directorio .ssh donde se encuentran las claves SSH. 

Podemos encontrar el archivo `known_hosts` que se usa para que SSH recuerde los servidores a los que el usuario se ha conectado y sus claves publicas 
	(los hosts que encontremos son a los que se ha conectado el usuario y podrian ser interesantes)

```
ls ~/.ssh
```
