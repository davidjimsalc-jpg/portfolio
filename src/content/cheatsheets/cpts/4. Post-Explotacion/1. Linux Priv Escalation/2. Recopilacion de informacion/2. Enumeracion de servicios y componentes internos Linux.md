## Servicios

#### Paquetes instalados

Para encontrar paquetes que tengan vulnerabiliades. Para detectar estos paquetes que podrian ser vulns:

```
apt list --installed | tr "/" " " | cut -d" " -f1,3 | sed 's/[0-9]://g' | tee -a installed_pkgs.list
```
![[Pasted image 20260916212838.png]]

#### GTFObins

[GTFObins](https://gtfobins.github.io/): es una plataforma que incluye binarios que pueden ser explotados para escalar privs

```
for i in $(curl -s https://gtfobins.org/api.json | jq -r '.executables | keys[]'); do if grep -q "$i" installed_pkgs.list; then echo "Check for GTFO: $i";fi; done
```
![[Pasted image 20260916213139.png]]


#### Trazar llamadas al sistema

Strace: se puede usar para rastrear y analizar llamadas al sistema y el procesamiento de señales. Esto nos permite seguir el flujo de un programa y entender como accede a los resultados del sistema, procesa señales y recibe o envia datos

```
strace ping -c1 10.129.112.20
```
![[Pasted image 20260916213520.png]]


#### Archivos de configuracion

Pueden contener secretos y credenciales:

```
find / -type f \( -name *.conf -o -name *.config \) -exec ls -l {} \; 2>/dev/null
```
![[Pasted image 20260916213606.png]]

#### Busqueda de scripts

Similar que con los archivos de configuracion:

```
find / -type f -name "*.sh" 2>/dev/null | grep -v "src\|snap\|share"
```
![[Pasted image 20260916213635.png]]

#### Servicios en ejecucion por usuario

Si observamos la lista procesos podremos saber que scripts o binarios se estan ejecutando y porque usuario

```
ps aux | grep root
```
