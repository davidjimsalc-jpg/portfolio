
Una vulnerabilidad en el kernel de Linux, llamada [Dirty Pipe](https://dirtypipe.cm4all.com/) ([CVE-2022-0847](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2022-0847)), permite la escritura no autorizada en archivos del usuario root en Linux. Técnicamente, la vulnerabilidad es similar a la vulnerabilidad [Dirty Cow](https://dirtycow.ninja/)

Todos los kernels desde la versión `5.8` hasta la `5.17` están afectados

Permite a un usuario escribir en archivos arbitrarios siempre que tenga acceso de lectura a dichos archivos

Por ejemplo, podríamos editar el archivo `/etc/passwd` y eliminar la solicitud de contraseña para el usuario root

1. Descargamos el [PoC](https://github.com/AlexisAhmed/CVE-2022-0847-DirtyPipe-Exploits)

```
git clone https://github.com/AlexisAhmed/CVE-2022-0847-DirtyPipe-Exploits.git
cd CVE-2022-0847-DirtyPipe-Exploits
bash compile.sh
```

Tras compilar el código, tenemos dos _exploits_ diferentes disponibles. La primera versión del _exploit_ (`exploit-1`) modifica el archivo `/etc/passwd` y nos da una terminal con privilegios de root.

Con la ayuda de la segunda versión del _exploit_ (`exploit-2`), podemos ejecutar binarios SUID con privilegios de root. Sin embargo, antes de poder hacerlo, primero necesitamos encontrar estos binarios SUID

2. Verificamos la version del Kernel:

```
uname -r
```
