
Estas tareas se pueden configurar tambien para que solo se ejecuten una vez y se suelen usar para tareas administrativas

El comando `crontab` puede crear un archivo cron y este se ubicara en `/var/spool/cron`

Elementos de los archivos crontab:

```
minutos horas dias semanas COMANDO

0 */12 * * * /home/admin/backup.sh  --> backup.sh se ejecuta cada 12h
```

	Los crontabs de root casi siempre solo pueden ser editados por root o por un usuario con privs

Igualmente podremos buscar que archivos ejecutados como root son escribibles por todos o mirar el archivos crontab y modificar una linea de ese archivo añadiendo un comando de reverse shell

Hay aplicaciones que crean archivos en `/etc/cron.d` y puede estar mal configurados


1. Buscamos un archivo o directorio con permisos de escritura:

```
find / -path /proc -prune -o -type f -perm -o+w 2>/dev/null
```

	Aqui vemos varios backup.sh escribibles

```
ls -la /dmz-backups/
```

[pspy](https://github.com/DominicBreuker/pspy): nos permite confirmar que se esta ejecutando una tarea cron ya que nos permite ver los procesos en ejecucion sin ser root

