
La cuenta `root` proporciona acceso administrativo

## Enumeracion

[LinEnum](https://github.com/rebootuser/LinEnum): puede asistir a la enumeracion para la escalada de privs

Piezas para la enumeracion manual:

- Version del SO y Distribucion: para saber las herramientas que pueden estar disponibles y exploits
- Version del kernel: para encontrar exploits publicos (estos pueden causar inestabilidad)
- Servicios en ejecucion: para ver que servicios estan corriendo y cuales como root. Un servicio mal configurado o vulnerable que se ejecute como root puede ser una ruta facil de escalada

#### Listar procesos

```
ps aux | grep root
```

- Privilegios de sudo: por si podemos ejecutar algun comando o script como `root` debido al NOPASSWD

```
sudo -l
```
![[Pasted image 20260916154302.png]]

- Archivos de configuracion: pueden contener mucha informacion `.conf, .config, .cfg...`
- Archivo shadow: si es legible contiene los hashes de contraseñas de usuario
- Hashes de /etc/passwd: podria recopilar hashes de contraseñas de usuario, aunque en la gran mayoria de ocasicones pone una X y los hashes se guardan en /etc/shadow

```
cat /etc/passwd
```
![[Pasted image 20260916154603.png]]

- Tareas cron: tareas programadas de Linux que pueden ser aprovechadas si tenemos permisos de escritura en ellas o si estan mal configuradas

```
ls -la /etc/cron.daily/
```
![[Pasted image 20260916154656.png]]

- Sistemas de archivos no montados y unidades adicionales: se descubrimos y podemos montar una unidad o un sistema de archivos no montado para leer archivos sensibles, contraseñas o copias de seguridad

```
lsblk
```
![[Pasted image 20260916154801.png]]

- Permisos SETUID y SETGID: pueden permitir que el archivo se ejecute como root
- Directorios con permisos de escritura: descubrir que directorios tienen permisos de escritura por si necesitamos cargar herramientas

```
find / -path /proc -prune -o -type d -perm -o+w 2>/dev/null
```
![[Pasted image 20260916154954.png]]

- Archivos con permisos de escritura: si hay un script ejecutado como root que tengamos permisos de escritura podriamos elevar nuestros privs facilmente:

```
find / -path /proc -prune -o -type f -perm -o+w 2>/dev/null
```
