
[OpenVAS](https://openvas.org/) : es un escaner de vulnerabilidades publico que tiene capacidades para realizar escaneos de red autenticados y no autenticados

![[Pasted image 20260410145404.png]]

## Instalar OpenVAS

	sudo apt-get update && apt-get -y full-upgrade
	sudo apt-get install gvm && openvas
	gvm-setup

La primera vez que se levante puede tardar mucho 30min

![[Pasted image 20260410145450.png]]

Tras esperar podemos por fin empezar con OpenVAS:

	gvm-start
