
## SSH - 22

SSH (22) es un protocolo de acceso remoto seguro. Nos podemos autenticar con credenciales (user:pass) o mediante una clave publica (pub_key o id_rsa)

	ssh user@IP
		Enter Password: PASSWORD

	ssh user@IP -i id_rsa
