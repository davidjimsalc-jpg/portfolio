## Modulos

#### Auxiliares 

> search type:auxiliary name:http

| Modulo                | Explicacion                                                                                                                               | OPTIONS IMPORTANTES                                                               |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| http_version          | Nos revela info de version del servicio, host... Nos permite mas adelante encontrar vulnerabilidades a esas versiones                     | PORT 80 o 443<br>SSL fasle o true                                                 |
| http_header           | Nos revela los hearders de la web<br><br>Se puede cambiar a GET                                                                           |                                                                                   |
| http_put              | Verifica si se puedan hacer puts o deletes poniendo un archivo cualquiera<br><br>ACTION: put o delete                                     | FILEDATA archivo,<br>PATH,<br>ACTION                                              |
| robots_txt            | Nos revela el contenido del robots.txt                                                                                                    | PATH /,<br>VHOST nombre.domio.algo                                                |
| dir_scanner           | Realiza un fuzzing de directorios<br><br>Nos interesan los codigos:<br>- 200<br>- 301: son redirecciones<br>- 401: mirar si existen       | DICCIONARY, PATH                                                                  |
| files_dir             | Reliza un fuzzing de archivos de la web con sus extensiones y recursos                                                                    | EXT,<br>PATH                                                                      |
| apache_userdir_enum   | Enumera usuarios validos del servidor apache mediante una wordlist                                                                        | USER_FILE                                                                         |
| http_login            | Realiza una fuerza bruta de usuarios y contraseñas en una ruta la cual pida credenciales (ej. /secure que tiene un form de autenticacion) | AUTH_URI /ruta,<br>BRUTEFORCE_SPEED <1-5>,<br>PASS_FILE,<br>USER_FILE,<br>VERBOSE |
| robots.txt            | Mirar si tiene /robots.txt                                                                                                                | TARGETURI                                                                         |
| brute_dirs            | Fuzzing directorios web                                                                                                                   | TARGETURI<br>WORDLIST                                                             |
| iis_webdav_upload_asp | Subir archivo asp al WebDAV                                                                                                               | HTTPPASSWORD<br>HTTPUSERNAME<br>PATH /RUTA/ARCHIVO.ASP                            |
