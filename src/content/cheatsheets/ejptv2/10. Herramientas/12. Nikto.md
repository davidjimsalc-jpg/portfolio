

| nikto -h target                                                                                                                       | Realiza un escaneo del target<br><br>Veremos cosas como:<br>- Version webserver<br>- Lengua y version backend dado por el header "x-powered-by"<br>- La variable de la cookie: PHPSESSID<br>- /robots.txt esta presente<br>- config directory si se encuentra<br>- Otros directorios que se encuentren como phpmyadmin por ejemplo |
| ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| nikto -h /URL/path -Tuning 5 -o nikto.html -Format htm                                                                                | Con esto podemos ver si en una url especifica hay alguna vuln de inclusion de archivos (En la vida real no va a haber una direccion que sea Local File Intrusion tan obvia pero es para demostrarlo)<br><br>-Tuning 5: limita el escaneo a vulns tipo 5 = file inclusion (tambien incluye RFI entre otras)<br>                     |
| Si ha nikto le especificas un path toma como objetivo ese path pero si le especificas el home page analiza el servidor web en general |                                                                                                                                                                                                                                                                                                                                    |
