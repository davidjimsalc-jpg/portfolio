
## Con Nmap

| nmap -Pn -sS -sV -O -T4 IP                    | Encontramos un solo puerto, SSH version OpenSSH 7.2p2 en un Ubuntu 4ubuntu2.6 y protocolo 2.0                                                                                |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ls -la /usr/share/nmap/scripts \| grep banner | Con este script podemos ver que servicio y version esta corriendo en ese puerto en particular si es obetenible                                                               |
| nmap -Pn -sS -sV --script=banner -T4 IP       | Vemos lo mismo que hemos obtenido antes.<br>Suele ser muy util cuando no somos capaces de identificar un servicio por -sV                                                    |

## Con Netcat

| nc IP PUERTO -v                               | Nos da el mismo banner que nmap<br>Es util cuando con el script de nmap no nos da informacion valida<br>-v: verbose mode                                                     |
